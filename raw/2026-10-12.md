## 重点论文 / 模型 / 项目

## 1. WorldGuide: Goal-Directed Video World Model for Procedural Task Execution｜P0

**作者与机构**：Ankan Deria、Komal Kumar、Hisham Cholakkal、Fahad Shahbaz Khan、Salman Khan；Mohamed bin Zayed University of Artificial Intelligence（MBZUAI）。**发布时间与性质**：arXiv v1 2026-10-08 UTC；预印本，尚未同行评审；本轮同时有官方 GitHub 和 Hugging Face 模型卡更新。论文、项目页、[GitHub](https://github.com/mbzuai-oryx/WorldGuide)、[Hugging Face 模型卡](https://huggingface.co/MBZUAI/WorldGuide-Ckpt)。

它解决的是长时程序视频生成的闭环问题：给定初始图像和目标，模型不能只生成一条固定动作序列，而要根据已经生成的视觉结果决定下一步，并知道何时结束。WorldGuide 的 ContextPlanner 预测原子动作或 `<DONE>`，Video DiT Executor 生成动作对应的短视频片段；片段进入下一次规划，分层视觉记忆保持长时状态且控制 token 成本。Planner 与 Executor 使用同一批 step-level demonstrations 训练，Executor 还接收 planner 的动作 embedding，因此“提出动作”和“把动作实现出来”在训练目标中对齐。

作者报告的 WorldGuide Bench 包含约 58,679 个视频、245 个任务和 27 类程序任务。WorldGuide 在该基准上的 Task Success 为 **33.33%**，MiniMax-H3 为 29.90%，但两者输入条件不完全相同，官网还标注差异统计显著性不足；在 VideoCraft-Bench 的 goal-only 条件下，WorldGuide 为 **47.69%**，MiniMax-H3 为 32.73%。这些是作者/官方结果，不是第三方复现。核心创新不是“视频更清晰”，而是把视觉反馈、原子动作执行和终止判断放进同一个闭环。与 open-loop 视频模型、冻结 executor 的 planner-executor 方法相比，它更接近可被审计的程序执行模型。

局限在于它仍是视觉世界中的程序视频生成，不是实体机器人控制；成功率低于 50%，并且测试划分是已知任务的新示范，不能直接等同于任务外泛化。视频评估还依赖自动/人工判断，生成错误会跨步累积。可复现性在今日候选中最好：闭环训练/推理代码已公开，项目页给出 planner/executor checkpoint 路径，但当前 Hugging Face 仓库实际只有 README 与 .gitattributes，不能把权重写成已确认下载；数据集仍标注为 coming soon，完整训练依赖 HunyuanVideo-1.5 和多 GPU。轻量验证建议先取 20-50 个任务子集，对比 closed-loop、open-loop、去视觉反馈三种设置，固定同一视频 backbone，用完成率、重复/跳步率和人工状态检查替代单一视觉质量分数。

**是否值得深入阅读：是，优先级最高。** 它把“世界模型是否真的用于行动”转化为可观测的 next-step、completion 和 state-feedback 指标。

## 2. MiniWAM: Learning Compact Future Targets for Efficient World-Action Modeling｜P0

**作者与机构**：Jie Chen、Ruofei Bai、Yuxin Cai、Yifeng Zhang、Chengyang He、Jun Li、Wei-Yun Yau、Guillaume Sartoretti；National University of Singapore、Nanyang Technological University、A*STAR Institute of Advanced Intelligence and Computing。**发布时间与性质**：arXiv v1 2026-10-08 UTC；机器人 WAM 预印本；[论文](https://arxiv.org/abs/2610.12194)，[项目页](https://j1dan.github.io/MiniWAM)。

MiniWAM 针对 WAM 的主要成本瓶颈：多数方法在 DINO、视频 VAE 等 backbone 的原生高维特征空间预测未来，导致未来 token 太多、训练太慢。它先用 privileged current-future transitions 训练 PRISM（Predictive Representations via Inverse Spatiotemporal Modeling），把 inverse-dynamics supervision 与 feature reconstruction 结合起来，再冻结 PRISM encoder，让 MiniWAM 从当前观测同时预测紧凑未来表示和机器人动作。训练目标因此保留控制相关的变化信息，同时丢掉不必要的视觉细节。

作者报告：相对 native future-feature prediction，未来特征 token 减少 **65 倍**，world-action training 最高加速 **8 倍**；项目页给出的 0.25B 结果为 LIBERO **97.2%**、LIBERO-Plus **73.6%**、RoboTwin 2.0 **46.1%**，可与明显更大的 WAM 竞争。表征分析显示 PRISM 学到的行为结构不只是重建特征的副产物。结果均为作者报告，目前没有我能确认的第三方复现；项目页明确写着 **Code & models coming soon before Nov 2026**，因此代码、权重和训练数据仍未公开确认。

创新点是把“世界建模的价值”从像素/原生 feature 保真转成“对控制足够的未来表示”。局限是 PRISM 依赖 privileged current-future transitions，仿真证据强于实机证据，且尚未证明压缩目标在遮挡、视觉大变化或跨 embodiment 下同样稳定。与 PLaW-VLA、DreamTrue 等上一期条目相比，本项不是重复的 counterfactual post-training，而是直接压缩 future target 和训练成本。

轻量验证可从 Push-T、LIBERO-90 或单一 RoboTwin 任务开始：保持 action head、backbone 和训练步数不变，比较 native future target、只做 reconstruction、PRISM 三种目标，记录显存、吞吐、未来 latent 预测误差、短闭环成功率和 long-horizon drift。**是否值得深入阅读：是。** 它是本轮最适合在单卡上做机制复现的候选。

## 3. LeWAM: End-to-End World and Action Modeling with JEPAs｜P0

**作者与机构**：Minghao Fu、Tavis Siebert、Eryk Halicki、Randall Balestriero；University of California San Diego、ETH Zürich、University of British Columbia、Brown University。**发布时间与性质**：项目页与 GitHub/Hugging Face 在 2026-10-09 至 2026-10-11 连续更新；arXiv 正式论文仍标为 coming soon，属于官方项目/代码/数据/权重发布，不是已同行评审论文；[项目页](https://le-wam.github.io/)、[GitHub](https://github.com/MinghaoFu/lewam)、[Hugging Face 组织](https://huggingface.co/LeWAM)。这与下一节 NVIDIA 版 LeWAM 不是同一工作。

它把共享 ResNet-18 encoder、Mixture-of-Transformers predictor、latent dynamics 与 action flow matching 合在同一端到端模型中，训练目标为 latent prediction、action flow matching 和 SIGReg 高斯正则。规划过程是 sample -> imagine -> refine -> execute：先采样动作，再预测 latent future，用目标 latent 误差和 proximity penalty 做梯度 refinement，执行前 K 个动作后重规划。

官方项目页给出的作者结果是：十个模拟导航/操作环境的平均 visual-planning success **93.5%**，LeWM+CEM 为 50.9%；100-step long-horizon 平均 **46.2%** 对 10.9%。最新公开仓库还给出三种 seed 的 Push-T **98.7%**、Scene **97.3%**、ToolHang **94.7%** 等任务结果，以及行为克隆平均 64.7%；这些都是作者/官方 artifact 的自报结果，尚无第三方复现。

本项的价值在于可复现性边界已经清楚：MIT 代码、HDF5 数据和 Hugging Face checkpoint 均有入口，任务配置和 reproduce 文档齐全，适合今天就跑一个 Push-T 或 ToolHang。局限是主要证据仍是仿真和小规模实体机器人，且与 NVIDIA 的同名 LeWAM 在架构、作者和 arXiv 状态上都不同。轻量验证应先按官方脚本固定 seed 跑单任务，再将 latent planning 换成 action-only baseline，比较模型预测收益与真实 rollout 的相关性。**是否值得深入阅读：是，artifact-first 优先级高。**

## 4. LeWAM: A JEPA World Action Model with Diffusion-Steering-Based MPC｜P1

**作者与机构**：Shashank Hegde、Alexander Popov、Elie Aljalbout、Nikolai Smolyanskiy；NVIDIA。**发布时间与性质**：arXiv v1 2026-10-08 UTC；预印本；[论文](https://arxiv.org/abs/2610.12407)。它必须与上一节 Fu 等人的 LeWAM 分开记录，不能把两个仓库或结果合并。

NVIDIA 版 LeWAM 解决重建式 WAM 的冗余 latent 与 raw-action MPC exploitation：在 decoder-free JEPA latent 上用 bidirectional Transformer 同时学习 forward、backward、inverse dynamics 和 policy prediction；action head 用 flow matching；规划时在 policy diffusion noise space 采样和 steering。

作者报告：linear probe 中 task-state 信息优于 forward-only LeWM，同时压低视觉 distractor；Lift、Can、Square 的完整四模式 policy success 约为 **94.0%、82.8%、80.4%**，noise-space DS-CEM 约为 **97.6%、78.8%、87.2%**，raw action MPC 约坍缩到 3%-8%。尚未发现与该 arXiv ID 明确绑定的代码/权重或独立复现。

它与 Dreamer/TD-MPC、LeWM 和重建式 WAM 的关系是“保留可规划 dynamics，但把 latent 和 MPC 变量都约束到控制分布”。局限是任务规模较小、以仿真和受控 distractor 为主，尚未证明大规模视频或多 embodiment 外推。轻量验证建议在 Push-T/Lift 复现 raw-action MPC、noise-space MPC 和无 planning policy，画模型预测收益与真实 rollout 收益的 ranking correlation。**是否值得深入阅读：是。** 重点读 §4.2 和 §5.5，检查 noise-space 约束究竟减少了 model exploitation 还是只提供了更强的行为先验。

## 5. VioLA: Learning Generalist Humanoid Control Policies from Human Data｜P0

**作者与机构**：Mert Albaba、Jens Beißwenger、Anna Manasyan、Daniel Marta、Michael J. Black、Wieland Brendel、Andreas Krause、Georg Martius、Martin Riedmiller；Vesoma、ETH Zürich、Max Planck Institute for Intelligent Systems、University of Tübingen、ELLIS Institute。**发布时间与性质**：arXiv v1 2026-10-08 UTC；预印本；项目页 [viola.is.tue.mpg.de](https://viola.is.tue.mpg.de/)，[论文](https://arxiv.org/abs/2610.12435)。

VioLA 处理的是人形机器人“动作空间太大、机器人示范太少”的双重瓶颈。它不让 generalist policy 直接预测关节命令，而是预测 body motion latent 和 hand motion latent；冻结的 body/hand controller 再把 latent 转成保持平衡的机器人命令。人类和机器人动作 encoder 映射到同一个 latent space，因此人的视频可以直接作为 policy action target。训练池共 1.406 亿帧，其中 **93.2% 来自人类数据**。

官方项目页把实机结果写成 locomotion/posture **30/30（100%）**、whole-body manipulation **31/35（88.6%）**；对比的 released GR00T N1.7 分别为 5/30 和 0/35，Ψ0 为 0/30 和 3/35。项目页同时明确：task families 出现在训练中，但 evaluation episodes、实验室环境和 object instances held out；所以“zero-shot”指没有 task-specific fine-tuning，不是任务类别完全未见。代码仍标注 coming soon，目前没有第三方验证。

创新价值在于重新定义 human-to-robot 对齐接口：不是先把人类动作精确 retarget 成关节轨迹，而是把跨身体的 motion latent 作为中间协议。局限是高度依赖预训练 controller 的质量与 embodiment 覆盖，当前实证集中在 Unitree G1，复杂接触、手指精细操作和跨机器人迁移仍需验证。

轻量验证可先冻结一个已有 whole-body controller，在 3-5 个 locomotion 和 3-5 个 manipulation 任务上，对比 joint-action policy、motion-latent policy 和 human-only/mixed/robot-only 三种数据配方；重点记录平衡恢复、动作延迟、latent reconstruction error 和 manipulation contact failure。**是否值得深入阅读：是。** 它是本轮最直接的数据接口创新。

## 6. ManiUnit: A Manipulation Skill Dataset and Benchmark for Long-Horizon Tasks｜P1

**作者与机构**：Guoting Wei、Dawei Yan、Xia Yuan、Gengming Zhang、Yelin He、Guodong Du、Jiaquan Ye、Heng Zhang、Xinming Wei、Xianbiao Qi、Chunxia Zhao、Haokui Zhang、Rong Xiao；Nanjing University of Science and Technology、Northwestern Polytechnical University、Intellifusion。**发布时间与性质**：arXiv v1 2026-10-08 UTC；数据集/benchmark 预印本；[论文](https://arxiv.org/abs/2610.12089)。

ManiUnit 不再把长时任务只评成一个终点成功率，而是从 50 个 BEHAVIOR-1K activities 中切出 **137,899 个 segments、21 类 skill、417 个 subtasks**，构成 **1,260 个 test instances**。每个 segment 有显式 subtask instruction；benchmark 通过恢复中间 simulator state、设定 local success condition，并分别扰动 mobile base 或 joint configuration，测量 skill 是否能从真实继承状态开始工作。

作者报告：joint perturbation 让 full benchmark success 相对 demonstrated starting states 下降约 **56%**；在两个长时活动上，skill-level policy 的 local manipulation success 为 **78.7%**，完整示范训练的 task policy 为 **49.3%**；通过 planner 组合 task policy 与 skill policy，full-task success 从 **4.0%** 提升到 **18.0%**。这些是作者/官方论文结果，尚未看到公开下载、代码或第三方复现的明确链接。

它的创新是把“顺序执行失败”拆成 skill ambiguity、starting-state mismatch 和 evaluation opacity 三个可测问题，与仅看最终帧或最终成功的 benchmark 形成互补。局限是当前主要在仿真，技能切分与 local goal 依赖 BEHAVIOR-1K 的 simulator 定义，真实机器人上的继承状态和接触误差仍未知。

轻量验证建议只选 5-10 个 BEHAVIOR 活动，建立 original/base-perturbed/joint-perturbed 三组起点，比较 task-only、skill-only、planner-composed 三种执行；报告每个中间 skill 的 attempt rate、local success、继承状态误差和终点 success，而不是只汇总最后一项。**是否值得深入阅读：是。** 它提供了把长时机器人结果变成可诊断证据的最小评测骨架。

## 7. Embodied Turing Machines: Stateful Code for Robot Recursive Self-Improvement｜P1

**作者与机构**：Kairui Hu、Siyuan Hu、Fangzhou Hong、Zhaoxi Chen、Ziwei Liu；Nanyang Technological University、Ropedia。**发布时间与性质**：arXiv v1 2026-10-08 UTC，技术报告；[论文](https://arxiv.org/abs/2610.12369)。

论文提出 Code-Only-as-Policy（COAP）：把机器人与环境看成 Embodied Turing Machine，世界状态是 tape，代码规则是 policy。代码从 RGB 和 proprioception 测量/维护显式状态，再做 action、check、recover；不同任务共享一个 library，coding agent 可以在闭环中修改和复用库。运行时不需要 VLA/VLM，因而执行便宜、可审计、可回溯，也可能成为 VLA 或 Agent Harness 的数据引擎。

作者在 RoboDojo 42 个双臂任务上报告 **70.24% success**，且测试时不运行模型。其真正价值不在“代码一定能替代 VLA”，而在于把 self-evolution 的对象变成显式函数、状态变量和验证测试。当前没有公开权重/代码和第三方复现；外部自动审阅也提醒结果依赖 benchmark assets 与状态表示质量，因此应把 70.24% 当作作者声明，而不是已确立的 SOTA。

局限是 COAP 的上限由 perception/state estimation 和手工/自动代码逻辑决定；面对未建模接触、视觉歧义或新物体，显式状态可能比 latent policy 更脆。它与本轮 VioLA 的关系是互补：VioLA 扩大 data interface，COAP 扩大 execution/state interface；与 agentic RSI 的关系是把“改模型”转成“改可验证程序”。

轻量验证可在 Push-T、LIBERO 或 3 个 RoboDojo 子任务上写一个小型 state machine，比较 COAP、VLA 和 Agent Harness 的 CPU/GPU 成本、恢复次数、失败类型、代码 diff 是否能解释成功提升；每次自修改必须有 holdout scene 和回滚测试。**是否值得深入阅读：谨慎值得。** 先读状态表示和 failure recovery，再读 headline success。

## 8. Unifying Policy Learning and State Prediction through Spatial Language Modeling｜P1

**作者与机构**：Minye Wu、Zehao Wang、Tinne Tuytelaars；KU Leuven。**发布时间与性质**：arXiv v1 2026-10-08 UTC；预印本；[论文](https://arxiv.org/abs/2610.12172)。

这项工作把空间智能作为一级建模目标：用共享的离散坐标 token 和 semantic token 表示 scene contours、goal、action target 与 future state，再用 task-specific grammar 把它们串成 Spatial Language Sentence。一个 autoregressive Transformer 用统一的 next-token objective 学 action generation 与 action-conditioned state prediction；训练先用 random-play transition pretraining，再用 expert demonstrations 同时监督动作和状态。控制时只解码可执行 action target，新观测不断刷新 history。

作者在 Push-T 仿真和真实机器人上报告了与基线有竞争力的仿真表现，以及更高的 real-robot task success 和 target coverage；联合 action/state sequence 与 random-play pretraining 都带来增益。该结果是作者报告，摘要没有给出完整数值，尚无我能确认的代码、权重或独立复现。创新是让空间几何和动作共享一个可解释的坐标语言，而不是把空间状态隐藏在不可解码的 feature 中。

局限是目前集中在二维 Push-T，坐标 grammar 的扩展性、遮挡、三维接触和多物体关系尚未验证。轻量验证可以在同一 Push-T 环境中做 action-only、action+future-state、random-play+joint 三个 ablation，统计 state prediction IoU、target coverage、control success 与长时漂移。**是否值得深入阅读：值得作为空间智能分支的基线。**

## 9. Agents as Software: A Programming Languages Agenda for Agent Reliability｜P1

**作者与机构**：Shraddha Barke、Adithya Murali；Microsoft Research。**窗口内发布**：Microsoft Research 在 2026-10-09 以 Onward!/OOPSLA 2026 入口重新发布；原始 arXiv v1 为 2026-09-26，故这是官方发布窗口内新增，不是新论文版本；[官方页](https://www.microsoft.com/en-us/research/publication/agents-as-software-a-programming-languages-agenda-for-agent-reliability/)，[arXiv](https://arxiv.org/abs/2609.32198)。

这篇 agenda 把 agent 视为由 prompt、工具、memory、policy、workflow 和 execution trace 共同构成的软件 artifact。它建议用 event-trace/state specification 描述 permission discipline、grounded belief、freshness、temporal guards 和 budget invariants，在部署前做 static analysis，在运行时做 prefix-based monitoring、证据检查与 recovery。它没有新模型、代码、数据集或定量 benchmark，贡献是把 Agent reliability 从“模型输出好不好”转成“轨迹、状态和高影响动作能否被规格化、监控和修复”。

这项工作的价值在于为 COAP、Agent Harness 和 self-evolution 提供共同的审计语言，局限则是 abstraction ambiguity、事件词汇遗漏与自然语言 predicate 不可靠尚未通过实验解决。轻量验证可将一个机器人/科研 agent 的工具调用记录序列化成 trace，先实现 `must-confirm-before-act`、`freshness-before-schedule` 和 `rollback-on-violation` 三个监视器，再测违规阻断率和误报率。**是否值得深入阅读：值得作为 Agent infrastructure 背景，但不能把它当成已验证的可靠性系统。**

## 10. VPP2: Video Prediction Policy 2｜P1

**作者与机构**：ROBOTERA、香港大学 MMLab 及合作机构；本轮为公司官方 PR 与 RoboDojo leaderboard 的窗口内新增证据，上一期候选池已出现 VPP2，因此只有这次的新 benchmark/code 证据使它重新升档。**发布性质**：[ROBOTERA 官方 PR](https://www.prnewswire.com/news-releases/robotera-tops-embodied-ai-benchmark-robodojo-302903605.html) 2026-10-09；[RoboDojo leaderboard](https://robodojo-benchmark.com/) 2026-10-08/09；代码据官方说明开源。

VPP2 是把 video prediction 与 action generation 结合的 WAM，目标是让模型预测动作改变环境的方式，并可由 VLM 先分解高层指令。官方报告 RoboDojo 平均 success **32.26%**、score **39.26**，ALOHA 十类任务平均 **58.5%**，LIBERO-Pro **45.0%**，高层 planner 组合后五类任务从 27.6% 提升到 57.6%。这些仍是公司/benchmark 贡献方报告，不能替代独立复现；但 RoboDojo 官方榜单已记录 39.26/32.26，且公开代码使其具备可核验入口。

局限是官方 PR 未给出完整训练数据、权重版本与评测脚本细节，真实机器人数字仍可能受平台与任务选择影响。轻量验证应先跑公开 RoboDojo/ALOHA 子集，固定 VPP2、同一 VLM planner 和一组 held-out object，逐项核对 video prediction、instruction following、action success 三层指标，不把一个 aggregate score 直接当作 WAM generality。**是否值得深入阅读：是，但先做 artifact/leaderboard 对账。**

## 今日研究地图

| 问题分类 | 今日映射 | 近期趋势 | 仍未解决的 gap |
|---|---|---|---|
| 结果可验证的世界模型 | WorldGuide | 从 open-loop 视频走向视觉反馈、原子动作与完成判定 | 生成视频的成功状态是否对应真实物理状态，尚缺跨任务、跨 embodiment 的可执行验证 |
| 紧凑预测表示 | MiniWAM、Fu 等人 LeWAM、NVIDIA LeWAM | native future feature 转向 compact latent、JEPA 与 policy-conditioned planning | 压缩是否保留接触、遮挡、失败边界；latent metric 与真实 success 的对应关系仍弱 |
| 人到机器人数据接口 | VioLA | 从 joint retargeting 转向共享 motion latent 与冻结 controller | 多机器人、多手型、多接触任务的统一 latent 是否稳定，尚缺公开 checkpoint 与第三方复现 |
| 长时执行诊断 | ManiUnit、Spatial Language Modeling | 从 terminal success 转向 skill/local state/next action 证据 | 仿真中间状态与真实继承状态之间仍有 gap，评测协议还没有统一 |
| 显式状态与自进化 | Embodied Turing Machines、VPP2、Agents as Software | 从改参数转向改代码、状态、trace 和 recovery logic | 如何防止代码过拟合 benchmark，如何做 holdout、回滚和安全审计 |
| Spatial Intelligence | Spatial Language Modeling、WorldGuide | 空间几何、状态预测和目标动作共享接口 | 2D/3D/4D 表示、persistent memory、物理动力学和语言动作接口尚未统一 |

本期可归纳出三条趋势：

1. **闭环优先**：世界模型的价值越来越由“下一步是否因结果而改变”衡量，而不是单帧视频质量。
2. **压缩但不失控**：MiniWAM 与 LeWAM 都在寻找比像素或 dense VAE 更小的未来表示，但必须保留可规划的 dynamics。
3. **状态接口外显**：VioLA 用 motion latent，ManiUnit 用 skill unit，COAP 用代码状态，Spatial Language Modeling 用坐标 token，大家都在把 action/world state 从黑盒中间层拉到可检查接口。

## 今日研究机会与轻量验证

**机会 A：把 WorldGuide 的闭环指标移植到机器人 WAM。** 用 MiniWAM 或一个小型 latent dynamics，在每一步同时输出 next action、predicted future state、uncertainty 和 completion；先在 LIBERO/Push-T 做 50 个 rollout，比较 open-loop、replan-with-predicted-state、replan-with-observed-state。核心不是追求更高 FVD，而是测 `P(success | predicted state)` 与 `P(success | observed state)` 的差距。

**机会 B：PRISM/JEPA 的控制保真度测试。** 在固定 backbone 和 action head 下，逐步压缩 future target，画出 token budget - latent error - closed-loop success 曲线；加入视觉 distractor、遮挡、摩擦变化三种干扰。若压缩后 success 保持而 state reconstruction 下降，说明目标真正抓住了 control-relevant information。

**机会 C：human-to-robot latent 的最小跨 embodiment 实验。** 不必训练 VioLA 的 140.6M 帧版本；用少量人类动作、一个 frozen controller 和 2 个不同形态模拟器，测同一 latent 的 motion decoding、balance recovery、contact failure。加入 robot-only、human-only、mixed 三种配方，保持更新步数一致。

**机会 D：长时 benchmark 的中间证据协议。** 在 ManiUnit 风格的 5-10 个任务上强制记录 `skill attempt -> local success -> inherited state error -> next action`，再把 WorldGuide/COAP 的 completion 或 recovery 机制接上。目标是让任何 terminal success 都能追溯到具体中间失败，而不是只比较最终百分比。

**机会 E：把 Agent trace contract 接到机器人执行。** 参照 Agents as Software，把 `action proposal -> evidence -> authorization -> execution -> outcome` 写成 trace，接入 ManiUnit 的 local goal 与 COAP 的 recovery library；在同一批任务上测安全阻断、恢复成功和误报率。
