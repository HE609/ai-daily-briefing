## 今日精读顺序

**今天我建议的精读顺序是：GR00T 2 → Meituan-Robotics-0 → ObjectWorld → Tiresias → REINS。**

- **GR00T 2：**先看官方 WAM 如何把人类视频、UMI 与机器人数据放进同一个未来视频—动作目标，并把“零样本跨本体”与“少样本适配”分开报告。
- **Meituan-Robotics-0：**再看一个资源已经闭合的中国团队 VLA，重点核对离散动作预训练、连续 flow-matching、Rollback 纠错和事件记忆是否真正互补。
- **ObjectWorld：**随后读空间智能主线的完整物体流接口，判断它能否成为跨本体控制前的中间状态，而不是只做漂亮的轨迹预测。
- **Tiresias：**再看语言、候选动作、视频想象和跨域基准如何被统一，尤其关注 36 秒推理成本与 51 分 unseen 结果的关系。
- **REINS：**最后读 Agent harness 如何把 LLM 的语义规则接到毫秒级规划、校验与持久记忆，审计“自演化”是否只是记忆增长而非权重更新。

## 重点论文 / 模型 / 项目

## 1. GR00T 2: Scaling Robot Foundation Models for Generalization, Dexterity, and Adaptation｜P0

**作者与机构：**NVIDIA GEAR / NVIDIA Research。发布时间为 **2026-11-09（官方研究页与 CoRL 公告）**，性质为官方技术报告/白皮书与模型预览，不是已同行评审论文。[官方研究页](https://research.nvidia.com/labs/gear/gr00t-2/) · [白皮书](https://research.nvidia.com/labs/gear/gr00t-2/assets/gr00t2_whitepaper.pdf) · [NVIDIA CoRL 公告](https://blogs.nvidia.com/blog/robotics-simulation-advancements-corl/)。

它解决的是“机器人看到任务但没有关于世界如何变化的可迁移预测”。GR00T 2 用一个 diffusion transformer **同时去噪未来视频与机器人动作**，输入近期视频、指令和本体状态，输出未来观测与动作 chunk；不同本体通过小型动作头接入。官方披露的预训练混合为 **402,730 小时人类第一视角视频、10,184 小时手持 UMI 夹爪演示、23,500 小时机器人遥操作**，覆盖平行夹爪、灵巧手和 Unitree G1。训练目标的关键变化是让视频预测成为动作学习的物理监督，而不是只做动作模仿。

**作者/官方结果：**50 个目标机器人从未见过的任务，零样本平均成功率 **40%**；每任务 1 条示范为 71%，5 条示范、单张 RTX 5090 约 30 分钟 LoRA 后达到 **95%**。真实机器人 RL 后，三个接触丰富任务达到 **88–96%**；通过 Agent 调用 WAM API，三种玩具连续装配为 **98/100、97/100、97/100**；视觉标点把 YAM 的“what-and-where”成功率从 40% 提到 **92%**。GR00T 2 Turbo 在 Jetson Thor 上每次预测 **124 ms**，G1 全身任务 48 次爆米花服务全部成功，清桌任务 93%。模拟—真实匹配的作者报告相关系数为 Pearson **0.92**（成功率）和 **0.93**（Elo）。这些全部是 NVIDIA 官方报告，未见第三方复跑。

**创新、局限与关系：**它把 π0.5、GR00T N1.7、Cosmos/World Action Model 和人类视频预训练路线推进到更统一的“世界—动作联合生成”；真正的新证据是跨本体的 human→robot、UMI→YAM 和 DexUMI→灵巧手，而不是又一个仅在 LIBERO 上的 VLA。局限是官方研究页明确写着 **代码预计 12 月提供**，GR00T 2 主权重/训练脚本在本轮未找到；公开的是 **Human-1M-100K** 约 10 万小时子集，不能把它等同于完整 402,730 小时训练语料。任务、机器人、后训练轮数和真实成功门也仍由 NVIDIA 选择，不能直接与第三方榜单混排。

**可复现性与轻量验证：**[Human-1M-100K 数据集](https://huggingface.co/datasets/nvidia/PhysicalAI-Human-1M-100K) 在窗口内有 11 月 7 日更新，CC BY 4.0、可直接浏览；GR00T 2 代码和权重尚未闭合。低成本验证可用公开 GR00T N1.7 或一个 0.5–2B VLA 做四组：机器人数据、机器人+人类视频、联合未来视频/动作目标、联合目标+少样本 LoRA。固定 10–20 个跨本体任务，分别报告零样本、1-shot、5-shot、执行失败类型和推理延迟，不把官方 95% 当作可复现结果。

**是否值得深入阅读：值得，优先级最高。**优先读 72-task 人类视频缩放曲线、X-Adapt 数据契约、Turbo 的压缩视频表示和模拟—真实匹配统计，再看主权重何时真正落地。

## 2. Meituan-Robotics-0: A Vision-Language-Action Foundation Model for Desktop Manipulation｜P0

**作者与机构：**Meituan Robotics Team，论文作者列表含 Caicheng Wang、Chen Zhao、Chengpeng Jin 等；美团机器人团队。论文提交于 **2026-11-05 18:55 UTC**，属于上一批次边界论文；模型、代码、评测 checkpoint 和 RoboDesk 数据在 **11 月 9 日 UTC** 完成实际发布，因此本轮按“窗口内资源新增”纳入。[论文](https://arxiv.org/abs/2611.08577) · [GitHub](https://github.com/Meituan-Robotics/Meituan-Robotics-0) · [主模型](https://huggingface.co/MeituanRobotics/Meituan-Robotics-0) · [RoboDesk](https://huggingface.co/datasets/MeituanRobotics/RoboDesk)。

MR0 面向 stationary-base desktop manipulation，针对三个长期问题：异构机器人数据无法直接混训、成功示范缺少模型自身错误状态、反应式策略离开观察窗口后无法维持任务状态。它的训练链是 **Stage 1 FAST 离散动作 token 预训练 → Stage 2 MMDiT 连续 flow-matching 跨本体控制 → Stage 3 真实世界后训练**。后训练包括成功示范、HG-DAgger、RECAP，以及新提出的 **Rollback**：回到历史锚点保留被替换的失败片段，同时收集人类修正，直接构成 CFG-DAgger 的正负监督。控制侧用统一末端执行器接口和异步 action-chunk merging；Agent 侧用 Monitor、Planner、Event Memory 只在任务进度或可行性变化时重规划。

**结果与资源状态：**训练数据为 **147M vision-language samples、15,060 小时机器人轨迹、12 个本体**；其中公开 RoboDesk 3,235 小时，许可真实数据 7,530 小时，开放仿真 4,295 小时。GitHub 表格给出 RoboTwin 2.0 **93.22% clean、93.88% randomized**；论文总体报告 **93.6%**，RoboDojo VLA 平均成功率 **14.63%**，RoboCasa365 score **29.03 / SR 28.33%**。在 Ethernet insertion 上，RollBack + CFG-DAgger 达到 **70% success、0.90 progress score**。主模型、RoboTwin/RoboDojo/RoboCasa365 checkpoint 和 SHA256 manifest 已在 Hugging Face 出现；代码仓库包含训练配置、评测入口和 OpenPI-compatible policy server。RoboDesk 数据为 **CC BY-NC-SA 4.0**，代码与模型组件许可证需按各仓库和模型卡分别核对。

**创新、局限与关系：**MR0 与 π0.5、OpenVLA、RynnUnify、Fast-WAM 的关系是把跨本体数据对齐、纠错采集和任务记忆放到同一条交付链，而不是只提升 backbone。Rollback 的价值在于它用“被替换动作片段”提供局部失败标签，避免完整 value learning；事件记忆则把长任务状态从运动控制器中拆出来。局限是主表仍以仿真和少量真实任务为主，许可真实数据并不公开；论文报告的 15,060 小时与 GitHub 页面展示的模型/数据快照需固定 revision 后再比较；RoboDojo 分数不能与 RoboTwin 成功率混为一个总榜。

**轻量验证：**先下载主 checkpoint 做 20 个 RoboTwin episode 的推理 smoke test，固定 action chunk 长度与 camera 输入；再做三个开关：无 Event Memory、只事件检索、事件检索+条件恢复。Ethernet insertion 用 30–50 个 Rollback 风格干预片段比较 HG-DAgger、CFG-DAgger 与 RECAP，记录 success、progress、干预次数和恢复延迟。这样可以验证 MR0 的机制贡献，而不重训 15,060 小时模型。

**是否值得深入阅读：值得，优先级与 GR00T 2 并列。**先读数据 canonicalization、Rollback 轨迹重建和 event memory 的触发条件，再核对公开 checkpoint 与论文表格是否来自同一版本。

## 3. ObjectWorld: Scaling Object-Centric World Models with a Large-Scale 3D Full-Object Flow Dataset｜P0

**作者与机构：**Haonan Chen、Sicheng Isabella Lu、Haitian Li、Jiajin Wu、Hexiang Wei、Jiawei Zhang、Xin Fei、Yiwen Hou、Chenrui Tie、Chongkai Gao、Sheng Wang、Lin Shao；新加坡国立大学 Lin Shao 团队。论文和项目页在窗口内公开。[论文 PDF](https://nus-lins-lab.github.io/ObjectWorld/static/paper.pdf) · [项目页](https://nus-lins-lab.github.io/ObjectWorld/)。

它把“目标视频”与“机器人动作”之间的接口改成 **3D full-object flow**：对完整物体表面（包括输入视角看不到的区域）采样 512 个点，预测未来 48 帧的稠密 3D 轨迹。这样一个表示既能描述刚体运动，也能描述衣物、柔性物体的非刚性变形，还不绑定某个机器人本体。训练时 Qwen2.5-VL 产生任务条件视觉/语言特征，PointTransformer V3 编码物体与场景几何，flow head 用 x1-prediction 预测整条表面轨迹；执行时只在接触局部拟合末端轨迹，保留全物体非刚性运动。

**数据和结果：**项目页报告 **1,210.1 小时** full-object flow，其中 755.6 小时真实视频、454.5 小时仿真，约 488K clips/trajectories；论文细化为 198,947 条仿真轨迹、289,976 条真实视频 clips。自动标注不依赖机器人动作、标定相机、深度或预扫描物体网格，使用 VLM、Track4World/DA3、SeC、SAM 3D、Any6D、FoundationPose 组成流水线。Golden filtering gate 的专家验证精度 **93.3%**。全帧 flow EPE **6.22 cm**，优于最强报告基线 10.24 cm；仿真执行 **29/30**，真实平行夹爪执行 **13/15**，高于 Dream2Flow 的 10/15。作者报告的 13/15 与 29/30 都是方法链结果，尚无第三方复核。

**创新、局限与关系：**它连接 ObjectForesight、Dream2Flow、PointWorld 与 4D/3D world model，但把“完整表面、可执行、跨本体”同时放进接口。局限在于完整几何是由多个外部模型估计的，误差会从 VLM 分割、深度、姿态跟踪一路传入 flow；时间被重采样为动作进度，不等价于真实秒级动力学；项目页有交互式 28 个示例，但本轮未找到可下载的完整 1,210 小时数据或训练代码，不能把网页浏览称为数据集开放。

**轻量验证：**从公开 RoboTwin/ManiSkill 生成 20 个 rigid + 10 个 deformable clip，固定 512 点、48 帧，用现成 SAM 3D/Depth Anything/点云配准构造 full-object 与 visible-only 两组监督。只训练小型 flow head，比较 EPE、hidden-surface coverage、flow-to-action 轨迹误差以及真实控制器的成功率；核心是验证完整表面监督的独立增益，而不是复刻自动标注流水线。

**是否值得深入阅读：值得。**优先核对 hidden-surface flow 是否真的改善执行，及“对象运动接口”相对直接视频预测和直接动作监督的样本效率。

## 4. Tiresias: Towards Language-Conditioned World Models｜P0

**作者与机构：**Fengyi Wu、Yifei Dong、Yetong Sha、Lingdong Kong、Qiyu Hu、Bohan Xiong、Qi Dai、Alexander G. Hauptmann、Zhi-Qi Cheng；华盛顿大学、新加坡国立大学、Microsoft Research、卡内基梅隆大学。论文为 **2026-11-07 批次**，含代码和数据脚本。[论文](https://arxiv.org/abs/2611.10392) · [GitHub](https://github.com/UWMILab/Tiresias)。

Tiresias 先提出统一任务 **LCWM**：给定初始 agent-view RGB 和语言指令，输出完成指令的动作序列；LCWM-Bench 把导航、机器人、3D 游戏、驾驶的 **15 个数据集、142,987 episodes、428,961 条三种风格指令**放进同一 action interface 和评测协议。参考 Agent 采用“选择性想象”：语言条件 diffusion policy 先生成 **128** 个候选轨迹，Trajectory Ranker 保留 **8** 个，Wan2.2 视频世界模型只想象这 8 个未来，Visual Ranker 再与轨迹分数按 2:1 融合选出最终动作。

**作者结果：**LCWM-Bench val seen overall score（SR 与 nDTW 的四域宏平均）为 **63**，val unseen 为 **51**；MPC 版本为 59/46。Tiresias 的 val seen 一步 imagination 为 **FVD 274.0、SSIM 0.674、PSNR 20.351、LPIPS 0.242**；val unseen 为 744.9、0.550、19.695、0.303。默认 128→8→1 推理延迟约 **36 s**，将 shortlist 改为 2 个可降到 9 s、SR 从 0.60 降到 0.55。论文明确写出：尚未在真实机器人上部署，物理控制效用仍未知。

**可复现性：**GitHub 有完整目录、训练脚本、下载脚本、测试和四域数据准备流程；但需要 Wan2.2-TI2V-5B、Meta DINOv3 ViT-L/16 权重访问，仓库没有本项目训练后的最终 checkpoint，不能把“有代码”写成“开箱即跑”。轻量验证可只做导航域 10% data_ratio、N=32→k=2，比较 random、Trajectory Ranker、Trajectory+Visual Ranker 的 SR/nDTW 与想象帧数，先不训练完整 Wan2.2。

**创新、局限与关系：**它把 LLM Agent 的语言规划、diffusion proposal、world-model imagination 和统一 benchmark 接起来，补足了 world model 论文常见的“只预测、不执行”缺口。局限是整体评分仍在仿真/离线数据，36 秒级延迟很难直接进入机器人闭环；跨域 action interface 的统一可能掩盖每个域的执行差异；val unseen 从 63 降到 51 说明来源外推仍是主要瓶颈。

**是否值得深入阅读：值得。**重点读 128→8 的候选保留率、视觉 ranker 是否真的带来超越 trajectory-only 的闭环收益，以及 36 秒想象成本能否通过小模型蒸馏或缓存降下来。

## 5. DexForesight: Grounding Dexterous Policies with Implicit Spatial Foresight｜P1

**作者与机构：**Zhongxi Chen、Yi Yang、Xinyi Chen、Mingzhe Ye、Yaping Li、Zhihong Liu、Congsheng Xu、Haonan Wang、Zhijie Deng；Sharpa Robotics、SJTU–Sharpa Joint Lab for Embodied AI、香港中文大学、复旦大学。论文与项目页于 **2026-11-08** 发布。[论文](https://arxiv.org/abs/2611.11166) · [项目页](https://dexforesight.github.io/)。

DexForesight 研究“策略是否可以在不生成未来视频的情况下保留空间预见”。训练阶段用约 **370 小时、60 个任务**的演示，另有约 100 小时由 stereo RGB 离线估计的深度；空间 world model 预测 3D hand-point motion 和视觉特征变化，显式利用手的运动学几何覆盖摄像头看不到的手指。训练完冻结 world model，把其 predictive queries 与策略 queries 对齐，部署时只保留策略，输入 RGB、语言和 robot state，不需要深度或未来解码器。

**结果：**11 个 DexJoCo 仿真任务从基线 **49.4% 提升到 60.5%**；三项真实灵巧手任务 **58.3%**，强基线 50.0%；推理开销仅 **1.3%**（230.4 ms 对 227.4 ms）。冻结策略特征上的 0.54 s 未来手位移线性探针误差从 QwenVLA 的 13.59 mm 降到 10.01 mm，降低 **26.3%**。作者还报告 query alignment 比直接加预测 head 更好（60.5% 对 53.1%）。未见第三方验证。

**局限与复现：**深度只在训练用，部署更简洁，但训练仍依赖离线深度估计、手部运动学和 Sharpa 专属平台；项目页和论文没有公开训练代码、权重或完整数据下载。轻量替代实验可在 20 个仿真任务上用公开手模型构造“深度训练/无深度部署”的 query alignment，对比 action-only、直接预测 head、query alignment 三组，并对遮挡手指和相机视角做受控扰动。

**是否值得深入阅读：值得作为 WAM→VLA 的桥接工作。**优先看“隐式预测知识”是否只在 probe 上存在，还是在长时接触任务和跨物体留出上真正改善动作。

## 6. BAT-WAM: Bridging Action and Touch in World-Action Models for Dexterous Hands｜P1

**作者与机构：**Dong Fang、Feixuan Huang、Yuanxin Zhong、Yuxiang Gao、Qi Song、Yunlong Wang、Xiaosong Jia、Yu-Gang Jiang；复旦大学、Rimbot、东南大学、清华大学。论文提交于 **2026-11-07**。[论文](https://arxiv.org/abs/2611.10967)。

BAT-WAM 处理触觉、关节状态和动作被遮挡或缺失时的 WAM 表征问题。它给 Touch 与 Action/Joint 分别学习 codebook 和 decoder，用 RGB 条件的连续 latent bridge 做双向关联；Touch 每手 196 tokens，Joint 8 tokens，RGB 用冻结 SigLIP 连续编码。静态目标包含 unimodal reconstruction、masked prediction、latent alignment、codebook matching 和 commitment loss；时序目标根据历史 Touch、历史 Joint、目标时刻 RGB 和历史动作预测未来 Touch。

**结果：**在 HTBench 完整遮挡条件，Action+Image 的 F-RMSE **0.0145**，HandTouch 为 0.0221，下降 **34.73%**；局部遮挡 H-RMSE **0.0137**，HandTouch 为 0.0224，下降 **38.87%**。未来触觉预测 RMSE **0.0157**，相对 HandTouch 降低 25.59%。真实 PiPER + Linker Hand L6 七任务、每任务 200 条演示，平均成功率 **79.3%**，OpenWAM-α 为 66.4%，OpenWAM-α+HandTouch 为 69.3%；未见物体/布局/姿态的 unseen 平均为 **54.5%**，两个基线为 42.0% 和 38.5%。这些是作者报告，尚无独立复现。

**局限与复现：**论文只给出方法、实验和硬件描述，未找到专属代码、权重或 HTBench 数据下载入口；全手触觉 glove、PiPER 和 Linker Hand L6 的传感器契约是重要依赖。轻量验证可用公开触觉模拟器或 2D taxel 数据，固定遮挡 mask，做 image-only、joint-only、image+joint 三组 masked completion，再用一个小型 action head 测接触任务成功率；不要把合成触觉重建称为 BAT-WAM 完整复现。

**是否值得深入阅读：值得作为跨本体对齐的 P1。**重点核对动作状态是否真的提供了触觉可预测信息，还是只在相同手型/相同物体分布上提供 shortcut。

## 7. WARP-JEPA: World-Model-in-the-Loop Amortized Rollout Planning for Frozen Hierarchical JEPAs｜P1

**作者与机构：**Junjie Li、Zhaojiacheng Zhou、Kaixiang Wang、Zihan Wang、QingSong Zhao、Jiong Lou、Jie Li；上海交通大学。论文与代码于 **2026-11-07** 发布。[论文](https://arxiv.org/abs/2611.10806) · [MIT 代码](https://github.com/hideinsewer/WARP-JEPA)。

WARP-JEPA 针对 H-JEPA 在线 gradient-descent planner 的两个问题：迭代优化占长时 episode **最高 97.7%** 的运行时间，低预测 cost 也不一定对应成功控制；同时长层级组合和底层两步规划的 horizon 不对称。方法冻结 world model，用 world-model-in-the-loop causal Transformer 做顶层多候选 proposer，用并行 residual MLP 做下层 proposer；训练目标结合 model-based rollout cost 与 best-of-K behavior cloning，一次批量验证候选。

**结果：**30 个冻结 H-JEPA 模型、Push-T/FourRoom/Visual AntMaze/OGBench Cube 四类 benchmark；长时任务端到端加速 **9.6–18.8×**，Cube 为 2.9–3.0×。代表性成功增益为 Push-T **+23.9 pp**、FourRoom **+16.7 pp**、Visual AntMaze **+33.3 pp**、Cube **+26.0 pp**。例如 Push-T L2 从 online GD 40.8% 到 TM 64.7%，AntMaze L2 从 45.3% 到 78.7%。代码含 CPU unit tests、环境锁定、checkpoint manifest 和 held-out task 生成脚本，但论文实验使用单张 NVIDIA H200、CUDA 12.8、MuJoCo 3.14，依赖上游 H-JEPA/LeWorldModel 资源。

**局限与轻量验证：**这是高质量的 planner 复用和效率工作，不等于 world model 本身更准确；成功收益可能来自 proposer 的行为先验和更好地逃离 online GD 局部极小。先运行 CPU tests，再只复现 Push-T L2 的 10 个任务，比较 online GD、MLP proposer、Transformer proposer 的速度、成功率和候选数量；不重训 30 个模型。

**是否值得深入阅读：值得作为效率线 P1。**优先看成功提升来自 world-model cost、best-of-K 监督还是候选结构，及在更短 horizon 或真实机器人上是否仍成立。

## 8. REINS: A Self-Evolving Agent Harness for Real-Time Trajectory Planning｜P1

**作者与机构：**Zhihong Cui、Hengyu Liu、Haoran Tang、Amir Taherkordi、Tor Skeie、Shijun Liu；奥斯陆大学、奥尔堡大学、香港理工大学、山东大学、Simula Research Laboratory。论文于 **2026-11-07** 发布。[论文](https://arxiv.org/abs/2611.10748) · [代码](https://github.com/ZhihongCui/REINS)。

REINS 把软件 Agent harness 的三种耦合搬到实时轨迹规划：**grounding**（LLM 规则对齐到变量级 learned dynamics）、**verification**（把规则编译成 calibrated predicates 并做 H-step rollout）、**consolidation**（用 Neo4j indexed rule memory 按变量检索，O(log n) 返回熟悉场景规则）。新场景才调用 LLM，验证通过后写回记忆；熟悉场景不再调用 LLM，因此自演化发生在规则记忆而不是 LLM 权重。

**作者结果：**仿真和 highD/rounD replay 的 tactical decision layer 上，compliance **98%+**，规划延迟 **1.9–4.6 ms**，相对最佳 learned baseline 碰撞率下降约 **49–56%**。Highway 1000 episode 中规则记忆从 88 增到 145，LLM call rate 从 70.0% 降到 **12.81%**，compliance 从 0.9885 到 0.9956，collision rate 从 7.05% 降到 5.67%；100,000 条规则时检索仍低于 0.8 ms。论文还报告在 2.5–10% 观测噪声和 5% frame drop 下，REINS collision rate 最高约 8.14%，但这些仍是作者设定的仿真/回放条件。

**局限、复现与价值：**它的 perception 被假设为干净的 factored variables，真实世界部分是 replay，不是完整感知—规划—控制闭环，不能称为可部署 AV stack；LLM 使用 GPT-4o temperature 0，成本和服务可用性也未被报告。代码、配置、数据脚本和 Neo4j schema 已公开。轻量验证可换成本地小模型，只让它提出 20–50 条规则，再做 schema 校验、rollout verification、memory hit/miss 三组 100 episode 对照，报告规则调用率、误拒绝、冲突和延迟。

**是否值得深入阅读：值得作为 Agent/self-evolution 主线。**重点是把“记忆增长”“规则覆盖”“外部验收不变”分别报告，避免把调用次数下降直接写成模型能力自我提升。

## 9. Spatial Harness: Grounding Spatial Reasoning in Executable World States with Physics Engines｜P1

**作者与机构：**Chentao Cao、Zhanke Zhou、Sangni Duan、Bo Han；TMLR Group、香港浸会大学计算机系；Hang Li，ByteDance Seed。论文于 **2026-11-08** 发布。[论文](https://arxiv.org/abs/2611.11344) · [代码占位仓库](https://github.com/tmlr-group/Spatial-Harness)。

Spatial Harness 把空间推理拆为 Perceiver 和 Reasoner：Perceiver 从问题和视觉估计中建立对象/相机的共享坐标，把场景写成显式可执行 world state；Reasoner 在 physics engine 中执行视点变化，用计算出的测量和渲染视图回答问题。它覆盖 MindCube、SAT、MMSI-Bench、SpatialRGPT-Bench，目标是解决“模型读对了场景但想象的视角变换不满足几何/物理约束”。

**作者结果：**MindCube 上 Qwen3.5-27B 从模型内部推理 **52.70%** 提到 **71.14%**，比 pySpatial 高 7.52 个百分点；当对象和相机位姿使用同一标注输入时，显式执行达到 **98.25%**，模型内部推理为 71.81%。这些结果说明执行式状态有价值，但也说明标注位姿质量会显著影响上限。

**证据边界：**论文摘要写“代码公开”，但本轮核到的仓库只有 README，内容为“paper and code will be released within a month”；因此当前应标为 **论文可读、代码未闭合**。这与上一期曾出现的 `SpatialHarness`（arXiv:2610.12457、实时机器人操作脚手架）是不同作者和不同任务，不能合并去重。轻量验证可用 PyBullet/MuJoCo 构造 20 个对象—相机位姿，比较 VLM 内部推理、显式状态测量、显式状态+渲染三组，加入位姿扰动和遮挡，报告几何答案准确率与状态构建失败率。

**是否值得深入阅读：值得作为 Spatial Intelligence 评测接口。**优先追踪仓库落地、自动位姿估计误差和执行式状态能否迁移到机器人规划，而不是只看 MindCube 的高分。

## 今日研究机会与轻量验证

1. **跨本体数据与目标的四因素实验。**用公开小型 VLA 或 GR00T N1.7，在 20 个任务上固定控制器和推理预算，只改变人类视频比例、机器人数据比例、未来视频/动作联合目标和事件记忆。报告 zero-shot、1-shot、5-shot、失败类型与推理延迟，避免把更大数据量直接当成更强机制。

2. **“预测好”是否真的帮助控制。**用 ObjectWorld 的 full-object flow、Tiresias 的 imagined future 和一个直接行为克隆策略，统一接入同一末端控制器。先在仿真做 30 个 rigid/deformable 任务，再在 5 个真实任务上做 10 次重复；同时记录 EPE/SSIM、接触误差、轨迹偏差和成功率，检验预测指标是否能预测动作收益。

3. **触觉缺失的因果审计。**在 BAT-WAM 风格的 mask 下做 image-only、joint-only、image+joint、image+joint+future-touch 四组。用同一演示、同一 action head、同一推理频率，分离 tactile reconstruction、contact detection 和最终 success，不把触觉重建分数直接当作控制能力。

4. **规划效率与自演化的联合曲线。**WARP-JEPA 测 proposer 数量与 world-model rollout 数，REINS 测规则记忆大小与 LLM miss rate；共同报告每成功 episode 的 GPU/LLM 成本、延迟、失败恢复和外部验收。建议先用 CPU unit tests、10–20 个任务和本地小模型，确认接口后再上 H200/GPT API。

5. **可执行状态基准。**用 Spatial Harness 的对象—相机显式状态构造 20 个受控干预：遮挡、视角变化、物体位姿噪声、摩擦/重力变化。比较 VLM 内部推理、显式测量、physics-engine 渲染三组，分别报告状态解析错误、执行错误和任务答案错误；这比只报最终准确率更能解释 gap。
