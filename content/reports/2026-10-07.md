## 今日精读顺序

今天我建议的精读顺序是：

**A → [OpenWAM](https://openwam.stanford.edu/)**：有公开代码和预训练权重，能先建立统一的 VTA/Joint/Decoupled WAM 对照面，再谈结构创新。

**B → [DepthWorld](https://arxiv.org/abs/2610.08780)**：把相机标定、深度、点图和动作条件放进同一个 3D world model，直接对应空间一致性这个核心瓶颈。

**C → [World Models’ Last Exam in Physics](https://arxiv.org/abs/2610.08791)**：先确定怎样测“看起来对”与“物理上对”的差别，避免只用 VLM 打分推动模型迭代。

**D → [ViDAL](https://arxiv.org/abs/2610.08150)**：冻结视频表征、只改 action latent，适合在有限算力下验证动作表示是否真的携带视觉动力学。

**E → [RIWANav](https://arxiv.org/abs/2610.08640) + [VeriFine](https://arxiv.org/abs/2610.08761)**：前者研究世界模型与策略互相改进，后者研究验证器如何跟着策略变强，合起来是自进化闭环的两侧。

## 重点论文 / 模型 / 项目

## 1. OpenWAM: An Open Framework for Composable World-Action Models｜P0

**作者与机构、时间、性质。** Heng Yu、David D. Yuan、Juze Zhang、Changan Chen、Yao Feng、Michelle Baldonado、Steve Cousins、Li Fei-Fei、Jiajun Wu、Ehsan Adeli，Stanford University；项目页和论文版本在 2026-10-06 更新，属于官方项目页 + arXiv 预印本 + 开源研究软件。入口：[项目页](https://openwam.stanford.edu/)、[论文](https://arxiv.org/abs/2610.07922)、[GitHub](https://github.com/OpenWAM/OpenWAM)、[Hugging Face 权重](https://huggingface.co/OpenWAM-Stanford/OpenWAM-Pretraining)。

**问题与方法。** 现有 WAM 往往把视频模型、动作头、训练数据和推理顺序绑在一起，难以判断性能究竟来自哪一个设计。OpenWAM 从 Wan2.2-5B 出发，用超过 10,000 小时机器人/人类视频与约 334 万条轨迹做因果 robot-video 预训练；模型由 5B video expert 与 2B action expert 组成共享 Mixture-of-Transformers，支持 video-then-action、action-then-video、joint 和 decoupled 四种组合。训练目标同时覆盖因果视频预测、动作建模以及反事实片段上的 IDM/FDM 一致性。

**证据与结果。** 官方报告 VTA 在 LIBERO 平均 98.6%，LIBERO-Long 97.8%，双臂 VTA/Joint 约 92%；因果 robot-video 预训练让 LIBERO-Long 从 68.4% 升到 97.8%。LIBERO-Long-CF 约 32k 反事实片段显示，局部上下文 IDM 在 held-out LIBERO-90 达到 84.0%，而 full-context 为 47.0%、仅示范为 21.5%；FDM RGB MSE 下降 34.5%，16-way outcome identification 从 21.1% 升到 71.3%。这些都是作者/官方结果，尚未看到第三方复核。创新在于把 WAM 变成可组合的实验平台；局限是 alpha 软件、公开权重是视频预训练 checkpoint 而不是可直接部署的 action-finetuned policy，长时 rollout 仍可能漂移。相对 PointWAM/XGenAct 等单一训练范式，它更适合做结构消融和因果归因；非常值得深读。

**可复现性与轻量验证。** GitHub 为 AGPL-3.0，提供训练/评测/模拟适配器；HF 权重约 20.4 GB，含配置和校验文件，但不含优化器、完整数据和前端资产。先按 README 的 CPU sanity check（`openwam-validate-config`、`openwam-sanity --device cpu --max-batches 1 --rollout-steps 1`）确认环境，再在单卡上只取 LIBERO 少量任务比较 VTA、Joint、Decoupled，并复现 IDM/FDM 的反事实指标，成本远低于重新做预训练。

## 2. DepthWorld: 3D World Model for Robot Manipulation｜P0

**作者与机构、时间、性质。** Jai Bardhan、Josef Sivic、Vladimir Petrik，Czech Institute of Informatics, Robotics and Cybernetics, Czech Technical University in Prague；2026-10-06 提交，CoRL 2026 accepted 的 arXiv 论文，项目链接在论文页中给出：[论文](https://arxiv.org/abs/2610.08780)、[HTML/方法细节](https://arxiv.org/html/2610.08780v1)、[项目页](https://www.jaibardhan.com/depthworld)。

**问题与方法。** RGB-only 视频世界模型可以逐帧逼真，却未必保持跨视角几何和机器人基座坐标的一致性。DepthWorld 先用立体深度和 joint factor graph 汇总每台机器人的所有 episode，恢复共享运动学与外部相机位姿；数据来自 DROID-3D 的 71,100 个场景、28 台机器人、13 个实验室，90% 外部相机 episode 的重投影误差低于 0.7 像素。模型基于 Stable Video Diffusion，使用空间 latent tiling 联合预测多视角 RGB 与 depth，不改 SVD VAE，并增加机器人基座坐标系中的 DPT point-map head；训练先 40k steps 联合 RGB-depth，再用 50k steps 加强 point-map loss，动作条件来自 Ctrl-World。

**证据与结果。** 在同一 RGB-only baseline 上加入深度监督，PSNR 提升 1.48 dB，并改善 metric depth 与几何一致性；这是作者报告，尚无第三方验证。创新是把“标定—深度—点图—动作条件”连成可检查的空间链条，补上 Ctrl-World 及其他 action-conditioned video WM 缺的 3D 约束。局限是训练重、对多相机标定质量敏感，论文/项目页未确认公开权重或完整 DROID-3D 下载包；相对 DUSt3R/MaSt3R/VGGT，它不是通用重建器，而是把几何监督嵌入机器人 world model，值得深读。

**可复现性与轻量验证。** arXiv 源码和项目页可读，DROID 原始数据可获得，但当前未核实官方 checkpoint。可先标定 1–5k 个 episode，在小型 SVD/Wan adapter 上加入 depth/point-map 辅助损失，用跨视角重投影误差、深度误差和简单 push 规划成功率做三重检查；不要一开始复刻 90k steps 全量训练。

## 3. World Models’ Last Exam in Physics｜P0

**作者与机构、时间、性质。** Mingju Gao、Qingle Liu、Yuzhao Peng、Xinjie Lin、Ziming Qin、Zheng Jiang、Wenyi Li、Calvin Xiao、Youjie Zheng、Kaisen Yang、Qinhuai Na，Navers Lab、Einsia.AI、Peking University、Tsinghua University；2026-10-06 arXiv 预印本，配套项目页：[论文](https://arxiv.org/abs/2610.08791)、[HTML](https://arxiv.org/html/2610.08791v1)、[项目](https://lab.einsia.ai/phys-last-exam)。

**问题与方法。** 过去的 world-model 评测常依赖 VLM 主观判断或只测单一力学公式，无法回答“视频看起来像真的，但接触、守恒或相变是否真的正确”。该工作构造 40 个受控任务，覆盖力学、光学、流体、热/相变、电磁、表面张力、颗粒介质等；每个任务有可观测性筛选、任务专属的可测物理量和 CoTracker3/SAM2/测量程序，不需要参考视频。

**证据与结果。** 8 个视频模型、1,280 个视频的作者评测中，最高总分为 57.76/100；测量型 evaluator 与人类判断的一致性高于直接 VLM baseline，合成的已知物理视频也能验证测量模块。结果尚无第三方复核。创新不在再做一个模型，而在把物理一致性变成可复算残差；局限是 40 个任务仍覆盖不了开放世界接触、遮挡和长时控制，项目页当前未明确完整 benchmark code/data 的下载状态。它与 WorldArena 等行动/世界模型评测互补，建议作为所有新 WAM/WM 的先验门槛，值得深读。

**可复现性与轻量验证。** 先实现自由落体、摆周期和滚动三个合成任务，比较 VLM judge 与测量残差，再把 OpenWAM/DepthWorld 的短 rollout 接入；若两者排序不一致，优先报告物理 failure mode，而不是调参追分。

## 4. Building Rome from a Single Image｜P1

**作者与机构、时间、性质。** Jiraphon Yenphraphai、Fang Li、Tianshuo Xu、Depu Meng、Quentin Herau、Yihan Hu、Raymond A. Yeh、Wei Zhan；2026-10-06 arXiv 预印本，机构在当前解析的 arXiv 页面未完整暴露，项目链接为 [论文](https://arxiv.org/abs/2610.08790)、[HTML](https://arxiv.org/html/2610.08790v1)、[项目页](https://build-rome.github.io/)。

**问题与方法。** 单张图重建常在未观测表面、远近尺度和户外场景上失败。作者重做 Trellis2 的场景生成管线：近处用小的 adaptive physical chunks、远处用大的 chunks；将 DINOv3 特征、point map 和 free-space/observed/unknown visibility 显式对应起来，并用 agentic pipeline 生成约 4,000 个户外合成场景。训练约 100k AdamW steps、16 张 A100，新模块学习率 1e-4、LoRA 3e-5，数据包含 SAGE-10k 与户外合成场景。

**证据与结果。** 作者报告在 Tanks&Temples 上相对最强 baseline Chamfer 降 24%、F1 提升 30%；在 121 个 in-the-wild 样本上 pairwise preference 至少 73%；adaptive chunking 比固定 chunk 快约 3×。这是空间智能方向的关键补充，但尚无代码/权重确认，4,000 场景生成管线也较重；结果仍主要是离线几何指标，尚未证明能提升机器人闭环任务。它和 World Labs Atlas/Marble、HY-World 处在同一空间重建趋势上，却更接近可导入 simulator 的单图到显式场景，值得以 P1 深读。

**轻量验证。** 用公开 Trellis2 或其他开源 3D generator，在 1–2k 合成室内/户外场景上只复现 adaptive chunk 与 visibility loss；把重建结果导入仿真，增加可 traversability 和机器人导航成功率，而不只报告 Chamfer。

## 5. ViDAL: A Visual Dynamics-Grounded Action Latent Space for VLAs｜P1

**作者与机构、时间、性质。** Yuan Xu、Yixiang Chen、Qisen Ma、Jiabing Yang、Peiyan Li、Kai Wang、Jianhua Yang、Jianlou Si、Jun Huang、Jing Liu、Nianfeng Liu、Yan Huang、Liang Wang；2026-10-06 arXiv 预印本：[论文](https://arxiv.org/abs/2610.08150)、[HTML](https://arxiv.org/html/2610.08150v1)。

**问题与方法。** 原始 action chunk、离散 action token 和连续 latent 通常只要求重建轨迹，却没有约束“这个动作会带来什么视觉变化”。ViDAL 训练 Action VAE 重建 action chunk，并把 latent 对齐到冻结 Wan VAE/video model 的未来视觉 latent；训练后冻结 Action VAE，作为 regression 或 flow-matching VLA 的 plug-in action interface，推理时不再调用视频模型。

**证据与结果。** 作者报告 LIBERO 平均 98.1%；相对 OpenVLA-OFT 小幅提升 0.3、相对 pi0.5 提升 1.2；RoboTwin2.0 对 pi0.5 Clean/Random 提升 11.2/9.9 个百分点，对 StarVLA-OFT 提升 4.2/1.8；真实单臂 Franka 和双臂 ARX 绝对提升 20.0/23.4。创新是把视频动力学作为 action target 的训练约束而非部署依赖，局限是结果仍来自作者的基准和真实机器人实验，公开代码/权重尚未确认；它与 FAST/OAT 等 action token 化路线正交，很适合轻量复现实验，也值得深入阅读。

**轻量验证。** 冻结 Wan VAE，只在少量 LIBERO/RoboTwin 训练 Action VAE，匹配 batch、参数量和 action horizon，对比 raw action、FAST/OAT 与 ViDAL latent；额外做“latent→未来视觉变化”的线性 probe，确认提升不是单纯正则化。

## 6. EgoLAP: Learning from Egocentric Human Data through Language-Action Reasoning｜P1

**作者与机构、时间、性质。** Lihan Zha、Shresth Grover、Tenny Yin、Samuel M. Bateman、Hengkai Pan、Mengchao Zhang、Aykut Onol、Allen Z. Ren、Dhruv Shah、Anirudha Majumdar；2026-10-06 arXiv 预印本，项目页为 [EgoLAP](https://ego-lap.github.io/)，论文入口 [arXiv](https://arxiv.org/abs/2610.08726)。当前解析页面未完整显示作者 affiliations，因此不补写未经核实的机构名称。

**问题与方法。** 人类第一视角视频量大，但人体动作与机器人关节动作存在 embodiment gap。EgoLAP 把人类与机器人轨迹放进同一个 VLA 预训练任务，用语言化的 action chain-of-thought 表示时间抽象的 motion intent，再用几何、物理和 affordance 做 motion-level reasoning；推理时只保留轻量 action expert，语言目标作为辅助监督而不是逐 token 自回归动作。

**证据与结果。** 作者报告真实任务平均 progress 80.1%，比替代 action representation 高 2.3×；仿真成功率 38.3%，motion-level reasoning 单项带来 35.6 个百分点，加入人类数据使 sim success 从 7.2% 升至 16.4%；相对 ABC-VLA 在 sim/real 分别高 16.9/54.5 个百分点。尚无第三方复核，公开权重/数据/代码未确认；语言中间层可能把几何误差隐藏在“合理描述”里，且当前对比基准不等于通用 WAM。它延伸 Language-Action Pretraining，但不同于 FAST/OAT 的纯编码，适合在人—机器人跨本体对齐方向深读。

**轻量验证。** 从 Ego4D 与一个小型 robot dataset 各取同类任务，标注短语言动作和接触/目标几何；在 1–2 个 YAM 或双臂仿真任务上做 no-reasoning、语言 reasoning、FAST/OAT 三组对照，分别报告成功率和 embodiment shift 下的失败类型。

## 7. RIWANav: Recursive World–Action Models with Self-Improvement for Urban Navigation｜P1

**作者与机构、时间、性质。** Jing Xie、Shouwei Ruan、Yubin Wang、Yuxiang Zhang、Haitao Yang、Songchang Jin、Dianxi Shi；2026-10-06 arXiv 预印本：[论文](https://arxiv.org/abs/2610.08640)、[HTML](https://arxiv.org/html/2610.08640v1)。

**问题与方法。** 长时导航会累积误差，纯 imitation learning 学不到失败，物理 RL 又昂贵；冻结 world model 也会在策略变强后过时。RIWANav 交替执行两个循环：world model 对多个候选动作预测未来视频，用相对质量给 GRPO 反馈；更新后的策略产生 action-video pairs，再保留 expert-consistent 样本、按行为新颖性和当前预测误差采样，继续更新 world model。实现基于 Cosmos 的条件视频目标。

**证据与结果。** 作者报告 UrbanNav test-seen SR 89.92、SPL 86.87，unseen SR 88.25、SPL 82.59，并给出 NE、nDTW、SDTW、OSR 等指标；结果来自三次 seed 的作者实验，未见第三方验证。创新是让 WM 与 policy 共同进化，而非把 WM 只当 frozen simulator；局限是 Cosmos 计算量、导航场景特化、代码/权重尚未确认，真实机器人声明仍需独立复核。它和模型式 RL、POET 的关系是“把可视化 action-conditioned WM 放进递归数据环”，值得与 VeriFine 组合阅读。

**轻量验证。** 用小型预训练 action-conditioned WM 或离线 UrbanNav，在低分辨率上只跑 1–2 轮 RSI；比较 frozen-WM、policy-guided replay、novelty/error replay 三组，重点记录 held-out route 的 rollout calibration、失败恢复和数据多样性，而不是只追 SR。

## 8. AutodidactWAM: Cross-Modal Self-Distillation from Generated Video to Robot Actions｜P1

**作者与机构、时间、性质。** Sergei Kurchev、Iaroslav Kolomiets、Miguel Altamirano Cabrera、Artem Lykov、Dzmitry Tsetserukou，Skolkovo Institute of Science and Technology 与 MWS R&D Center；2026-10-06 arXiv 预印本、ICRA 2027 submission：[论文](https://arxiv.org/abs/2610.08119)、[HTML](https://arxiv.org/html/2610.08119v1)。

**问题与方法。** Cosmos 3 WAM 在未见过的 Unitree G1 + BrainCo 五指手上，生成视频看似合理，但共同生成的 native action 会错位。AutodidactWAM 用 RoboHaMeR 手部姿态和 IK 从生成视频恢复 action，把 recovered action 作为偏好目标，只更新 action layers，并比较 SFT 与 rectified-flow Diffusion-DPO；最终使用 DPO+SFT+DTW 的混合策略，不依赖持续 teleoperation。

**证据与结果。** 作者报告 native action 的 pre-grasp/grasp/pick-place 成功约 17/10/7%，视频恢复 action 的 gate 约 75/47/42%；在 Oreo 任务上混合训练后 pre-grasp 90%、完整任务 20%，held-out 为 80/30%，而 plain Flow-DPO 尽管 preference accuracy=1.0 仍出现 0% 成功。结果是作者的真实机器人实验，无第三方验证。创新是用视频作为跨模态 teacher 修复 action branch，局限是硬件、RoboHaMeR/IK 和 Cosmos 依赖重，完整任务收益仍低；它和 OpenWAM 的“共享基底”互补，适合做 action causality 的失败分析，值得作为 WAM 跨模态对齐案例深入阅读。

**轻量验证。** 先在仿真或公开 WAM checkpoint 上合成手部 pose，训练逆动作提取器，做离线 self-distillation 与 teacher-forcing；只有当 recovered action 在几何误差和 contact outcome 上优于 native action，再上真实 G1，避免把硬件失败误判成算法收益。

## 9. VeriFine: Scaling Verification for Self-Improvement in Embodied Reasoning｜P1

**作者与机构、时间、性质。** Zewei Zhou、Rachel Luo、Yulong Cao、Chaowei Xiao、Chensheng Peng、Boyi Li、Thomas Tian、Zheng Lian、Yan Wang、Jiaqi Ma、Boris Ivanovic、Marco Pavone、Wenhao Ding，NVIDIA、UCLA、UC Berkeley、Stanford；2026-10-06 arXiv 预印本与项目页：[论文](https://arxiv.org/abs/2610.08761)、[HTML](https://arxiv.org/html/2610.08761v1)、[项目](https://veri-fine.github.io/)。

**问题与方法。** 固定 judge 会在 policy 变强后成为瓶颈，尤其是空间、因果和安全性判定。VeriFine 把系统拆成两个耦合环：Policy Improvement Loop 用 rubric judge 诊断失败、调 curriculum 并优化 policy；Judge Improvement Loop 在性能平台期引入选择性人类指导和 coactive calibration，更新 judge，再继续训练 policy。评估覆盖 driving 与 robot navigation 的 RFT/SFT。

**证据与结果。** 作者报告 reasoning 分数从 base 的 60.56/68.05，经三轮 reference-free judge 升到 71.61/83.13；judge 与 human teacher 的相关系数由 0.55 升至 0.85，最终 student 为 0.82、MAE 0.17，策略最终 reasoning 从 68.09 升至 77.59（+14%）。结果全部为作者报告，数据、judge backbone 与部分教师系统的开放性有限，未见第三方验证。创新是把 verifier 也作为可学习对象；局限是 calibration 成本和 rubric 迁移性，且 judge 变好不等于真实物理成功变好。它与 RIWANav 的关系是“RIWANav 改 WM-policy 数据环，VeriFine 改 judge-policy 评价环”，值得合读。

**轻量验证。** 用开源 VLM judge 和小型 robot-nav dataset，先固定 rubric，再做两轮 failure taxonomy、judge-guided curriculum 与 coactive correction；除 success 外报告 judge-human correlation、误报安全事件和新路线上的 calibration，才能证明是验证器进步而不是评分器自嗨。

## Spatial Intelligence / Frontier 扫描

## 今日研究机会与轻量验证

1. **几何—动作联合的最小可证伪实验。** 用 OpenWAM 预训练权重和 DepthWorld 的 point-map 思路，在 1–5k DROID/LIBERO 片段上只加深度与未来视觉对齐损失；以跨视角重投影、action-conditioned outcome identification 和真实/仿真成功率三项共同决定 go/no-go。

2. **物理门控而非“看起来像”。** 从 Last Exam 选自由落体、摆和滚动三个任务，先用合成视频校准测量器，再把同一测量器应用于 OpenWAM/DepthWorld rollout；若 VLM 分数与测量残差冲突，把冲突样本做成训练集和 failure taxonomy。

3. **低成本跨模态 action 修复。** 采用 ViDAL 的冻结 Wan VAE 和 AutodidactWAM 的视频恢复 action，先在仿真里比较 native/recovered action 的几何、接触和未来帧误差；只有离线指标一致改善，才引入真实硬件。

4. **把自改进拆成两条可观测曲线。** 在 RIWANav 风格的离线导航上加入 VeriFine 风格 judge calibration，分别画 policy success、world-model calibration、judge-human correlation 和数据新颖性；这样能区分“策略变强”“模型变准”“评分器变宽松”。

## 证据状态与可复现性

- **强可复现入口：** OpenWAM 有公开 GitHub、AGPL-3.0 许可、CPU sanity path 和约 20.4 GB HF 视频预训练权重；WorldSolver 有公开代码和固定 solver scaffold。
- **部分可复现：** DepthWorld 有论文/HTML/项目说明，DROID 原始数据可获得，但当前未确认完整 DROID-3D 标定包和 checkpoint；Last Exam 有论文与项目页，但 benchmark code/data 的正式下载状态仍需人工核验。
- **主要是作者证据：** DepthWorld、Building Rome、ViDAL、EgoLAP、RIWANav、AutodidactWAM、VeriFine 的指标均来自作者实验；本轮未找到独立第三方复现或正式排行榜证据。
- **检索失败与筛选的区分：** broader-web 交叉核对后，未发现另一个同时满足窗口、影响力和一手证据要求的重大官方发布；WorldSolver、workshop challenge 和窗口外 Atlas/Figure/MIT 更新均已登记。其余低信号博客、二手榜单和无一手链接条目是选择性排除，不是用“筛选”掩盖漏检。
- **复现风险：** 大模型项目常把“预训练 checkpoint”“可部署 policy”“优化器/数据/硬件脚本”混称；今天只把 OpenWAM 的公开视频预训练权重称为权重，其他项目没有确认就标为未公开。所有大算力建议都先走单卡/低分辨率/小数据的物理和几何 gate。

今天先读 **OpenWAM → DepthWorld → Physics Exam**，建立可组合、可测量的基线；随后用 ViDAL 的冻结 action-latent 实验和三任务物理 gate 做第一轮轻量验证，再决定是否投入 RIWANav/VeriFine 的闭环自改进。
