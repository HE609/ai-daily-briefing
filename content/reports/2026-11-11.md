## 2. Steel — Scaling Simulation Across Robots, Tasks, and Worlds｜P0

**Skild AI 与 NVIDIA** 联合发布。官方仓库将开源日记为 **2026-11-09**，首个公开提交时间为当天 08:51 UTC。性质为物理求解器与代码发布，配套官方性能研究。Steel 面向同时包含不同机器人、关节规模、任务与接触结构的 GPU 仿真批次。[官方技术文章](https://www.skild.ai/blogs/steel) · [发布仓库](https://github.com/skild-ai/steel)

方法结合 **约化坐标关节动力学、Projected Gauss-Seidel 约束求解、关节空间质量矩阵分解复用**，按关节数量组织计算，并依据每个环境的接触负载分配工作。它作为 Newton 的求解器服务于机器人学习，优化目标是物理仿真的吞吐与内存效率。公开测试使用 Newton 1.8 release candidate，并启用 **reuse_kinematics=True**。

**官方在单张 RTX PRO 6000 Blackwell 上报告**，二十项任务的吞吐相对 PhysX 几何平均为 **3.8 倍**，相对 MuJoCo Warp 约 **1.3 倍**。二十任务异构混合的最优批量比较达到 **13.0 倍**。在双方同为 61,440 环境时，吞吐约为 361 万与 30 万 env-steps/s，显存约为 11 与 29 GiB。统计对象为 simulation-step throughput，训练收益还取决于渲染、策略更新与数据传输。[硬件、批量与测量条件](https://www.skild.ai/blogs/steel)

创新价值在于降低任务和本体多样性带来的 padding 与求解开销，这对跨本体基础策略和仿真课程很重要。物理误差、接触稳定性、不同批量和开关配置都需要配合速度评测。**值得精读并做小规模复跑**，本轮独立性能验证状态待核。

已核到 Newton 内的实际求解器、示例和测试，以及 WebGPU 实现，采用 Apache-2.0，资产另按来源授权。轻量验证可固定四种机器人任务、时间步、求解迭代和随机种子，在 64–1,024 环境下测吞吐、峰值显存、穿透、能量漂移，再比较达到同一策略成功率所需的墙钟时间。[Newton 求解器源码](https://github.com/newton-physics/newton/tree/main/newton/_src/solvers/steel) · [WebGPU 实现](https://github.com/skild-ai/steel-webgpu)

## 3. World In-Context Learning for Agentic Robot Manipulation — RoboScript｜P0

**Heng Fang、Zehui Guo、Yuehan Zhang、Mingyang Du、Dingkang Liang、Xiang Bai**，华中科技大学与 ArcheOne AI。预印本 v1 提交于 **11-09 18:59:45 UTC，即北京时间 11-10 02:59:45**。研究问题是，冻结的通用模型如何通过世界反馈，从一条示范形成能够部署到新场景的操作知识。[论文](https://arxiv.org/abs/2611.12885) · [项目页](https://ArcheOne-AI.github.io/RoboScript)

WICL 的链路为 **技能构建 → 示范初始化 Task Memory → 仿真 rehearsal 与记忆修订 → 冻结记忆部署 → 跨批次反思**。Agent 侧使用可部署的观测、几何与动作工具，控制平面持有训练期监督和官方验收。学习对象是可读任务记忆与指导规则，参数保持冻结。附录给出了模拟器信息隔离、坐标检查及练习停止条件，适合与 Reflexion 和经验驱动 Agent 学习共同阅读。

**作者结果**为 RoboTwin 2.0 五十任务、每任务每设置十回合，共一千个测试回合。GPT-6.1-Sol 的 clean/randomized 成功率为 **83.6% / 83.2%**，均值 **83.4%**。论文的最强训练策略比较项为 61.7%，适用其 clean-only 训练和表中基线范围。消融中，十任务上的完整部署流程为 78.5%，直接把示范写入记忆为 69.0%。真机四任务各十次，分别成功 **10、7、7、6 次**，使用仿真记忆适配后的离线动作计划。[论文与完整协议](https://arxiv.org/pdf/2611.12885)

最值得审查的是交互预算。Sol 平均每任务 rehearsal 约 12.5 个实例，部署每回合平均 **54.7 次模型调用、233 万 tokens**。五十任务学习加一千次评测，作者按标价估算约 1,911 美元。一条示范之外还包含世界交互、工具和基础模型先验。**值得精读，优先看信息边界、恢复与成本表**，独立复现状态待核。

Apache-2.0 仓库已包含 core、wicl/rsi/skill_builder、视觉服务及 RoboTwin 流程，真实机器人部署代码仍列在 TODO。模拟器资产和模型 API 需另行准备。轻量验证先用内置 Mock 检查状态流，再取三个任务，比较示范记忆、rehearsal、rehearsal 加反思三组，固定测试种子并计入全部练习、推理和失败成本。[代码与运行入口](https://github.com/ArcheOne-AI/RoboScript)

## 4. LingBot-Touch — Learning Heterogeneous Tactile Representation for General Dexterous Manipulation｜P0

**Bing Han、Yichuan Peng、Haoyu Dong 等，Robbyant 蚂蚁灵波团队**，项目负责人 Wei Ning。论文 v1 为 **11-09 18:12 UTC，北京时间 11-10 02:12**，伴随编码器与推理代码发布，同行评审状态待核。它研究压阻、磁式与视觉触觉传感器之间可迁移的接触表示。[论文](https://arxiv.org/abs/2611.12806) · [官方项目](https://technology.robbyant.com/lingbot-touch)

模型将 taxel 的位置映射到 **canonical fingertip geometry**，以模态专属 tokenizer 接入共享 Haptic Transformer，通过 Tactile-JEPA 预测被遮蔽时空区域的潜表示，并使用 EMA target、布局与信号增强。预训练语料为 **4,983 小时、464,431 episodes、约 13.3 亿帧**。下游冻结编码器，通过 attention query 接入现有策略，HaT-Tiny 约 546 万参数。

**作者真机实验**涵盖两种手、二十六任务，报告每任务二十次试验。主控制表使用 **4K 小时预训练的 Tiny**，LingBot-VLA 的平均成功率从 **48.3% 提高到 73.1%**，π0.5 从 **48.1% 到 69.9%**。十二项仿真 RL 任务报告三种子结果。语料总规模、4K 主表与额外 5K 缩放实验应分别记账。[实验表与训练设置](https://arxiv.org/pdf/2611.12806)

它把 JEPA 的表示预测推进到异构触觉，与 BAT-WAM 的未来触觉—动作联合预测可以组成互补研究问题。局限包括电容传感器覆盖、掌面接触不足，以及跨传感器几何和信号规范的依赖。**值得精读并优先做公开权重验证**。目前所列控制收益来自作者实验，第三方任务复跑待核。

已核到 Tiny/Small 的 config.json 与 encoder.pt，HF API 显示公开且无 gating，权重约 21.9/87.1 MB。仓库公开冻结编码器推理、传感器适配及样例，完整预训练语料和训练链交付待核。轻量实验可用两类样例做固定编码器 probe，比较原始触觉、CNN 和 JEPA 特征，并独立扰动 taxel 布局及标定误差。代码与模型卡采用 Apache-2.0。[代码](https://github.com/Robbyant/lingbot-touch) · [Tiny 权重](https://huggingface.co/robbyant/lingbot-touch-tiny) · [Small 权重](https://huggingface.co/robbyant/lingbot-touch-small)

## 6. WanderBench — Can World Models Explore Dynamic Worlds from Video?｜P0

**Yuhang Chen、Jiheng Li、Jiale Wang、Zai Wang、Guangyue Liu，华中科技大学**。v1 提交于 **11-09 15:23:53 UTC，北京时间 11-09 23:23:53**。性质为视频条件世界探索基准与免训练方法预印本。它把“探索一个已记录的动态世界”作为独立空间智能问题，要求保留人物身份、事件进程和返回地点时的当前状态。[论文](https://arxiv.org/abs/2611.12557)

基准包含 **745 段真实及生成单镜头视频，长度 3–25 秒**，用键盘动作定义相机路径，以六个维度、二十四个子指标评估输出。生成帧与源视频按同一事件时间对齐。WanderLand 将同一时刻的源帧持续输入冻结模型，并在重访时复用此前的静态内容，目标是同时维持源动态与空间记忆。[评测与机制](https://arxiv.org/html/2611.12557v1)

**作者测试八个模型**，五个受长度限制的模型按可生成的前缀计分，Medium/Hard 主要比较三个全长度模型。Hard 层的平均源动态保真分约 **37.2/100**，动态重访也是共同弱项。WanderLand 在五个模型的六维度上均有提升，源动态保真最大提高 **8.3 分**。这些是该基准中的作者测量，指标与机器人闭环成功之间仍需建立实证联系。

相对 VBench、WorldScore 等工作，它新增了源视频事件时间和动态返回的明确约束。本报认为，这能识别长期生成中的“场景仍像原处、事件已偏离”的失败。局限包括 VLM/几何估计器参与评分、真实与生成源视频混合，以及不同模型可评时长的差异。**值得精读，适合用于评测设计**。[结果表与评测条件](https://arxiv.org/html/2611.12557v1)

本轮尚未核实本论文专属代码、完整视频集和评分包的稳定下载入口，第三方复跑待核。轻量验证可先制作二十条有已知事件时间的路线，包含离开、遮挡、返回和物体状态改变，分别标注主体身份、相机路径、事件时序和返回状态，再与感知质量分数比较。用公开小型视频模型测试源帧条件和重访记忆两个开关即可开始。

## 8. Compass 1 — Open-World and Persistent Embodied Navigation｜P1

**Hai Zhang、Siqi Liang 等**，香港大学、上海创智学院、Archon Robotics、Spatial Robotics 与华为。论文 v1 提交于 **11-09 09:04:48 UTC，北京时间 11-09 17:04:48**，项目公告日期为 11 月 10 日。它研究单目 RGB 导航中的长时历史使用、开放环境探索与回到过去目标的能力，同行评审状态待核。[论文](https://arxiv.org/abs/2611.12087) · [项目页](https://www.yuance.ai/research/compass1)

核心为 **稀疏关键帧加 History Representation Map**，再用任务阶段、探索一致性、时空目标检索三类 VQA 激活历史。统一 backbone 联合学习语言、视频生成和连续动作，VQA、视频与动作损失权重为 **3∶1∶1**。动作标签由单目几何和尺度估计构造。训练使用 500 多小时自采视频、2,000 多小时网络视频，作者配置为 32 张 H200、六万步。

**作者开放环境评测**为八类任务、四种场景、每项十次，共 320 次，整体成功率 **79.4%**，最强基线 **17.8%**。持续历史回溯任务约 **58%**。R2R Val-Unseen 的单目 SR 为 **70.1%**，属于另一评测协议。跨本体展示覆盖轮式、四足、人形与无人机，需分别核对每种平台的试验数量。[论文实验与协议](https://arxiv.org/pdf/2611.12087)

它承接 NaVid、WNM-3D 等导航路线，把世界生成、空间图和历史检索联合使用。本报建议优先看 HRM 与 VQA 的消融。推理速度按一次动作 chunk 折算，十二动作在 0.43 秒内生成对应约 28 个预测动作/秒，持续观测与控制的端到端频率仍需独立计量。**值得精读长时状态机制**。

资源状态需要保留时间边界。官方仓库目前主要为论文、README 和媒体，数据、部署代码与真机 checkpoint 的计划时间均为 **2026 年 12 月**。轻量验证可在现成导航模型上比较最近帧、均匀历史、关键帧、关键帧加显式地图四组，加入方向与里程误差，测回溯成功、错误身份检索和总时延。[代码仓库与交付计划](https://github.com/OpenDriveLab/Compass1)

## 10. InfraRSI — Harnessing Recursive Self-Improvement for Training Infrastructure｜P1

**InfraRSI Team，Yuchuan Tian、Haocheng Mei 等**，TokenRhythm Technologies、北京大学、Infinigence AI、上海交通大学与清华大学。v1 提交于 **11-08 18:59:37 UTC，北京时间 11-09 02:59:37**。这是训练系统优化 Agent 的预印本与代码发布，研究对象包括启动配置、算子、通信与跨硬件经验迁移。[论文](https://arxiv.org/abs/2611.11558)

五阶段流程为 **init、doctor、run、report、apply**。固定工作负载、数值与计时契约，联合搜索配置和源码改动，将 OOM 纳入峰值内存模型，并用全部试验校正运行时间预测和 LLM 速度先验。最优候选重新与原始基线配对测试，验证后的经验写入跨硬件记忆。学习目标是受约束的运行效率和经验更新。

**作者四个 dense/MoE 训练工作负载**覆盖 8×H100、8×H200 与双节点 16×H100。几何平均加速为 **1.83 倍**，最大值 **2.75 倍**，平均 MFU 从 **17.4% 到 30.0%**。作者还审计 1,212 条执行记录与十六项验收不变量。最大加速、平均加速、失败搜索成本和最终训练吞吐需要分别统计。[实验与验证器](https://arxiv.org/html/2611.11558v1)

它延伸 AlphaEvolve、RE-Bench 和配置调优路线，将有价值的系统改动、失败信息和跨 GPU 经验纳入搜索。局限是四种训练负载的覆盖范围、数值容差的充分性，以及优化成本何时能由后续训练节省摊平。**值得读验证与经验迁移设计**，本轮第三方性能复现待核。

已核到实际 harness、verifier、测试与 toy_cpu 示例。公开仓库的整体许可条款仍需进一步核对，完整论文实验轨迹和依赖环境也需逐项验收。轻量验证先在 toy CPU 任务检验工作量、损失与计时约束，再在单 GPU 小模型上设置固定搜索预算，报告搜索总成本和加速的盈亏平衡点。[代码与示例](https://github.com/TokenRhythm/InfraRSI)

## 今日研究机会与轻量验证

- **优先做动态重访评测**。构造二十个带事件时间的场景，包含物体移位、状态改变和遮挡。比较纯视频递归、静态记忆、时间对齐记忆，指标为身份保持、事件时序、相机误差、返回状态和视觉质量。先验证各指标能否识别同一组可控错误。
- **审计一条示范的实际学习成本**。固定三个 RoboTwin 任务与二十个留出种子，比较示范记忆、仿真练习和反思。记录示范、练习回合、API tokens、墙钟、首次成功与错误完成声明，给出达到同等成功率的总成本。
- **验证触觉表示的独立增益**。先用 LingBot-Touch Tiny 的公开样例测试信号、布局和几何接口，再比较 raw/CNN/JEPA 与线性/attention probe。只有 probe 通过后再接固定策略，检验接触质量和任务成功之间的关系。
- **连接仿真速度与训练收益**。固定四任务、两种接触难度及同一策略，分别计量物理步、渲染、更新和端到端时间，同时测穿透及成功率。InfraRSI 的小模型实验也使用相同总成本原则，计入全部失败搜索与最终复验。
