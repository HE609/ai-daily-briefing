## 1. Genie Sim / Agent2Act：LLM 到动作的闭环接口与评分修复｜P0

**Genie Sim Team / AgiBot；发布性质为官方代码更新，无对应的新模型训练报告。**Agent2Act 提交于 **10 月 31 日 12:36 北京时间**进入主分支；评分修复于同日 **10:40**提交。[Agent2Act 实质提交](https://github.com/AgibotTech/genie_sim/commit/a2bbec0c0e2d05f7cb5c13c9a75bcbc16ea229be)、[固定版本说明](https://github.com/AgibotTech/genie_sim/blob/a2bbec0c0e2d05f7cb5c13c9a75bcbc16ea229be/source/agent2act/README.md)、[评分修复](https://github.com/AgibotTech/genie_sim/commit/4a507ed57d01ca66ea806fde0ea307c9b6f3f364)。它解决的是部署接口问题：多模态模型选择下一步操作后，怎样把决定转换成有边界的机器人命令，并用新观测继续执行、拒绝或重规划？这不是新的 VLA / WAM 基座。

系统接收原始任务、当前图像和机器人状态，支持直接输出末端目标与路点的 motion 模式、调用 π0.5 / OpenPI 等动作模型的 policy 模式，以及显式 auto 路由。只读深度查询只返回当前帧证据，不推动环境或获取新帧；本地层处理坐标、IK、插值、候选过滤与动作检查，再通过 CoRobot WebSocket / msgpack 接口执行有限 action chunk。被拒绝的动作触发有上限的重规划。没有新的训练目标或专属权重，增量来自运行时和可追溯接口；相对 SayCan、Code as Policies 一类分层控制思想，最值得读的是具体的执行契约。另一个独立增量是评分代码保留 ANY / ALL / SOME 目标拓扑、完整步骤分母与中断状态，避免压缩记录后把部分完成算成完整成功。

**本报完成了有限独立检查：**在固定提交上，以脚本决策和合成观测运行离线 replay，输出 **20 步候选、下发前 8 步**；闭环、policy capability、命令边界、重试预算四个上游测试模块共 **70 项通过**。这确认选定离线接口能运行，**没有调用模型 API、Isaac Sim 或真机，也没有测任务成功率**。评分修复只做源码核查，没有据此重算历史榜单。新代码及其 README 也没有提供可直接引用的机器人能力增益。

**值得精读，完整执行效果仍待验证。**原始代码为 MPL-2.0；第三方 URDF 等材料另有条款和待确认事项。专属权重、训练数据不属于该包交付范围，真实运行仍依赖外部模型、checkpoint、资产与仿真环境。默认 G2 示例关闭速度检查；局部轨迹不保证避碰或动力学可行，长重试也不构成实时控制保证。轻量下一步是在固定场景、动作预算与原生评分器下，对比 motion、policy、auto 三组，分别报告提案拒绝率、实际执行量、端到端时延与最终成功；旧评测记录则先按新评分口径审计，不能直接拼接新旧分数。

## 2. GROME：把静态场景和动态实体分别记住｜P0

**Fang Yu、Xiaoxue Wu、Haiyu Zhang 等；上海人工智能实验室、华东师大、复旦、北航、香港中文大学。**v1 于 **10 月 29 日 18:54 北京时间**提交，预印本，同行评审状态未核实；**属于窗口外首次专题精读，不计本期新增**。[论文与版本](https://arxiv.org/abs/2610.39812)、[方法和完整实验](https://arxiv.org/html/2610.39812v1)、[官方项目](https://lyeean.github.io/GROME_/)。它研究长时探索中的核心矛盾：背景应该在重访时保持原样，动态人物或车辆却不能被旧记忆冻结在过去的位置。

GROME 在冻结的 LingBotV2 上工作，把历史帧提升为局部 pointmap，并将静态几何与动态实体分开保存；深度先与静态历史对齐，检索时选择空间匹配的背景与较新的实体状态。投影参考通过分离的注意力分支进入原生条件路径，Reference Value Adaptation 调整参考特征统计；静态参考仅在前两个去噪步骤建立布局，动态参考持续参与后续去噪。**没有新增训练损失和参数更新**，但依赖深度、分割等辅助模型。相对 VMem 的视图记忆、原始历史上下文及时间检索，关键变化是记忆内容与更新时间的分工；与 L3G-World 直接保存潜空间 Gaussian 的路线也不同。

**作者结果：**200 个 WorldScore 场景包含静态、动态各 100 个，主要轨迹为 **15–18 秒、24 FPS**。同骨干动态场景，PSNR 从原始上下文条件的 **19.291** 升至 **24.111**，LPIPS 从 **0.403** 降至 **0.243**；但这些重访指标在共同有效的**静态区域**计算，不是移动实体的未来轨迹误差。实体一致性为 **0.769**，低于 WorldPlay 的 **0.910**；后者运动表现较差，说明只看外观会奖励冻结。GROME 的原始 Motion Accuracy **16.840** 与同骨干参考 **16.640** 接近且置信区间较宽，不能据此声称运动显著提升。静态 PSNR **20.620** 也低于 Gen3C 的 **21.725**，不是全部指标领先。

**值得精读机制，复现尚缺完整公开包。**项目页的 Code 链接为空且禁用，不能把按钮当代码发布；本轮未核到专属实现、权重或固定的完整评测数据包。论文的可复现说明和演示不等于上述材料已开放。长期颜色漂移与严重深度错误仍会传播，也没有证明接触物理、真实状态或闭环控制收益。轻量验证可先固定二十段含移动物体的“离开再重访”视频，对比原始历史、仅静态、仅动态、分解记忆四组；分别测背景重访、实体身份、最新位置与运动延续，并用等大小记忆和同一生成预算，检查收益是否超过简单的近期帧检索。

## 3. Algebraic World Model：从未知环境交互到可检查的规则与证明｜P0

**Guancheng Pan、Qixin Tan、Yang Yuan、Andrew Chi-Chih Yao；浙江大学、清华大学、上海期智研究院。**v1 于 **10 月 30 日 01:20 北京时间**提交，预印本，同行评审状态未核实；**早于本期窗口，属于边界外补读**。[论文](https://arxiv.org/abs/2610.40503)、[全文](https://arxiv.org/html/2610.40503v1)、[官方交互项目](https://ephemeral6.github.io/awm-site/)。这里 AWM 指 Algebraic World Model，不能与 World Action Model 混称。研究问题是：没有预先给定规则时，Agent 能否通过交互建立一个可执行模型，并对尚未探索的行动序列证明可达或不可达？

方法分三阶段：Explore & Prototype 用 Python 假设解释交互并根据反例修改；Structure & Simplify 将假设组织成有类型的对象和共享规则，以范畴论指导简化；Formalize & Prove 将规则写成 Lean 4 定义，再证明可达性、不变量或行动代价下界。它不是训练新的神经世界模型，也没有新的梯度训练目标，优化对象是显式程序与规则。相对 Dreamer / 视频世界模型，优势是规则可检查；相对已知形式规范上的定理证明，新增困难是规范本身也要从环境中学出来。屏幕到状态的解析仍发生在 Lean 之外，证明只在所写模型及其显式前提下成立。

**作者结果：**25 个公开 ARC-AGI-3 游戏、183 个关卡的获胜轨迹均能在学习到的 Lean 模型中重放。两个封闭的不可解关卡，各三次运行，AWM **6/6**给出模型内的闭合证明；有编码工具的两个基线合计 **0/12**。六次初始代价界中 **4 次正确**，提供“存在更便宜解”的反馈后改正为 **6/6**，这包含额外外部反馈。主榜 **99.9** 分与人类行动量 **43%**只对应计分的获胜轨迹；22 个游戏在正式计分前已有同一运行的探索阶段，不能说总交互成本减少 57%。作者还报告冻结规则预测 **4,160/4,160** 个新布局转移，拒绝 **4,031/4,031** 个修改机制后的转移；这支持指定环境中的一致性，仍非开放物理世界的正确性保证。

**建议精读，尤其读证明的前提和完整成本。**[lp85 原始档案](https://ephemeral6.github.io/awm-site/raw/lp85.zip)已实际下载检查，包含 Lean 文件、Python 规则、转移轨迹和作者的公理审计记录；README 明示生成 formalization 的 world/formalize.py 未包含。作者的重检查记录属于作者证据，本报没有重编译 Lean 或独立重跑游戏。未确认完整 Agent 运行环境、所有构建依赖与统一许可，不能称一键全量复现；专属模型权重不适用。轻量实验先选一个有限状态谜题，留出状态布局和规则扰动，固定探索预算，比较“可执行假设”与“假设加形式证明”；用真实引擎的穷举结果核验不可达结论，单独统计解析错误、错误规则、证明失败和全部探索成本，再考虑迁移到机器人技能图。

## 4. 微软合成企业评测：带组织、时间与业务流程的 Agent 测试环境｜P2

**Somya Chatterjee、Harshita Sahijwani、Min Chen 等；Microsoft Research 与 Copilot 团队。**官方研究博客于 **10 月 30 日 21:05 北京时间**发布；性质为工业评测方法披露，本轮未核到对应的新同行评审论文。[官方文章](https://www.microsoft.com/en-us/research/blog/from-synthetic-enterprise-data-evaluations-to-real-microsoft-copilot-ai-confidence/)。它关注企业 Agent 的数据难题：通用问答集缺组织关系和长期上下文，真实客户工作区又不能直接充作共享评测数据。

Industry Evaluation Data Generation Platform 用公开职业资料、招聘信息和公司披露约束角色、组织规模与业务活动，生成带用户、邮件、会议、文档及跨周项目历史的合成工作区。六阶段查询管线把通用任务筛选、行业化、绑定到生成内容，再自然化改写并检查准确与重复；质量框架检查结构、情境、行为和内容安全。它没有公布新模型训练目标，研究对象是环境、查询和验收流程。相对静态检索问答或单次工具调用评测，潜在价值在跨文档依赖和时间结构；与可交互 Agent 环境的关系则仍在建设，不能把当前案例直接当作完成多步行动评测的证据。

**官方结果：**三个行业工作区覆盖制药、资本市场、IT / 软件，每个具有数百用户及通信历史；内部复合质量指标相对初版提高 **39%**，部分环境质量分超过 **0.9**。这些数字度量的是合成数据质量，不是 Copilot 成功率提升；每数据集约 **10 万美元**、项目合计约 **30 万美元**节省也是团队估算。文章没有给出公开的独立复核、统一下游能力增益或完整成本对照。

**适合读评测设计，暂不按新能力模型投入复现。**工作区和数据目录为内部复用，未核到公开生成源码、完整数据、配置或评分器；权重不属于该发布的重点。主要 gap 是合成质量评分是否真能预测真实错误，生成器与评判器是否共享盲点。轻量替代可搭建十个虚构团队、三十条有时间版本的任务，固定一份独立事件账本；比较无时间结构、仅时间线、完整组织依赖三组，测过期信息使用、错误引用及错误操作。只有留出任务和独立账本核分也改善，才值得扩大合成数据规模。

## 今日研究地图

持续地图仍按 **感知与状态 → 转移预测 → 规划与执行 → 学习闭环 → 评测与基础设施**组织。以下趋势和论文机会是本报综合判断，尚待实验验证。

| 问题分类 | 今日材料与近期趋势 | 未解决 gap | 可形成论文的机会 |
|---|---|---|---|
| 持久空间与动态记忆 | GROME，衔接 L3G-World、LucidLyra | 静态重访、实体外观与真实动态正确性尚未统一 | 同观测、同预算的静态 / 动态记忆更新与失效校准 |
| 可辨识转移与显式规则 | Algebraic World Model，衔接 world2vec | 解析器、学习规则和证明正确性仍有分界 | 带留出干预的规则发现与可审计模型适用域 |
| 规划与动作执行 | Agent2Act，衔接 VLA / WAM 分层控制 | 模型判断、局部可行与实际成功之间有距离 | 同一动作后端下，深度查询、候选过滤和重规划的独立贡献 |
| 反馈与学习闭环 | 形式模型修订、Agent 运行记录 | 外部反馈与系统自改进混合，验收器可能同步变化 | 冻结验收器、计入全部探索和反馈的自改进评测 |
| 环境与评测基础设施 | Genie 评分修复、微软合成工作区 | 评分口径和合成真实度尚未绑定外部效度 | 旧结果可迁移性审计与合成质量到真实错误的预测 |

相对上一期，新增连接是：**状态与时间接口明确之后，还必须追问谁负责更新、谁负责执行、谁负责验收，以及验收标准能否跨版本保持可比。**跨本体数据、接触、连续动作与预测效用等既有问题继续保留，没有因今天更换条目而撤销。

## 今日研究机会与轻量验证

**1. 记忆有效，还是只是更容易复制画面？**固定二十条静态与动态重访轨迹，给四种记忆同样的容量与可见历史，加入物体移位、短暂遮挡和再次出现。背景 PSNR、实体身份和最后可见状态分别核分，并用独立场景状态作真值。只有分解记忆同时减少背景漂移和过期实体，才继续做生成骨干实验；若仅背景变好、动态被冻结，先修正写入和过期策略。

**2. 证明能否帮助发现模型本身的错误？**在有限状态谜题中加入一条未公开机制变化，固定探索预算，独立引擎保留真实转移。比较可执行模型、模型加证明、模型加反例搜索三组；指标是错误不可达判断、识别机制变化的交互数与总耗时。若证明只增加模型内确定性而不能发现环境偏差，研究重点应转向适用域和主动反例，而非更长的证明。

**3. Agent 收益能否与控制后端、评分器版本分开？**用同一模型和机器人后端，固定十项任务及初态，分别切换只读深度、候选过滤与有界重规划；保留原生成功判据。先以少量配对运行排查效应和失败类型，观察到稳定信号后再扩样本。评分代码升级则单独重算同一批原始记录；若分数变化来自分母或目标逻辑修复，不归因于策略能力提升。

**4. 合成环境是否预测真实 Agent 的错误排序？**先为三十条虚构业务任务建立独立事件账本和可执行验收，设计过期文件、跨团队依赖和缺失权限。生成质量分、问答正确率与实际动作正确率分开记录，比较不同模型的错误排序是否稳定。无需生成数百万文档；若规模扩大却不改善独立验收，先检查生成器与裁判的共同盲点。

## 证据状态与可复现性

GROME 与 Algebraic World Model 的重点数值均为**作者报告**，同行评审状态未核实；微软数字为**官方内部评估与成本估算**。本报的独立执行仅限 Agent2Act 的合成离线 replay 和 70 项选定单元检查，不能扩展成完整软件验收、模型能力复现或真机验证。
