【🚨 今日重点】

  1. NVIDIA × Stanford × UT Austin：RoboTTT 把机器人基础模型的"上下文"拉到 8K 时间步——Yuke Zhu、Li Fei-Fei、Linxi "Jim" Fan 等团队提出 Test-Time-Training 机器人策略 RoboTTT，将视觉运动上下文扩展到 8K 时间步（比现有 SOTA 高 3 个数量级），且推理延迟不增；在真实机器人上比单步基线整体性能提升 87%，完整完成 5 分钟、10 阶段装配任务（基线从未做到）；8K 上下文训练比 1K 提升 62%。来源：arXiv 2607.15278 / NVIDIA Research / 公众号，2026-07-17。

  2. HoloGeo：用"证据驱动推理"破解 VLM 地理定位的"地标偏差"——新加坡国立大学 + 牛津 + 山东科大团队构建 LandmarkBias-3K 基准与 BF-30k 训练集，提出 HoloGeo 框架；多维度奖励鼓励对多样视觉线索的平衡关注，IM2GPS3K / YFCC4k 保持 SOTA，并在新基准上显著超越开源 VLM。来源：arXiv 2607.15255 / 公众号，2026-07-17。

  3. HDR：让视频基础模型"多步推理"——HKUST × PKU × Muka Robotics——北大-港科-北航-木卡机器人联合发布 HDR（Hierarchical Denoising for Reasoning），用树形层次结构 + 稀疏分层注意力把因果视频生成改造成多步推理框架；6 项任务（迷宫/汉诺塔/一笔画/滑块/推箱子/倒水）成功率从 34.22 提升到 60.29，速度比双向扩散快 54.2×，真机机器人实验证明可用于物理交互与世界建模。来源：arXiv 2607.15278 / 公众号，2026-07-17。

━━━ 顶级研究组新发布 ━━━

  • RoboTTT（NVIDIA + Stanford + UT Austin）：将测试时训练（TTT）集成进 VLA 策略，序列动作强制 + 截断 BPTT，把视觉运动上下文拉到 8K 时间步；解锁一次性上下文模仿、对扰动鲁棒、长视野任务；具身领域首次证明"上下文长度是新的扩展轴"。来源：arXiv 2607.15278（cs.RO/cs.AI/cs.LG）/ NVIDIA Gear 实验室。
  • MeanFlowNFT（Tencent Hunyuan + HKUST）：把 DiffusionNFT 前向过程 RL 引入 MeanFlow 生成器，受 MeanFlow identity 启发构建诱导瞬时速度预测器；Wan 2.1 4 步采样 VBench 84.33 分超越 50 步 LongCat-Video RL 的 82.57 分。来源：arXiv 2607.15273，2026-07-17。
  • SciDiagramEdit（KAUST + Microsoft Research + NTU）：从 arXiv 版本历史挖掘前后图形对作为训练信号，提出技能进化的智能体学习框架，在矢量图源上做可解释的指令驱动编辑。来源：arXiv 2607.15272（cs.CL）/ 公众号。
  • MeanFlowNFT / AutoSynthesis / RLAnything 同日登场——米兰理工 + 慕尼黑 + MIT CSAIL 团队发布 AutoSynthesis 元分析多智能体系统，28 篇研究中提取 20+ 量化声明，与专家级 Hedges' g 高度一致，证据合成全流程自动化。来源：arXiv 2607.15247。
  • T²MLR（Princeton, Sanjeev Arora）：Transformer 时间中层循环架构，把前一个 token 缓存的中层表示直接融合到当前 token 较早层；仅对 20% 中层块做循环即超过全层循环；1.7B 现成模型微调即可大幅提升数学推理。来源：arXiv 2607.15178（cs.CL）/ 公众号。

━━━ 生成模型 / 新范式 ━━━

  • MeanFlowNFT（Tencent Hunyuan + HKUST）：前向过程 RL 与平均速度生成器结合的首次系统方案，DiffusionNFT 的 policy-improvement 严格保证被继承；图像/视频生成多指标超 SOTA，few-step 性能甚至超过多步 RL 调整扩散。来源：arXiv 2607.15273。
  • T²MLR（Princeton, Arora）：打破"有效潜在推理必须遍历所有层"的旧范式；中层定点循环即可获得最强跨 token 推理持久性，已在自然语言预训练 + 多跳推理微调中验证。来源：arXiv 2607.15178。
  • Mask-Aware Policy Gradients for MDLMs（UT Austin, COLM 2026）：把掩码扩散语言模型的生成形式化为两阶段动作 MDP，策略梯度自然分解为 token 项 + masking 项；GSM8K 87.1%、MBPP 53.4%。来源：arXiv 2607.15200。
  • BadWAM（NUS + PolyU）：首篇系统研究世界-动作模型（WAM）对抗鲁棒性的论文，提出"世界-动作漂移攻击"统一框架；只动作攻击把任务成功率从 96.5% 砸到 43.1%，保持想象攻击还能保持"看起来对、实际错"的隐蔽性。来源：arXiv 2607.15207（cs.LG/cs.RO）。
