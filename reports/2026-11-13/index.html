空间智能与通用 AI 科研晨报 ｜ 2026-11-13

本轮检索窗口为北京时间 2026-11-10 08:59 至 2026-11-13 08:59，资源核验延伸至成稿。候选池并行覆盖 arXiv cs.RO、cs.AI、cs.CV、cs.LG，Spatial Intelligence、3D/4D 世界生成、real-to-sim、WAM/VLA、Robot Learning、Agent/self-evolution、GitHub、Hugging Face，以及主要公司和高校官方研究入口。相对 11 月 12 日，PAN 2、UGG、MetaWAM、LaST0.5、Elastic-WAM、Long-WAM refresh、Few-Shot Residual、Memory Clock、CIALLO、FGSE 与 NTT physics adapter 已有完整展开，本期只有在窗口内出现新代码、权重、基准结果或此前未展开的晚批次时重新纳入。

今天的新增判断集中在一个接口问题上。可迁移能力来自什么，正在被拆成动作表征、执行时长、未来视觉状态和安全决策四种接口。 OnlyAct 把无动作标签视频中的运动抽成可迁移 latent action，Ego Guidance 用未来视觉状态监督共享 VLM，ExRL 只学习何时刷新长动作 chunk，LEASH 则把 agent 的任务、动作和不可逆操作放到三个可审计的安全 gate。BEHAVIOR-1K 的两个窗口内方案进一步说明，长时成功率既受 WAM 的阶段状态影响，也受 agent 练习状态和评测基础设施影响。今天只展开八项，减少同日低证据重复。

今日精读顺序

今天我建议的精读顺序是：OnlyAct → LEASH → ExRL → DexSeed → Ego Guidance。

  • OnlyAct。先看如何从无动作标注视频中提取动作而压低场景泄漏，并用跨场景视频生成检验表征是否真的可控。
  • LEASH。再看 agentic robotics 的安全评测如何进入闭环执行，重点审查 harm rate、safe success 与人工判断之间的关系。
  • ExRL。接着看冻结长 chunk policy 只学习执行长度，如何在十分钟级真实交互中取得适配收益。
  • DexSeed。然后看人类手物交互怎样通过物理 rollout 扩成可执行的灵巧机器人数据。
  • Ego Guidance。最后看无动作人类视频如何通过未来视觉状态改变共享 VLM，并把收益推到分布外任务。

重点论文 / 模型 / 项目

1. OnlyAct: Extracting Action Representations from Foundation Models for World Models｜P0

Runjia Li、Minghao Chen、Junyu Xie、Philip Torr、Andrea Vedaldi、Tomas Jakab，University of Oxford。论文于 2026-11-10 17:59 UTC 提交，属于 NeurIPS 2026 论文和开源代码、权重发布。 论文 · 项目页 · 代码 · 权重入口

它研究的是动作条件世界模型的动作监督瓶颈。OnlyAct 以冻结的 V-JEPA 2 ViT-L 编码连续帧对，再用 LoRA 做 label-free contrastive adaptation。正样本把同一运动贴到不同场景，困难负样本来自同一视频的另一时间片。训练目标同时拉近相同运动、推远相同场景下的不同运动，形成 640 维动作 embedding。该 embedding 直接替代 AdaWorld 或 DreamDojo 的 latent action，还支持从真实动作做少量标注微调。

作者结果显示，13 个动作探针数据集的平均线性 probe (R^2) 为 0.490，在 13 个数据集中的 11 个取得最佳。场景泄漏测试的平均 held-out LPIPS 为 0.304，优于冻结 V-JEPA 2 的 0.275。相同 AdaWorld 世界模型下，LIBERO action-transfer direction 为 0.917，DreamDojo 为 0.803。nuScenes 控制性微调的 Follow 为 0.928，DreamDojo 为 0.722。结果来自作者论文和公开项目页，训练运行在表格级结果上仍有 single-run 项，尚无第三方复跑。

创新点是把动作表征学习从“重新学习 latent action bottleneck”改成“利用视频基础模型已有的运动信息，再处理场景泄漏”。它与 V-JEPA 2、DreamDojo、AdaWorld 和 OnlyAct 论文中引用的 Matrix-Game 系列相连，也为跨本体动作接口提供了一个可测的中间层。局限是正负样本依赖光流或颜色扰动构造，动作和场景在真实视频中仍可能共变，动作 transfer 指标依赖光流方向而不等同于物理因果正确。

值得深入阅读。 代码、训练脚本、表格复现脚本、checkpoint 下载说明和数据 split 已在 Apache-2.0 仓库中给出。README 记录 168K frame pairs、约 7.1M LoRA 参数、单张 RTX 4090 约 1.5 小时的适配成本。轻量验证可只跑 probe 和 leakage 两组，再在 LIBERO 或 SpatialVID 做“同动作不同场景”四组 transfer，记录 action (R^2)、scene LPIPS、生成方向一致性和跨 seed 方差。它适合成为今日最先执行的公开 checkpoint probe。

2. LEASH: Stay Safe in Agentic Robotics｜P0

Qinfeng Zhu、Weiguang Zhao、Ke Sun、Xihao Guo、Yunxi Jiang、Rui Zhang、Lei Fan、Kaizhu Huang，Xi’an Jiaotong-Liverpool University、Duke Kunshan University、University of Liverpool、NUS、CNRS。论文于 2026-11-10 14:06 UTC 提交，11 月 11 日公开代码和 benchmark，11 月 12 日补齐 Hugging Face 任务目录。 论文 · 项目页 · 代码与 benchmark · RoboRisk 数据集

LEASH 解决的是 agent 直接控制机器人时，安全判断往往只在任务开始发生一次的问题。RoboRisk 有 92 个仿真任务和 13 个真实机器人任务，覆盖 Task-level Refusal、Plan Repair、Execution-time Hazard、Instruction Injection、Sequential Memory 五类风险。LEASH 在任务接收、每次动作和释放或倾倒等不可逆操作前分别执行 task gate、action gate、commit gate。三个 gate 与 planner 共享一套相机条件安全策略，输入当前 RGB-D 观测。

作者结果使用 Harm Rate 和 Safe Success Rate。GPT-6 Astra 在仿真中的 harm rate 从 11.23% 降到 0%，safe success 从 78.99% 升到 80.80%。真实机器人上，Astra 从 15.38% 降到 0%，safe success 从 69.23% 升到 84.62%。GPT-6.1 Sol 的仿真 harm rate 从 18.48% 降到 1.45%，Gemini 4 Argon 的真实 harm rate 从 15.38% 降到 0%。这些是作者在 276 次仿真运行和 13 次真实任务上的结果，风险结果由人工判断，样本仍不足以支持硬件级安全保证。

研究价值在于把安全从“模型是否拒答”推进到“闭环动作中是否出现危险状态”，并且把 scene injection 和跨回合记忆纳入同一协议。它与传统碰撞检测、安全规划器和 agent harness 研究形成互补。局限是 commit gate 当前主要覆盖释放和倾倒，gate 判断依赖 reviewer，13 个真实任务每个 planner 只有一次执行，外部独立复核尚未出现。项目仓库已公开 3,312 条仿真结果和任务目录，许可证为 MIT，数据与代码入口清楚。

值得深入阅读并可立即复现。 轻量验证先跑仓库中的 P3-01 和一个 Sequential Memory 任务，把 baseline、LEASH、随机 gate 三组固定在同一 seed。记录 harm、safe success、拒答率、延迟和 token 成本，再把动作 gate 替换成简单规则，检验收益来自视觉安全 policy 还是 gate 结构本身。

3. ExRL: Sample-Efficient Online Adaptation of Long-Chunk Policies via Execution Length Control｜P0

Xu Luo、Jiaying Yang、Hao Wu、Junlin Xie、Zijin Hong、Ji Zhang、Lianli Gao、Jingkuan Song，UESTC、同济大学、香港理工大学。论文于 2026-11-10 02:44 UTC 提交，项目页和代码已公开。 论文 · 项目页 · 代码

ExRL 针对长动作 chunk 的在线适配难题。它冻结原始 Diffusion Policy、ACT、(pi_{0.5})、(pi_0)-FAST 或 Cosmos Policy，只增加一个根据当前观测和待执行 chunk 预测离散执行长度 (k) 的 adapter。训练使用带实际持续时间的 off-policy RL，奖励累计和折扣项按选中的 (k) 修正。动作内容由 base policy 产生，ExRL 学的是何时继续执行、何时截断并重规划。

作者结果在真实 (pi_{0.5}) 任务上，Stack cube 为 17/20，Clothing folding 为 17/20，Power insertion 为 22/25，Parts organization 完成 104/125 个阶段。固定执行长度的最好对照分别为 9/20、12/20、10/25 和 69/125。仿真中，LIBERO 的冻结 (pi_{0.5}) 可在 200,000 环境步内从接近 0% 提升到 90% 以上，Tool Hang 上 ExRL-SAC 超过 90%，其他基线约 20% 或更低。真实 stacking 约 10 分钟物理交互接近满成功率，clothing folding 在约 85 分钟内接近 90%。结果是作者报告，尚无独立真实复跑。

它的创新是把高维动作优化改写为低维时长控制，同时保留长 chunk 的表达能力。与 Adaptive Action Repetition、AAC、FFDC 和直接 residual RL 相比，ExRL 的接口只依赖 chunk 执行长度，适配到 WAM、flow VLA 和自回归 VLA。局限是执行长度策略受 base policy 上限约束，真实结果仍需高成本交互，动作候选本身错误时缩短执行只能改善重规划频率。

值得深入阅读并优先做小实验。 代码包含 Robomimic、Adroit、LIBERO、(pi_{0.5})、(pi_0)-FAST 和 Cosmos Policy 配置，数据和模型权重需按上游入口单独取得。轻量验证可在一个已有 chunk policy 上只比较固定 (k=1,10,50) 与 ExRL adapter，加入“长度打乱”对照，报告 success、replan 次数、动作抖动、显存和墙钟。这个实验能直接检验“状态与 chunk 联合决定时长”的核心假设。

4. DexSeed: Expanding Human Hand-Object Interactions into Robot Demonstrations for Dexterous Policy Learning｜P0

Huaijin Pi、Zehong Shen、Yong Wang、Kechun Xu、Changpeng Wang、Dingkun Wei、Wenjia Wang、Xing Zhu、Yujun Shen、Taku Komura，香港大学、Robbyant、浙江大学。论文于 2026-11-10 13:52 UTC 提交，项目页与演示已公开，代码仍在准备中。 论文 · 项目页 · 代码仓库

DexSeed 处理人类手物视频难以直接转成灵巧机器人动作的问题。流程先按手型、手物关系和方向构成 170-D grasp descriptor，聚成 grasp modes，再做 InteractionMesh retargeting、物体几何和位置增强。随后由 arm trajectory tracker 与 RL finger-control policy 在物理仿真中执行，只有通过成功条件的 rollout 才被渲染为机器人训练样本。最终 VLA 同时预测手臂与手指动作，输入 grasp 文字描述。

项目页当前公开 19 个 human source sequences、8 个 grasp modes、17 个 object categories、25,270 条 robot trajectories。物理参考轨迹实验中，加入 arm tracking 的方法成功率 95.50%，对比 ManipTrans 为 34.25%、Dexplore 为 24.81%。项目页还展示了八种 grasp mode 的真实机器人执行，以及由生成数据微调的 VLA 在 seen、layout、geometry、appearance 留出条件上的结果。论文摘要报告仿真和真实部署均可完成语言指定 grasp，具体数据以项目页表格为准。

创新点是把人类视频作为接触结构和相位先验，再通过完整物理 rollout 搜索可执行控制。它连接 Ego Guidance 的无动作视觉监督、DexMimicGen、SkillMimicGen 与跨本体数据扩增路线。局限是 19 条源序列规模仍小，手部动作的视觉重建、机器人手模型和仿真接触参数会共同决定收益，GitHub README 明确写着代码 coming soon，尚无外部复现和完整训练数据包。

值得深入阅读，适合作为跨本体数据线的首个复现候选。 轻量验证可以只取两个 grasp mode、三种物体几何和两种位置，比较无 arm tracking、无 physics filtering、完整 DexSeed 三组生成成功率，再把同样的 100、500、1,000 条演示喂给一个小型 VLA。需要把 data generation success、physics rollout success、policy success、real transfer 分开报告。

5. Ego Guidance: Enhancing Robot Policy Learning with Action-Free Human Egocentric Videos｜P0

Lin Long、Tianren Ma、Zhong Chu、Di Wu、Maosong Cao、Qixiang Ye、Junbo Zhao、Shanghang Zhang，浙江大学、中国科学院大学、南洋理工大学、北京大学、Ant Group。论文于 2026-11-10 07:33 UTC 提交，项目页已公开，代码入口待进一步核实。 论文 · 项目页

Ego Guidance 研究大量无动作人类第一视角视频能否帮助机器人策略。SPAR 使用共享 VLM backbone 和两个独立 MoT expert。机器人数据同时监督 action expert 与 future visual-state expert。人类视频只监督 future visual-state expert，目标是未来相机帧经过冻结视觉编码器后的特征。训练时联合损失为 (mathcal{L}{robot}=mathcal{L}}+lambdamathcal{L{gen})，(mathcal{L})，推理时移除 generation expert，保留标准 VLA 的动作路径。}=lambdamathcal{L}_{gen

论文使用约 38,000 个 DROID episode、230 小时机器人数据，Ego4D 原始 3,976 小时经过稳定相机和可见手两道 gate 后保留约 975 小时。SigLIP2 future representation 在 LIBERO-Plus 上的平均成功率为 76.2%，Wan-VAE reconstruction latent 为 60.0%。Open-AoE 预训练从 0 到 1,500 小时增加时，LIBERO-Plus 成功率持续上升，而 LIBERO 变化较小。真实 AgileX Cobot Magic 五项任务共 50 次，SPAR 为 20/50，π₀.₅ 为 22/50。视觉扰动下，Cucumber Transfer 的照明、背景、静态干扰分别为 9/10、8/10、5/10，π₀.₅ 为 7/10、7/10、4/10。结果均来自作者三 seed 或作者真实试验。

研究价值在于把“动作自由的视频数据”放到共享表示训练，而不把它强行伪标成机器人动作。它与 Open-AoE、Ego4D、Ego2Robot、WAM 和 Video Generators are Robot Policies 相关。局限是 raw Ego4D 会低于 robot-only，收益依赖过滤和训练阶段。真实任务成功率仍低，抓取、双臂旋转和长时任务是主要失败来源，代码与完整数据许可尚未闭合。

值得精读数据清洗和表征目标消融。 轻量验证可复现 SigLIP2、DINOv2、Wan-VAE 三个 target，在固定 150、450、1,500 小时视频预算下比较 LIBERO-Plus 的 camera、lighting、background、layout 变化，另外做“同视频数量、不同多样性”的反事实。它适合与 OnlyAct 放在同一表征接口实验中。

6. WAM is capable in BEHAVIOR-1K: the 2nd-place solution to the 2026 BEHAVIOR Challenge｜P0

Yelin He、Jiaquan Ye、Xinming Wei、Wenjie Xiao、Gengming Zhang、Guoting Wei、Xianbiao Qi、Rong Xiao，深圳市因特尔融讯科技有限公司、Johns Hopkins University。论文于 2026-11-10 09:46 UTC 提交，属于 CoRL 2026 竞赛技术报告。 论文 · BEHAVIOR Challenge · 官方 2026 评测说明

该方案以 Cosmos 3 WAM 为底座，解决 100 个长时 household task 中观察歧义和阶段误差。方法加入更长视觉历史、task-progress conditioning、17 个 task-group LoRA、Pick/Place/Close/Open skill LoRA，以及独立 stage estimator 和 subtask predictor。推理时使用 progress-conditioned routing、5 个动作候选聚合、rolling inpainting、短长 execution window、TOPP-RA retiming 和 task-specific gripper rules。阶段预测损失为 cross-entropy，动作 chunk 继续使用 WAM 的视频和动作去噪目标。

官方私有测试结果是 mean Q-score 0.615，full-task success 41.2%，在 100 个任务中排名第二，平均每个端口端到端推理速度超过 2 FPS。作者自评三轮为 Q 0.613、full-task success 40.9%。在 24 个任务子集上，skill-to-stage lookup 比 stage estimator 加后处理从 0.681/52.5% 提高到 0.707/56.3%。固定 episode clock 只有 0.480 Q，stage estimator 为 0.494 Q。官方结果是作者报告，论文明确指出自评配置比私有提交简化，代码和权重公开状态仍需从仓库与上游 Cosmos 资源拼接复现。

创新点是把 WAM 的“世界状态”具体化为 task stage 和 skill route，并把阶段错误当作可测的 non-Markovian ambiguity。它与本期 Long-WAM、Memory Clock、MetaWAM 形成互补。局限是很多收益来自工程组合，task-group、skill adapter、阶段标签和 execution window 没有完全等预算拆分。论文中的 instance cherry-pick Q 0.891 是上界，不应当当作单一固定配置结果。

值得深入阅读工程接口和阶段消融。 轻量验证先只复现 24 个高 stage-association 任务，在同一 Cosmos checkpoint 上比较 uniform clock、stage estimator、skill-to-stage lookup。再把 null-event 插入演示，测试阶段估计器是否把时间流逝误当作任务进度。官方私有测试无法复现时，优先做 public validation 和 per-task stage confusion matrix。

7. Game-Enhanced Embodied Learning with Event and Foresight Pretraining｜P1

Lianlei Shan、Han Jin、Yaunchao Ma、Xinpeng Chen、Linhao Zhou、Xin Bin，北京新颖随行科技有限公司。论文于 2026-11-10 09:46 UTC 提交，arXiv 预印本。 论文

它研究桌面游戏能否提供成对的观察、输入事件和视觉后果，作为机器人策略训练的补充。方法在 InternVLA-A1.5 上增加 event prediction 和 history-conditioned foresight pretraining。Coverage-preserving anchor selection 将游戏记录切成一秒目标，attention mask 阻止 teacher-forced future actions 泄漏到 foresight query。训练集含 394 个录屏、20 个游戏、约 223.36 小时时间跨度和 2,072,084 个训练 anchors。冻结视频模型提供未来视觉监督，训练目标同时覆盖鼠标键盘事件与未来视觉状态。

作者在相同 suite-specific robot fine-tuning 协议下报告 LIBERO 四套件总成功从 1,718/2,000（85.90%）提高到 1,811/2,000（90.55%），增益 4.65 个百分点。Spatial、Object、Goal、Long 分别增加 9.2、6.8、0.2、2.4 个百分点。40 个任务中 24 个改善、10 个下降、6 个持平。结果来自作者单一完整 game-pretraining stage，论文明确指出 game data、两个目标和训练随机性的独立贡献尚未拆开。

它把游戏作为廉价的 event-video-action 环境，连接 D2E、InternVLA-A1.5 和 action-free video pretraining。局限是键鼠事件与机器人动作存在接口鸿沟，游戏动态和真实物理接触差异大，当前结果没有证明可迁移的物理规律。代码、权重、完整录屏和数据许可证本轮未核实。

适合作为低成本数据接口对照。 轻量验证可固定 InternVLA-A1.5 和 12,400 updates，做 game events only、foresight only、二者联合、随机事件四组，保持 batch、seed、fine-tuning steps 一致，并用 LIBERO-Plus 的 appearance、camera、layout 扰动区分表征收益与任务记忆。

8. One Policy for 100 Household Tasks: Our Solution for the 2026 BEHAVIOR Challenge｜P1

Ilia Larchenko、Gleb Zarin、Atindra Nair、Keerti Manney、Vitaly Kleban、Mirko Kiefer、Anjana Yodaiken，独立 Robot Learning Collective。论文于 2026-11-10 18:06 UTC 提交，竞赛技术报告，代码、checkpoint 和项目页已公开。 论文 · 代码 · checkpoint · 项目页

该方案把 2025 年 50-task π₀.₅ 方案迁移到 2026 年 100 个 OmniGibson household task。核心是语义 stage、相似旧任务 warm-start、新的 21 维动作空间、variance-reduced multi-sample flow matching 和 200k-step 训练。数据为 20,000 个 episodes、211M frames，约 1,950 小时。作者还建立带 provenance、episode diagnostics 和可恢复 simulator state 的云评测基础设施，单 GPU 可让六个 simulator 快于 real time。

作者结果为 2025 共享 50 个任务 Q 从 0.260 提升到 0.371，100 任务 learned policy Q 为 0.392。14 个弱任务切换到 GPT-6 Astra agent 后，Astra 平均 Q 为 0.639，learned policy 为 0.108。公开提交包含部分 Astra 结果，整体 Q 0.446，full-task success 27.3%，最终排名第九。Astra 从训练实例的冻结 practice session 开始，使用 observe、xyz、act 工具，练习过程产生 notes 和 recipes，但不更新模型权重。全部结果都在模拟器内，无法推断真实家庭机器人能力。

研究价值在于展示单一 checkpoint、恢复性评测基础设施和 agent route 的组合，并把“练习记忆”变成可冻结的 session artifact。它与 FGSE、RoboACE、Memory Clock 和 BEHAVIOR WAM 方案共同指向状态、阶段、工具和验收器的长期接口。局限是 agent route 只覆盖 14 个任务，practice session 规模可达数百 MB，运行中位时间约 0.63 小时，成本和公开复现链仍高。代码公开，Astra session 和最终所有 agent 结果没有完全公开。

值得作为 agent-robot 混合系统案例阅读。 轻量验证可只复现 learned policy 的 semantic-stage、task-embedding warm-start 和 checkpoint provenance，再在两个任务加入 frozen practice session。报告 learned-only、agent-only、bounded intervention 三条曲线，记录 Q、stage error、API 调用、wall-clock 和恢复次数。不要把 Astra 的 14-task route 汇总成通用 VLA 成功率。

近期趋势有三点。第一，动作条件世界模型正在把 latent action、future representation、stage token 和 execution length 分成不同接口，单一“世界模型得分”不足以描述系统。第二，跨本体数据越来越依赖物理 rollout、状态表征和人类视频筛选，数据规模与可执行性必须分开记账。第三，Agent 研究开始把安全、记忆、练习和验收器作为持续状态，而不是一次性 prompt。

今日研究机会与轻量验证

  • OnlyAct × Ego Guidance 表征对照。固定 V-JEPA 2、SigLIP2、DINOv2 三种 encoder，在同一 LIBERO-Plus split 上测 action probe、future-state probe、scene leakage、camera/lighting/layout robustness 和真实动作 transfer。
  • ExRL × Memory Clock 长时控制。在同一 π₀.₅ 或 WAM checkpoint 上加入 pause、fidget、air-grasp 和动态延迟，比较固定 chunk、ExRL、clock-only、event-indexed 四组，记录 stage error、提前终止、重规划次数和成功率。
  • DexSeed 的生成链审计。只用两个 grasp mode 和 100/500/1,000 条示范，逐步去掉 arm tracking、physics filtering、appearance randomization，分别统计生成成功、接触保持、策略成功和真实小样本成功。
  • LEASH 的 gate 归因。固定 RoboRisk-S 任务和 planner，比较 full LEASH、task gate only、action gate only、commit gate only、随机 reviewer。报告 harm、safe success、延迟、token 和错误拒绝。
  • BEHAVIOR stage 语义审计。在 24 个高 stage-association 任务加入重复子任务与暂停片段，比较 uniform clock、stage estimator、skill-to-stage lookup，输出 stage confusion 和 action MAE。
  • Game pretraining 的等预算复核。固定 12,400 updates 和同一 InternVLA-A1.5，做 game events only、foresight only、联合目标、随机事件四组，外加 LIBERO-Plus appearance、camera、layout 三类扰动。

以上是轻量验证建议。本轮完成了论文、官方材料、公开代码/权重入口和实验协议核验，没有运行模型推理、GPU 训练、真机实验或独立 benchmark 复现。
