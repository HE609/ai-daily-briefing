今天最重要的判断是：研究竞争点从“能否生成看起来合理的视频”进一步转向 能否在统一空间坐标中预测动作后果、识别失败、支持闭环推理，并以较低成本接入真实机器人。Odyssey-3 是窗口内最重要的官方 frontier 发布；UNITAS、DreamTrue、PLaW-VLA 和 LAC-WM 分别从 3D 原生表示、反事实动作忠实性、低延迟未来表征和跨本体潜动作对齐推进世界动作模型；SpaceCast-Bench、ARC、RoboRSI 则把空间推理、行动理由和自演化过程变成可测量对象。

今日精读顺序

今天我建议的精读顺序是：A → Odyssey-3 → B → UNITAS → C → DreamTrue → D → SpaceCast-Bench → E → ARC。

  • A Odyssey-3：先建立“视频世界模型是否真的学到物理和可控交互”的官方参照，但必须把公司报告与独立验证分开。
  • B UNITAS：直接看 3D 坐标、动作流和场景流如何合成一个可执行的 WAM，是今日最贴近空间智能主线的论文。
  • C DreamTrue：重点读其动作校准、反事实后训练和缺陷奖励，判断“动作忠实性”能否超越视频逼真度。
  • D SpaceCast-Bench：有代码和数据，适合今天立即做轻量实验，验证模型是否利用了 3D 证据而非只猜答案。
  • E ARC：看不扩充机器人示范、不改基础架构时，动作因果推理是否能带来可重复的 RFM 增益。

重点论文 / 模型 / 项目

1. Odyssey-3｜P0

作者/机构与发布性质：Oliver Cameron、Jeff Hawke，Odyssey Systems；官方研究预览/模型与 API 更新，2026-10-08。官方页面称 Odyssey-3 Pro 在 Physics-IQ Verified 视频到视频榜单达到 66.1，并在 WorldMark 的 4 个类别中 3 个排名第一；这些数字均是公司报告，尚无同行评审论文或第三方复现实验。官方发布 · 体验 Odyssey-3 Flash。

它解决的问题是：把开放世界的视频预测变成可交互环境，使模型在用户或 agent 施加动作、事件后继续生成有因果一致性的世界状态。官方描述的核心是自回归扩散 Transformer：互联网视频、带时间定位且 schema 校验的事件标注、带键鼠输入的游戏录像、以及带刚体交互元数据的模拟数据共同训练；通过 teacher forcing 和 causal masking 让模型基于先前观测和动作预测未来，再用 distribution matching 与 adversarial distillation 得到少步实时版本。抽象地说，目标是学习 p(o[t+1:t+H] | o[<=t], a[<=t], e)，并让动作条件真正改变未来，而非只改变纹理。

官方结果覆盖 Physics-IQ、WorldMark、机器人臂、Flexion 人形和印度道路驾驶演示：机器人臂只用数十小时示范便展示了漏抓后重新调整夹爪、捡回掉落物等示范中未出现的恢复行为；驾驶实验冻结 backbone、使用 20 小时数据训练 waypoint policy。当前可用研究预览和 API，没有公开权重、论文、完整训练数据或第三方验证。局限在于官方页面没有给出每个机器人任务的试验次数、失败分布、控制频率和安全边界，WorldMark/Physics-IQ 也不能替代真实闭环成功率。

它与 Genie、Cosmos、Sora 类视频世界模型的关系是把实时交互、动作条件和物理榜单放到同一个产品叙事中，但“生成逼真”与“支持策略训练”仍需分开测量。值得深入阅读，优先检查动作注入接口、长时滚动误差和物理榜单的提示词/采样协议。轻量验证可以直接使用 Flash：固定初始 prompt，做“抓取→故意错位→恢复”和“物体推倒→重新摆正”两组干预，记录 8–16 帧后的物体位姿、遮挡后身份保持和动作响应延迟；不要把演示视频当作策略成功率。

2. UNITAS: A 3D-Native World Action Model for Embodied Manipulation｜P0

作者/机构与发布性质：Ruixiang Wang、Bo Yue、Hengyan Liu、Guiliang Liu、Kui Jia 等；香港中文大学（深圳）、DexForce Technology、佛山大学、中山大学、华南理工大学；arXiv: 2610.12099，2026-10-08，预印本。项目代码仓库为 DexForce/UNITAS，项目页为 unitas-wam.github.io。

UNITAS 试图解决现有视频 WAM 在像素空间表达动作、场景和几何关系时难以保持尺度与接触一致的问题。它使用统一的公制 3D 坐标：action flow 表示手/夹爪点轨迹，scene flow 表示动作导致的场景点位移，二者共享 world-aligned 3D positional embedding；物理时间轨迹 tokenizer 把不规则轨迹变成可预测 token，约 1.7B 参数模型同时服务动作流和场景流。训练目标不是只重建像素，而是联合预测动作后果与场景变化，并以 3D 几何作为策略接口。

作者报告在 RoboTwin 的动作条件场景预测中，相比 PointWorld 位移误差最高下降 49%；LIBERO 成功率 99.8%，真实机器人平均任务成功率约 85%。论文还报告了 RoboTwin 场景预测、10,030 个 LIBERO-Plus episode、RTX 5090 推理效率和真实机器人每任务 20 次试验；这些是作者报告，当前没有独立复现。核心创新是把 WAM 从“视频 token + 隐式动作”推到可解释的 action/scene flow 对齐，直接连接预测、规划和 3D 反馈。

局限是场景点云、相机标定和动作流质量会把误差传给模型；真实世界 85% 的任务构成、失败原因和跨机器人迁移细节仍需核对。GitHub 已公开仓库但 README 显示推理/可视化、预训练 checkpoint 和训练评测说明仍在准备，当前不能视为开箱即用复现。值得深入阅读，尤其是 tokenizer、scene-flow/action-flow 的联合损失和长时滚动评估。轻量替代实验：不训练 1.7B 模型，使用公开点云/轨迹数据做 3D flow 的线性或小型 Transformer 预测，与像素未来预测在接触点误差、轨迹漂移和 5 步 rollout 上对比。

3. DreamTrue: Action-Faithful Robot World Model with Counterfactual Post-Training｜P0

作者/机构与发布性质：Junyan Li、Ruizhi Li、Xiangshuo Liu、Lue Fan、Zhaoxiang Zhang 等；中国科学院自动化研究所（NLPR）与阿里巴巴高德；arXiv: 2610.12468，2026-10-08，预印本；项目页 · 代码 · ModelScope 数据/模型入口。

DreamTrue 针对的是“视频看起来合理，但动作改变后未来不跟着变”的动作忠实性问题。它先做离线几何校准，把目标动作轨迹投影到不同视角的视频中，再用共享图像空间 action condition 训练跨视角、跨本体的未来预测；随后对记录动作做反事实修改，生成成功/失败未来，并用人工标注的 robot/object/interaction 缺陷训练 embodied video reward，最后进行 RL 后训练。论文和项目说明涉及 AgiBotWorld-Beta、DROID、RoboMIND 2.0、RoboTwin 2.0，二手项目材料报告约 2,232 小时视频与 153,666 个校准 episode，后者应视为项目/二手披露，仍需以正式数据说明为准。

作者在 AgiBot 记录动作上报告 EWMScore-P 72.51、PSNR 23.06、SSIM 0.936、LPIPS 0.094、nDTW 0.8772；interaction defect 从不含 RL 的 48.12 降到完整模型的 6.25，反事实 nDTW 0.8831，并称在 AgiBot World Challenge 2026 world-model track 排名第一。这些均为作者报告；目前没有第三方硬件复现实验。代码仓库已公开 calibration、wmvideo、reward 目录，ModelScope 有入口，但 README 说明完整数据将后续发布，代码和部分 checkpoint 可得，完整数据闭环未完成。

创新点是把 action calibration、counterfactual data 和缺陷奖励串成后训练闭环，直接测“动作是否改变了正确的接触和结果”。风险是奖励模型可能把可见缺陷当成真实失败，RL 可能在反事实分布上过拟合；二手 AI 评述也指出反事实 reward-loop 的分布偏移还未被独立测量。值得精读，重点核查相机标定误差、反事实动作的可执行性和 success/failure 判别阈值。轻量验证可以只取一个 RoboTwin 任务，构造 5 档夹爪偏移，分别比较视频 LPIPS、末端位姿误差和一个冻结视觉 reward；若像素指标不变而几何/成功标签变化，才说明动作条件有用。

4. SpaceCast-Bench: Benchmarking Predictive Spatial Reasoning｜P0

作者/机构与发布性质：Hongxing Li、Jinyue Su、Dingming Li、Wenqi Zhang、Weiming Lu、Jun Xiao、Yueting Zhuang、Yongliang Shen，浙江大学；arXiv: 2610.12402，2026-10-08；GitHub 与 Hugging Face 数据集 已公开，Apache-2.0。

它把空间智能从静态识别改成“观察—变换—推断”：3,862 个问题来自 182 个真实场景，覆盖 16 类任务、静态感知/局部预测/全局预测 3 个层级。数据由深度验证的视角链、受控 3D 变换和程序化标签构建，模型只看初始场景，需要预测未观察到的结果。问题形式更接近空间状态转移，而不是把视频问答换个提示词。

作者报告最强 baseline 约 58.0%，人类 87.2%；空间专门模型接近随机，bridge view 对结果影响明显，显式 3D 证据比生成的 outcome 图像/视频更可靠。Qwen3-VL-4B 微调后从 34.0% 提升到 65.7%，六个 OOD 任务 macro average 从 33.5% 到 38.1%。这些是论文作者报告，但代码、数据、评测 API 均可下载，复现门槛明显低于大型 WAM。

它与 LIVIN、SpatialBench、RoboSpatial 一类静态/具身数据集的区别是显式测预测和视角变换，正好填补“模型是否有空间动力学”这一缺口。局限是问题仍以离线问答为主，尚未证明分数能预测真实机器人闭环成功。值得今天先跑。轻量实验：在 1 张消费级 GPU 或 CPU 上跑官方评测，分别遮掉 bridge view、打乱视角顺序和加入随机图像干扰，测性能下降；再用 4B 模型做 100–500 条小规模微调，检查增益是否只来自模板记忆。

5. ARC: A Reasoning Recipe for Robot Foundation Models｜P0

作者/机构与发布性质：Gokul Puthumanaillam、Tao Sun、Elie Aljalbout、Moritz Reuss、Zhaoshuo Li、Fabio Ramos、Ankit Goyal、Jenai Xuning Yang 等；arXiv: 2610.12386，2026-10-08，匿名评审预印本；官方项目页。

ARC 研究的是如何不增加新机器人示范、不改基础架构、不做 foundation-scale 训练，仅通过 action-grounded reasoning trace 提升既有 RFM。它从 DROID 自动生成约 75K demonstrations、120 万 action-aligned frames 的 ARC-Trace-DROID，每条 trace 包含 state、cause、consequence、effect、action、avoid、completion；然后对 π₀.₅ 和 Cosmos3-Nano-Policy 采用各自适配的 trace encoder/动作专家训练。对 π₀.₅，事实样本用 flow matching，矛盾 trace 加 counterfactual margin loss。

作者/项目页报告：RoboLab-120 上 Cosmos3-Nano-Policy 36.8%→48.8%、π₀.₅ 28.0%→45.3%；RoboLab-Reasoning-50 上 Cosmos3-Nano-Policy + ARC 61.0%，比基线高 50.0 个百分点；真实机器人 π₀.₅ + ARC 91.7%，基线 9.5%。论文表中还报告 MolmoSpaces 57.6% 和若干零样本增益。结果来自作者的仿真与硬件评测，目前代码、模型和数据均标为 Coming soon，没有独立复现。

创新在于把“解释”约束为下一动作的因果作用，而不是泛化的长思维链；与普通 CoT 或语言计划相比，它有动作级监督和反事实矛盾样本。局限是自动 trace 质量、错误因果标签和硬件任务选择可能决定增益，且没有公开资产时外部验证受阻。值得精读，特别是同一 trace 是否同时提升长时任务、否定指令和场景变化。轻量验证可先在已有 DROID/LIBERO 轨迹上生成 7 字段 trace，用冻结 π₀.₅ 做 LoRA 或小型 trace adapter，对比无 trace、描述性 trace、动作因果 trace 三组，控制训练 token 数。

6. PLaW-VLA: Predictive Latent World Modeling for Vision-Language-Action Policies｜P1

作者/机构与发布性质：Yu Liu 等，吉林大学、Astribot、哈尔滨工业大学（深圳）、香港理工大学、东京大学；arXiv: 2610.12285，2026-10-08；项目页 · GitHub，Apache-2.0。

PLaW-VLA 解决的是视频生成式 WAM 推理太慢、像素重建与动作决策脱节的问题。它冻结 V-JEPA 2 的潜在未来表征，用 Mixture-of-Transformers 分成 VLM expert、预测任务相关未来 latent 的 world-model expert，以及输出连续 action chunk 的 action expert；历史、当前指令、本体感受和未来 latent 通过结构化因果注意力连接。目标是预测“与动作决策有关的未来状态”，而不是重建每个像素。

作者报告 RoboTwin Hard Horizon III 比 reactive baseline 高 11.8 个百分点，zero-shot LIBERO-Plus 比 reconstruction-oriented latent prediction 高 1.77 个百分点，达到相近策略性能时推理延迟约为生成式 WAM 的 1/19。项目页真实机器人表中，Fold Towel 50%、Play Basketball 66.7%、Pack Toy 55%、Organize Stationery 80%，并报告 zero-shot Fold Towel 48.3%；这些是作者报告，尚无第三方复现。

GitHub 已给出代码、训练工作流、公开的 π₀.₅/V-JEPA 2 依赖和 RainyBot/libero_v3_eef 数据入口，但 PLaW-VLA 预训练 checkpoint 标为 Release planned，完整训练仍需多 GPU。它与 DreamZero、VPP2 等生成式 WAM 的关系是用预测 latent 换取低延迟，风险是模型只学到任务相关的短期相关性而没有可滚动的世界状态。轻量验证：使用官方 backbone，在 LIBERO 选 3 个任务，对比 reactive、未来 latent、随机 latent 三组，固定 action chunk 和推理步数，报告成功率、每步延迟、未来 latent 与实际状态的线性可预测性。

7. Cross-Embodiment Robot Foundation World Models with Latent Actions (LAC-WM)｜P1

作者/机构与发布性质：Huang Huang、Sriram Yenamandra、Li Fei-Fei、Jiajun Wu、Tingfan Wu、Franziska Meier 等，斯坦福大学与 Meta FAIR Robotics；arXiv: 2610.10846，2026-10-07；OpenReview 页面显示为 ICML 2026 regular paper，属已接收论文的新窗口 arXiv 版本。项目页。

LAC-WM 解决跨机器人动作空间不一致导致的世界模型迁移问题。它用 V-JEPA 2 视觉嵌入作为状态，在 IDM 中从相邻视觉推断连续 latent action，FDM 预测下一个 latent，motion decoder 用显式运动标签做辅助 grounding；对新机器人只需训练 action projector 把原始控制映射到共享 latent 空间。训练损失联合重建与运动监督，核心假设是“跨本体共享的后果结构”比原始关节/末端动作更可迁移。

作者在未见实例/类别的 imagined rollout 上报告约 27.3–27.5 PSNR、0.037–0.040 LPIPS、8.44–8.51 FID、23.2–24.5 FVD；项目页 LIBERO 5-task average 为 LAC-WM 92.0%，EAC-WM 82.4%，VLA-mean 81.6%，并报告 dexterous 最高提升 46.7%、LIBERO 11.7%。这些数字是作者/项目页报告，虽然论文已被 ICML 接收，当前没有外部复现。

它把 cross-embodiment 从“共享动作 token”推进到“共享潜在后果”，与 UNITAS 的显式 3D flow 形成有价值的对照。局限是 latent action 的可辨识性、IDM 在视觉相似但动力学不同的状态下的多解问题，以及新本体 projector 的数据成本。公开项目页没有确认可运行代码、权重或数据。轻量验证可以用 EgoDex/DROID 的同一任务做 leave-one-embodiment-out：比较原始动作条件、latent projector 和随机 latent 三组，至少报告 unseen body 的 success、latent consistency 和 action reconstruction，而非只看视频 PSNR。

8. RoboRSI: Verifiable Self-Evolving Skill Library for Interactive Agents｜P1

作者/机构与发布性质：Zimo Wen 等、Cewu Lu；Noematrix Lab 团队；arXiv: 2610.12424，2026-10-08；GitHub（Apache-2.0，已公开）· 项目预览。

RoboRSI 研究 agent 如何在交互中修改技能库而不引入不可追踪的回归。Top-Down Skill Refinement 把任务组织成 compound/atomic/base skill tree，每个 skill 有输入输出 contract；Manager、Planner、Engineer、Reviewer 分工，分支内修订、验证后发布、旧版本只读保留，并把复合技能折叠为可复用单元。论文的训练/优化目标更像“通过验证的技能更新”，而不是只提升一次性成功率。

论文表格报告 LIBERO 56.0%（84/150）、LIBERO-PRO 49.5%（297/600）、LIBERO-Plus 42.1%（354/840）、RoboTwin 24.0%（37/154），覆盖率分别为 24/30、102/120、28/30、26/50；multi-agent 在 50 个任务中解决 36 个，single-agent 解决 9 个。项目 README 另有累计 pass 统计，口径与论文 frozen evaluation 不同，不能直接混作一个 benchmark。104 轮实体交互和真实硬件证据应与大规模仿真分开看。

GitHub 提供一键 LIBERO-PRO 重现脚本、append-only journal 和独立 audit，评估时可关闭自演化以冻结策略；不需要公开模型权重，但会依赖 API 与 LIBERO 资产。局限是 agent 提示词、成本、人工 steering 以及技能 contract 的书写质量可能决定结果，持续自演化是否比一次性重新训练更稳仍未充分验证。值得精读。轻量验证可以固定一个 20-task 子集，比较无 reviewer、单 reviewer、多 agent 三组，并强制插入一次错误技能发布，测回滚成功率、回归率、token/调用成本和最终长时成功，而不是只统计累计 pass。

9. USDCraft: Geometrically Grounded Programmatic Modeling of Articulated 3D Assets for Simulation｜P1

作者/机构与发布性质：Chuanrui Zhang、Zaijia Yang、Duomin Wang、Lu Shi、Daquan Zhou、Ruihua Zhang、Ziwei Wang；NVIDIA、南洋理工大学、北京大学；arXiv: 2610.11322，2026-10-08；项目页。

USDCraft 面向 real-to-sim 的瓶颈：普通图像/网格资产缺少可用于物理仿真的关节、碰撞、质量和运动限制。预训练 LLM 生成并迭代修改可执行程序；系统先分析源几何并生成带尺度、部件和不确定性标记的文本描述，再用几何复核、视觉反馈和物理 authoring guidance 修正 USD。目标不是只生成好看的 mesh，而是得到 Isaac Sim 可加载、可碰撞、可铰接的资产。

论文几何表中，USDCraft part F1 84.83 对比 74.48，static gIoU 0.694 对比 0.512，articulated gIoU 0.670 对比 0.495，joint-axis angle 6.83° 对比 21.14°。项目页给出 16 类可下载 USDZ 资产与 sim-to-real 演示：每任务约 200 条模拟示范训练 Diffusion Policy，Astra 在开抽屉、按烤面包机杆、打开烤面包机三个设置的仿真/真实成功率分别为 100/90、90/85、85/85；这些是作者报告，尚无独立复现。

代码和数据页面标为 TODO，项目说明代码预计两周内开放，因此当前应把它当作强方法预览和公开资产样例，而不是完整复现实验。它与 LIVIN 的“生活空间数字孪生”互补：USDCraft 解决可动部件与物理接口，LIVIN 解决完整居住场景。轻量验证无需训练 LLM：下载一个 USDZ，随机扰动关节轴、质量和摩擦，运行 20 个 Isaac Sim 轨迹，测碰撞、可达性和策略成功对资产参数的敏感度；这能直接检查“几何正确”是否真的转化为“控制可用”。

10. LIVIN: Benchmarking Spatial and Embodied Intelligence in Digital Twins of Lived-In Homes｜P1

作者/机构与发布性质：Peijun Xu 等，上海科技大学与 Deemos Technology；arXiv: 2610.12069，2026-10-08，预印本。

LIVIN 关注被实验室清空的桌面场景与真实生活空间之间的差距：30 个 lived-in home digital twins 保留布局、家具、日常物品和部分可动部件，并通过实例识别、建筑结构恢复、物体生成/摆放和人工审核构建。基准覆盖 3D detection、3D reconstruction、navigation、loco-manipulation，研究问题是空间理解、移动和操作能否在杂乱、长期存在的物体关系中共同成立。

作者报告平均每房间 40.15 个物体、密度 3.70 object/m²、可动体 12.17%；用户研究 plausibility 50.87、realism 55.05、mesh quality 60.98。导航中 GPT-6 Astra success 41.48%、SPL 23.59%，loco-manipulation 中抓放 24.4、push/pull 33.3、铰接 61.9、长时 12.5；这些都是作者报告，指标口径和评测 agent 需要复查，当前未找到公开代码或数据下载入口。

价值在于把 Spatial Intelligence 从单物体/单动作扩展到 lived-in、长时、多对象依赖，但局限是人工审核成本高、场景数量仍小，数字孪生真实度与策略迁移之间的因果链尚未闭合。值得阅读数据构建和任务划分部分。轻量验证可以从一个公开室内扫描出发，加入 5–10 个日常遮挡物，比较导航/抓取在“空场景、随机摆放、真实布局”三种设置下的性能，并用对象关系图而非单一图像质量分数解释失败。

11. The Physical AI Toolchain on AWS｜P1

作者/机构与发布性质：Abhishek Srivastav、Adam Weber、Ali Shahrokni、Steven DeVries、Ignacio Sánchez、Jathavan Sriram；AWS 与 NVIDIA 生态；AWS 官方 Physical AI Blog 2026-10-07 的工程栈发布，配套 AWS 官方博客 与 开源 GitHub 仓库。这是基础设施/参考架构，不是新模型论文。

它把数据摄取、Cosmos 3 世界生成、GR00T 微调、Isaac Lab RL、Isaac Sim 软件在环、NVIDIA OSMO 编排和 Jetson/Greengrass 部署串成一个闭环。仓库提供 Zarr/ROS/CSV→LeRobot v2、SageMaker/Batch 训练、Cosmos Predict/Transfer、Isaac Lab 4096 并行环境、GR00T 与 DreamZero LoRA、TensorRT/边缘部署等参考实现，并用 27 条真实遥操作 episode 做 pick-and-place 示例。GitHub 公开样例代码和 IaC，不提供新的基础模型权重；部分组件标为 preview 或 planned。

研究价值在于把“世界模型—数据—仿真—部署—反馈”变成可审计的工程接口，适合复现、回归门禁和多模型替换；局限是云成本、NVIDIA/AWS 绑定、真实硬件覆盖有限，工具链齐全不等于策略具有真实世界泛化。它与 RoboRSI 的技能审计、USDCraft 的资产生成可组合，但仍需独立的成功/失败标签和安全评估。轻量验证可以只部署本地的 ingest→Isaac Lab→GR00T evaluation 子链，不启动完整云集群；用 27 条 episode 做格式转换、checkpoint 完整性、固定 seed 评测和一次故意损坏的回归门禁。

Spatial Intelligence / Frontier 扫描

本轮已扫描 World Labs、Generalist AI、Physical Intelligence、Google DeepMind/Robotics、NVIDIA Robotics/Cosmos/GR00T、Figure、Skild AI、Field AI、1X、Meta FAIR、Anthropic、Toyota Research Institute、Stanford、Berkeley、MIT、CMU、Princeton，以及主要中国机器人/空间智能团队、GitHub、Hugging Face 和项目页。窗口内达到 Top Papers/Models 标准的新增官方发布主要是 Odyssey-3 官方研究预览 与 AWS Physical AI Toolchain 工程栈；其余入口没有检索到更强的新模型/数据集发布。Google DeepMind 的 Gemini Robotics ER2/Robotics-2、World Labs Atlas、Figure Helix 2.5 等最近公开信息均早于本窗口，因此没有机械重复。Anthropic 窗口内可见更新以使用政策/安全发布为主，没有新的 Physical/Agent 模型进入本报。

Spatial Intelligence 一级线索中，SpaceCast-Bench 是今天最可复现的空间预测基准，USDCraft 把 3D 几何推到可执行 USD，LIVIN 把评测推到 lived-in digital twins；UNITAS 和 LAC-WM 则分别代表显式 3D action/scene flow 与跨本体 latent action。候选池还检索到 Being-M0.7、LeWAM、WorldGuide、VGGTWorld-VLA、GATOR、MATE4D、MemoWM、ARC 和 CureWM。Being-M0.7 虽有技术报告，但官方网页日期与 arXiv 日期不一致且无公开权重；LeWAM/WorldGuide 的当前材料缺少足够代码或第三方结果；CureWM 的 arXiv 首次提交为 10 月 6 日 21:26 UTC，早于本轮窗口约 3 小时 35 分，故保留为下期边界候选而非本期条目。这些是选择理由，不代表检索失败。

今日研究地图

问题分类。

  • 世界生成与物理一致性：Odyssey-3、DreamTrue 关注动作条件、因果和反事实；前者强调开放交互与物理榜单，后者强调机器人接触和失败标签。
  • 空间状态与几何接口：UNITAS 用 3D action/scene flow，SpaceCast-Bench 测未知空间结果，USDCraft 把几何转成可仿真的 USD，LIVIN 扩展到生活空间。
  • 跨本体与低延迟控制：LAC-WM 的 latent action、PLaW-VLA 的 future latent 都在降低像素生成与动作控制之间的成本。
  • 行动推理与持续自演化：ARC 将因果理由绑定下一动作，RoboRSI 将技能修改、验证、回滚和复用变成 agent 基础设施。
  • 数据—训练—部署闭环：AWS Toolchain 试图把 Cosmos、GR00T、Isaac Lab、OSMO 与边缘部署接成工程闭环。

近期趋势。 一是从 pixel/video token 走向可度量的 3D 状态、轨迹和空间关系；二是从“生成未来”走向“反事实未来是否对应动作和失败”；三是用 frozen backbone、latent prediction、distillation 和 action adapter 降低部署延迟；四是把 benchmark 从静态问答推进到视角变换、lived-in 场景、长时技能和可回滚自演化。

尚未解决的 gap。 目前还缺一套跨模型的统一协议，同时报告 3D 几何误差、动作后果误差、失败识别、长时 rollout、控制延迟和真实成功率；公司世界模型的榜单分数与机器人任务成功之间仍没有可验证映射；latent action 的物理可辨识性和跨本体 projector 的数据成本没有统一结论；真实居住空间、遮挡、接触和动态变化的数据仍稀缺；自演化 agent 的累计 pass 还缺冻结策略、成本和回归率的共同口径。

今日研究机会与轻量验证

  1. 3D flow 与 future latent 的因果对照：在同一 LIBERO/RoboTwin 子集上，用 UNITAS 风格显式 3D flow、PLaW 风格 future latent 和像素预测做三路小模型；固定数据和 action chunk，比较接触点位移、5 步 rollout 漂移、成功率和单步延迟。
  2. 失败敏感的反事实评测：借鉴 DreamTrue 的缺陷 reward，构造抓取偏移、提前释放、错误旋转三类可执行反事实；每类至少 20 个起始状态，报告成功/失败分数 gap、false-positive rate 与视觉指标的相关性。
  3. 跨本体 latent action 最小实验：在两个机器人本体的同一语义任务上训练 IDM/FDM 小模型，留出第三本体只训练 projector；把动作重建误差、latent consistency 和真实成功率同时作为 gate，避免只报视频质量。
  4. SpatialHarness/SpaceCast 风格的遮挡测试：在 SpaceCast-Bench 上移除 bridge view、打乱视角、添加 distractor，再用 4B 模型微调 100–500 条；若性能不随 3D 证据变化，说明模型在模板匹配而非空间推理。
  5. 自演化审计而非累计成功率：在 RoboRSI 风格 20-task 子集上注入一次错误 skill release，比较单 agent、多 agent、带 reviewer 的回滚时间、回归率、调用成本和长时成功；把 frozen evaluation 作为主结果。
  6. 低成本 real-to-sim 回归：用 USDCraft 的 USDZ 资产或公开 Isaac 资产随机扰动关节轴、摩擦和质量，跑固定策略 20 次；建立几何误差→碰撞率→策略失败的链路，为后续真实数据采集决定最有价值的标注。

证据状态与可复现性

  • 官方发布/公司报告：Odyssey-3、AWS Physical AI Toolchain。Odyssey-3 有研究预览和 API，但无公开权重/训练集/第三方结果；AWS 有公开仓库和 IaC，但无新模型权重，云资源和硬件成本需要单独估算。
  • 作者报告的预印本结果：UNITAS、DreamTrue、SpaceCast-Bench、ARC、PLaW-VLA、USDCraft、LIVIN、RoboRSI。报告中的成功率、榜单和真实机器人数字都应标为 author-reported；当前没有独立硬件复现。DreamTrue 的 ModelScope/代码是部分可用，UNITAS checkpoint、ARC 代码/数据、USDCraft 代码仍待发布。
  • 同行评审状态：LAC-WM 的 OpenReview 页面显示 ICML 2026 regular paper，但本期引用的是 10 月 7 日新 arXiv 版本；论文已接收不等于当前所有工程材料都可复现。
  • 代码/数据可优先验证：SpaceCast-Bench、RoboRSI、PLaW-VLA（模型 checkpoint 尚待发布）、AWS Toolchain。先跑 SpaceCast 的遮挡/视角消融，再跑 RoboRSI 的 frozen audit，能在单卡或 CPU 上得到今天最可靠的增量证据。
  • 检索失败与筛选区分：本轮确实执行了 arXiv、官方入口、GitHub/HF 与 broader web 交叉检索；未进入正文的条目都有窗口边界、证据不足、无新版本或缺乏可复现材料的记录，没有把未检索到的重要工作包装成“主动筛选”。

今天先读 Odyssey-3 的动作接口和 UNITAS 的 3D flow，再用 SpaceCast-Bench 做遮挡/视角消融；如果要在自己的系统上动手，优先验证 DreamTrue 式失败敏感性和 PLaW-VLA 式低延迟 latent，而不是直接复现大模型训练。
