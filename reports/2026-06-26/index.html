【🚨 今日重点】

  1. Claude Code 重大升级 / Karpathy 称"LLM 第三次变革"（公众号·36氪 6月25日） - Anthropic 发布 Claude Code 大版本更新，被 Karpathy 评价为"第三次变革"。Anthropic 内部约 65% 产品代码已由 Claude 参与完成。Karpathy 此前也公开承认自己 12 月以来已"完全没写过一行代码"。来源：量子位 / 36氪。

  2. HIL-ResRL：1 小时真机 RL 微调成功率破 95% 的 VLA 通用"外挂"（公众号·量子位 6月23日） - 即插即用的"人-在-环 + RL"微调框架，1 小时内即可在真机上完成 VLA 模型强化学习微调，跨任务成功率 >95%，有望成为具身智能领域的"瑞士军刀"。

  3. GLM-5.2 全面铺开：智谱 744B MoE 1M-Context 模型引爆国产开源"长时任务"新阶段（公众号·Hugging Face Blog / Interconnects 6月13–17日） - 6月13日发布，1M 上下文稀疏 MoE 设计，定位长时任务（agent / coding），百度智能云 Token Plan 第一时间完成适配。Karpathy / Nathan Lambert 均称其为 "step change for open agents"。

━━━ 顶级研究组新发布 ━━━

  • 《Autodata: An agentic data scientist to create high quality synthetic data》（arXiv cs.AI 6月25日, Meta AI + 多机构合作）

  • 由 Ilia Kulikov、Yixin Nie、Yoram Bachrach、Jason Weston 等作者提出"agentic 数据科学家"，由多个 LLM agent 协作生产高质量合成数据。

  • 《The Unfireable Safety Kernel: Execution-Time AI Alignment for AI Agents》（arXiv cs.AI 6月25日）

  • Seth Dobrin 等提出面向"可逃逸 AI 系统"（含 agent）的执行时对齐机制，呼应最近 LLM-as-Agent 失控事件频发的趋势。

  • 《Robots Need More Than VLAs & World Models》（arXiv 2606.06556, 6月初挂出, 持续热度）

  • 一篇对当前具身基础模型路线（VLA + World Model）系统反思的综述。alphaXiv 在过去 3 天内被多次引用。

  • 《Yann LeCun's World Model Earns a Formal Proof》（科技媒体·TechTimes 5月31日）

  • LeCun 团队两篇预印本给出 JEPA 架构何时严格可学习/可证明的 formal proof，回应 "vibe coding" 后他离开 Meta 创办 AMI Labs（已融资 $5B）的新路线，被广泛视为"World Model 范式"的里程碑。

  • Microsoft Agent Framework @ Build 2026（科技媒体·微软 devblog 5月31日 / 6月2–3日大会）

  • Build 2026 上发布 Microsoft Agent Framework，重点强调 multi-agent、agent harness、可观测性、tool calling。距今 3 周内仍是企业级 agent 落地最被引用的开发框架之一。

━━━ 生成模型 / 新范式 ━━━

  • 《MVTrack4Gen: Multi-View Point Tracking as Geometric Supervision for 4D Video Generation》（arXiv cs.CV 6月25日, KAIST + 东京大学 + Stability 等）

  • 用多视角点跟踪作为 4D 视频生成的"几何监督信号"，结合扩散模型产出高保真 4D 视频，是 4D GS / 视频生成交叉点新工作。

  • 《DomainShuttle: Freeform Open Domain Subject-driven Text-to-video Generation》（arXiv cs.CV 6月25日）

  • 快手 / 中科大系作者群提出在开放域、任意主体驱动下的文生视频框架，对标 Runway Gen-4 / Pika 2.0。

  • 《MIMFlow: Integrating Masked Image Modeling with Normalizing Flows》（arXiv cs.CV 6月25日, 北大 + 阿里）

  • 阿里 + 北大 MIM + Normalizing Flow 端到端图像生成新思路，是 MIM 在生成方向上沉寂多年后的新一轮尝试。

  • 《Concept Removal for Frontier Image Generative Models》（arXiv cs.CV 6月25日, CISPA / Tübingen）

  • 针对 Sora / Imagen / Flux 等前沿文生图模型的"概念擦除"机制，给出统一评测与算法。

  • Fast-dLLM v2：Block-Diffusion LLM 加速新框架（NVIDIA Research 持续推进）

  • 把预训练 AR 模型高效转换为 block-diffusion LLM，主打"并行解码 + 双向上下文 + 自纠错"，被开发者社区视为 LLM 推理侧新范式候选。

━━━ 多模态 / VLM ━━━

  • 《How Robust is OCR-Reasoning? Evaluating OCR-Reasoning Robustness of VLMs under Visual Perturbations》（arXiv cs.CV 6月25日, 吉林大学）

  • 系统评测当前 VLM 在视觉扰动下做 OCR 推理的稳健性，发现多家 SOTA VLM 在低质量、噪声、几何扰动下表现"塌方"。

  • 《TriViewBench: Controlled Complexity Scaling for Multi-View Structural Reasoning in MLLMs》（arXiv 6月25日, 清华/北航）

  • 三视角结构化推理 benchmark，用受控复杂度增长对 MLLM 进行细粒度评估。

  • 《ShutterMuse: Capture-Time Photography Guidance with MLLMs》（arXiv cs.CV 6月25日, 中科院 + 鹏城）

  • 把 MLLM 拿来做"拍摄时实时摄影构图指导"，拍前 / 拍中给用户构图与参数建议。

  • 《Dual Distribution Estimation for Zero-shot Noisy Test-Time Adaptation with VLMs》（arXiv cs.CV 6月25日, 北大 + 阿里达摩院）

  • VLM 在零样本 + 测试时噪声条件下的分布估计与适应，弥补 VLM 在部署端鲁棒性的痛点。

  • 《SurgAtlas: 2,391 Hours of Open and Minimally Invasive Surgery》（arXiv cs.CV 6月25日, 密歇根大学等）

  • 史上最大规模开放手术视频-语言数据集，医学 VLM 的"ImageNet 时刻"。
