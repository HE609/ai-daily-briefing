📅 2026-06-23 AI Daily Briefing

时间窗口：2026-06-20 ～ 2026-06-22（72h 内新发布 / 重大进展）

🚨 今日重点（2-3 条最值得关注的新发布）

  1. 英伟达 Rubin 平台量产前最后技术披露，全面液冷架构细节公开 — 当地时间 6 月 21 日，英伟达官方博客发文，详细介绍即将量产的 Rubin 平台全液冷技术，称之为"数据中心历史上最重要的能效突破"。结合上月底 GTC Taipei 上发布的 Cosmos 3 物理 AI 基础模型，Rubin 是英伟达 2026 下半年最大硬件变量。来源：财联社 / NVIDIA 博客

  2. OpenAI 与三星电子达成 ChatGPT & Codex 企业部署 — 6 月 22 日 OpenAI 官方宣布：三星电子将面向员工部署 ChatGPT 与 Codex（OpenAI 的 agentic coding 工具），标志着传统硬件大厂全面接入 agentic 编程体系。来源：OpenAI News / 公众号

  3. PaddleOCR-VL 登顶 CVPR 2026 Highlighted Papers，文本-视觉多模态 OCR 新 SOTA — 百度 PaddleOCR 团队的 VLM 版本同时在 page-level 解析和 element-level 识别上达到 SOTA，已被 CVPR 2026 官方 Highlight，是工业级 VLM 在文档理解上的里程碑。来源：CVPR 2026 官网 / 百度智能云

🏛️ 顶级研究组新发布

  1. Yann LeCun (AMI Labs) 团队 LeWorldModel 持续被引用与扩展 — 5 月底 LeWM 论文（arXiv:2603.19312）实现首个端到端稳定训练的纯像素 JEPA，仅用 1D 数学 + 两项损失函数；6 月以来 LinkedIn、Medium、X 多个技术圈出现系统级解读，并被 Reddit r/artificial 列为"JEPA 终于可信"的关键证据。来源：arXiv / Medium / Reddit / LinkedIn（注：论文首发 5 月，但 6/20-22 仍在被顶级圈子广泛讨论与复现）

  2. Google DeepMind "D4RT" 一举拿下 CVPR 2026 Best Paper — 论文抛弃计算机视觉沿用 20 年的"点对应估计"思路，提出统一的 D4RT（Differentiable 4D Ray Transformer）模型，可同时处理 depth / optical flow / scene flow，训练数据量比单任务 SOTA 减少约 70%。来源：CVPR 2026 Awards / LinkedIn

  3. Google DeepMind "内部 AI Agent 当内鬼对待"安全框架 — 6 月 19 日 DeepMind 公开一份 alignment+containment 双层 Agent 控制框架，将 Agent 视为"insider threat"进行权限分层。来源：LinkedIn / DeepMind Blog

  4. Meta/AMI Labs Causal-JEPA 实证：物体级潜在干预显著提升世界模型因果性 — arXiv:2602.11389 的 C-JEPA 已被纳入多个新研究的 baseline（6 月持续被引）。来源：arXiv

  5. MIT 与 Caltech 联合 ICCV-style 工作 Log Analysis is Necessary for Credible Evaluation of AI Agents — Jacob Steinhardt (UC Berkeley) 团队主张：必须用 log analysis 而非纯 benchmark 评估 Agent，这将成为下半年 Agent 评测范式转变的旗手论文。来源：arXiv / Berkeley Publications

🌐 生成模型 / 新范式

  1. 阿里 HappyHorse 1.1 视频生成模型发布，五大维度全面升级 — 量子位 6 月 21 日报道，阿里发布 HappyHorse 1.1，对运动、镜头、物理一致性、prompt 遵从、长视频稳定性五大维度做了系统级改进，目标是与字节 Seedance 2.0、字节可灵 3.0、Google Veo 3.1 同台竞争。来源：量子位 / 阿里通义

  2. Qwen3.5 全家桶已稳定，开发者社区出现系统级基准对比 — Reddit r/LocalLLaMA 6 月 21 日发布"Best local model for vision 2nd benchmark update"，把 Qwen3.5-Flash、Qwen3.5-122B-A10B 等放在视觉 benchmark 第一线。来源：Reddit r/LocalLLaMA

  3. Gemini 3.5 Live Translate 6/14 上线后进入实战评估 — 6/14 发布的 70+ 语言实时语音翻译，过去一周被多个开发者社区（Scouts by Yutori、r/GeminiAI）做端到端测评，普遍认为翻译延迟已接近人类同声传译员。来源：Reddit / Scouts by Yutori

  4. DeepSeek V4 已成"标配"：内部 Agentic Coding 模型正式落地 — DeepSeek 在 4 月 24 日发布 V4 预览版后，6 月起被内部员工用作日常 agentic coding 模型，对外评测显示其使用体验优于 Anthropic Sonnet 4.5、接近 Opus 4.6 非思考版本。来源：钛媒体 / 21 财经（注：原始发布已超 2 周，但 6 月生态影响仍在持续）

👁️ 多模态 / VLM

  1. CARE 框架：面向多模态推理的自适应长度优化 — 6 月 22 日 arXiv cs.CV 新发布，提出 competence-aware reward shaping，让多模态推理模型按"题目难度"动态决定 CoT 长度，显著降低过度思考。来源：arXiv

  2. AudioX-Turbo 发布，920 万样本 IF-caps-Pro 数据集开源 — 知乎 arxiv 每日论文专栏 6/22 转载：面向音频生成的多模态大模型，配套数据集 IF-caps-Pro 含 920 万高质量样本，分两阶段标注。来源：知乎专栏 / arXiv

  3. PaddleOCR-VL（百度）CVPR 2026 Highlighted — 端到端文档理解 VLM，在 page-level 和 element-level 双榜 SOTA，是工业级 VLM 在 OCR 领域的新基线。来源：CVPR 2026 官方

  4. MMReasoning / Next Forcing 框架（6/10 起被持续讨论） — 因果世界建模下的 multi-chunk prediction 框架，受 LLM 中 multi-token prediction 启发，可在因果视频预测中实现"训练更快、精度更高、推理更快"三重收益。来源：知乎专栏 / arXiv

🤖 具身 / VLA / 机器人

  1. 上海交大 MINT 团队：0.9B 参数 VLA 跑出 90% 真机成功率，补上空间感 — 量子位公众号 6/22 推送：传统 VLA 普遍依赖 2D 视觉，对遮挡、细摆放判断不准。MINT 团队用 0.9B（极小规模）参数 + 3D 空间编码，实现 90% 真机成功率，是当前"小而强"具身模型的代表。来源：量子位 / 新浪财经 / arXiv

  2. AMAP CV Lab（高德地图）发布 ABot-Manipulation 通用 VLA — 机器之心 6/22 报道：高德 CV Lab 推出面向机器人操纵场景的通用 VLA 基础模型，创新采用 action 流形学习范式，整合超 600 万条开源轨迹数据，支持即插即用 3D 感知模块。来源：机器之心

  3. 极佳视界新 VLA 模型：以世界模型微调策略网络 — 用大规模机器人操作数据先训练 world model，再以 world model 输出的"未来状态 + 价值"为条件微调策略网络，特别适合复杂长时程任务。来源：智源社区 hub.baai.ac.cn

  4. 智平方郭彦东：世界模型与 VLA 不是竞争，而是协同 — 6/15 北京智源大会期间，智平方创始人郭彦东公开表态：未来通用机器人将既需要 VLA 端到端反应，也需要 world model 提供"想象未来"能力，二者融合是 WAM（World-Action Model）方向。来源：观察者网 / 智源大会

🧠 Agent / 大模型

  1. Self-Harness：让 AI Agent 改写自己规则的框架，性能提升最高 60% — VentureBeat Ben Dickson 6/22 报道：研究者提出 Self-Harness 框架，Agent 可在沙箱内动态重写自身的 prompt / 工具调用规则，在 SWE-Bench / APEX Agents 等多项基准上较 Claude Code、Codex 提升最高 60%（同等算力）。来源：VentureBeat

  2. Windsurf 正式更名为 Devin Desktop（Cognition 旗下） — 6/2 起生效：原 Windsurf 团队被 Cognition 收编后统一品牌为 Devin Desktop，Cascade agent 引擎继续保留。这是 vibe coding 赛道 6 月最大整合事件。来源：lushbinary / morphllm

  3. Claude Code 占据 agentic coding 工具主导地位 — MarkTechPost 6/14 深度评测 2026 主流 coding 工具：Claude Code 在 25 个维度综合领先，与 Devin Desktop、Cursor、GitHub Copilot $100 Max Plan 形成新四强格局。来源：MarkTechPost

  4. "AI is about to replace the interface" — VentureBeat 6/9 深度观点 — 企业软件正从"点界面"过渡到"Agent 跨系统推理并执行动作"，对 ERP / CRM / SaaS 中间层冲击巨大。来源：VentureBeat

🧬 AI for Science

  2. Gemini Robotics-ER 1.6 上线实验科学自动化 — 6 月 19 日起 Google AI for Developers 文档更新，Gemini Robotics-ER 1.6 成为科研机器人基础模型，可被实验室自动实验台调用（6/19 后 Gemini API 收紧无限制 key）。来源：Google AI Developers

  3. C-JEPA 论文进入机器人 / 物理实验引用榜单 — 在动态环境下的潜在干预框架，被多个 AI for Science 工作引用为世界模型新基线。来源：arXiv
