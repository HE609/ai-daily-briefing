今日精读顺序

今天我建议的精读顺序是：Praxis-1 → WorldDraft → PhysCapBench → Reins → Rethinking Actions。

  • A｜Praxis-1。先读公开 WAM 的完整训练契约、动作与视频联合预测，以及真实硬件和仿真边界，建立可运行基线。
  • B｜WorldDraft。再读可执行 4D 世界如何把几何、事件和相机路径固定成 renderer benchmark，避免把视频逼真度当作世界模型能力。
  • C｜PhysCapBench。随后检查物理语言监督怎样被拆成可核验的实体、事件、接触和状态变化。
  • D｜Reins。接着看通用多模态模型怎样通过 guarded chain、narrator 和 scene twin 进入长时真机闭环。
  • E｜Rethinking Actions。最后读动作连续性先验怎样改变冻结世界模型的候选搜索，适合做小算力复核。

1. Praxis-1：From Video Pretraining to Robot Control｜P0

作者与机构、时间、性质。 Runway Robotics 团队，官方模型发布与技术报告。首个公开权重公告为 2026-11-11，当前窗口新增了 SO-100/SO-101 checkpoint、NVFP4 版本和 LeRobot 接入，Hugging Face 集合在本轮显示为近期更新。前一期没有收录公开权重，本期按“检索遗漏 + 当前窗口新硬件适配”补录。入口包括 官方开放权重公告、技术报告、Apache-2.0 代码 和 Hugging Face 模型集合。

它解决的是机器人数据稀缺和动作策略缺少视觉未来的问题。Praxis-1 用 27B 参数的 MoE video-diffusion backbone 预测下一段视频，同时让小型 action expert 从视频隐状态产生动作。视频路径使用冻结的 Wan2.2 VAE 和 Qwen3.5-2B 文本编码器，20 个前馈层中 17 层使用 MoE。中训练阶段改为 chunk-causal attention，每个 1.6 秒、6 个 latent frame 的未来块只能看过去块。训练目标保持视频预测，并在 embodied-video、action mid-training 和 embodiment-specific post-training 中加入动作损失。SO-101 checkpoint 进一步把输出映射到 5 个关节加夹爪的 6D joint-space action head。

作者与官方榜单报告 RoboLab-120 1,200 episodes 上 46.2% success，高于 FLUX 3 Action 42.9%、Cosmos3 Nano 36.8% 和 π0.5 28.0%。在未见过的 Google RT-1 embodiment 上微调后，官方报告 SimplerEnv 80.0%，RT-1 原策略为 52.4%。这些数字属于 Runway 官方报告，尚无独立实验室复跑。代码、推理、LoRA/全量微调、MuJoCo simulator、DROID/YAM/SO-101 checkpoint 已公开。单个 checkpoint 约 54.4 GB，官方仓库要求至少 80 GB GPU、CUDA 13 和 Python 3.12，NVFP4 可降低路由专家推理成本。

创新点在于把一般视频预训练直接接到 action-conditioned WAM，并通过薄的 per-robot projection 支持不同 embodiment。它与 GR00T 2、Cosmos、π0.5 和其他 VLA 的关系是共享“视频或未来状态帮助动作”的目标，Praxis-1 更强调一个开放、可运行、带视频未来的策略包。局限包括 look-alike object、模糊指令和单提示多步骤任务，长时状态仍需要外部分解。值得深入阅读。 轻量验证优先运行公开 DROID MuJoCo 单任务和 SO-101 预处理检查，比较 bf16 与 NVFP4 的视频未来、动作误差、延迟和成功率，再把同一 checkpoint 的 1.6 秒预测与真实下一帧逐步对齐，不需要重新训练 27B 模型。

2. WorldDraft：If Code Builds the World, Can Video Models Just Render It?｜P0

作者与机构、时间、性质。 Zhiyu Hou、Wen-Jie Shu、Harold H. Chen、Weilin Ruan、Chenfei Liao、Liuzhou Zhang、Disen Lan、Xiaogang Xu、Qi Chen、Ser-Nam Lim，来自 SUSTech、ZODA、HKUST、CUHK、HKUST(GZ)、FDU、ZJU、UCF。arXiv v1 于 2026-11-12 03:09 UTC 提交，代码和 benchmark data 于 11 月 11 日开放，论文于 11 月 13 日在仓库标记为 released。性质为预印本、Apache-2.0 代码与数据集发布，尚无同行评审或第三方复跑。入口包括 论文、项目页、代码 和 Hugging Face 数据集。

WorldDraft 研究一个对 Spatial Intelligence 很关键的问题：当多模态 coding agent 已经用 Blender 或其他 simulator 构造了可执行的 4D 世界，视频模型能否只负责把它渲染成目标外观。数据包含 48 个 executable world families、6 类动态挑战、432 个严格配对案例。3×3 设计保持动力学和目标文本不变，改变 draft granularity（abstract、simulation、previs）与 appearance alignment（neutral、aligned、conflicting）。评测同时看 world preservation、rendering fidelity、appearance persistence 和 source leakage，指标包含 instance mask、bbox、track coverage、event timing、相机轨迹和属性持久性。

作者在 12 个视频模型上发现世界保持和外观实现存在明显张力。更丰富的 previs draft 能固定结构，却会降低外观绑定。冲突外观最高出现 64% source leakage。WorldDraft-Primer 是推理时视觉提示策略，无需重新训练。官方表中，OmniWeaving 加 Primer 后 preservation 从 61.61 提升到 64.60，realization 从 66.37 提升到 70.93，source leakage 从 50.97% 降到 47.55%，overall 从 57.62 提升到 60.13。MiniMax-H3 的 overall 从 63.63 提升到 65.56。结果来自作者自建 benchmark，模型输入协议和视觉提示模板会影响数字。

它与 Atlas、Spatial Foundry、BWM-Forge、Genie/WorldFoundry 的关系是把“可编辑世界”推进到可量化 renderer contract。局限是 48 个程序化世界仍集中在可控 Blender 场景，外观质量和物理可执行性分属不同证据链，不能把 renderer 分数直接解释为机器人成功。值得深入阅读。 轻量验证只下载 805 MB 数据中的 6 个 world families，先用一个开源视频模型跑 P0/P1/P2 三档 draft，再计算 camera error、entity persistence、event timing 和 source leakage。先复核指标实现，再决定是否接入大型商业模型。

3. PhysCapBench：A Cross-Domain Benchmark for Physically Grounded Video Captioning｜P0

作者与机构、时间、性质。 Haofeng Wang、Pengcheng Wen、Ruiqi Li、Yuhao Zhang、Tiange Zhang、Boren Zheng、Xuanyi Liu、Siyu Tao、Danni Yu、Gan Lin、Haocheng Tang、Tianzizhe Guo、Mingyuan Su、Boyuan Chen、Zhongyuan Wang，来自北京智源人工智能研究院、北京大学、清华大学、北京航空航天大学和 Physis。arXiv v1 于 2026-11-12 07:33 UTC 提交，性质为技术报告预印本。入口包括 论文、项目页 和 Hugging Face 数据集条目。

它处理的是视频语言监督经常描述“发生了什么”，却遗漏接触、因果、形变和状态变化的问题。PhysCapBench 将 third-person physical scenes、egocentric human manipulation 和 multi-view handheld-gripper demonstrations 放入同一协议，共 1,500 个序列，每个域 500 个。标注组织实体、事件、状态和关系，沿七个 physical dimensions 计算准确性与覆盖度。七名数据标注员依据帧区间、相机视角、手部角色和前后状态进行交叉复核，最终记录保留 evidence references 与字段级不确定性。训练目标落在 caption quality、video reconstruction 和 manipulation-policy instruction enrichment 三个下游接口。

作者报告物理 captions 相对 metadata captions 将 third-person 视频重建 LPIPS 降低 8.6–9.5%，egocentric 视频降低 26.9–30.9%。在 RoboTwin 2.0 的一个 π0.5 子任务上，instruction enrichment 带来 7.5 个百分点成功率提升。结果来自作者实验，尚无第三方复跑。项目页和 HF 数据集入口可见，数据文件版本、许可证和完整代码本轮没有全部核实，因此不把“页面可见”写成完全可复现。

它与 Physis-Lang、Ego4D、UMI、FineVLA、WGO-Bench 和 PhysCapBench 前身的关系，是把物理语言从提示工程提升为可审计的数据质量变量。局限包括 caption 仍受可见性限制，语言描述无法直接补齐不可观测接触力，三个域的采样分布也不能代表所有 robot data。值得深入阅读。 轻量验证可先抽取每个域 30 个样本，比较 metadata caption、通用 VLM caption 和物理模板 caption 的实体、接触、事件时序 F1，再把三组描述接入同一个冻结小型视频预测器或 VLA，分开报告 caption score 与策略成功。

4. Reins：Frontier Multimodal Models Driving Real Robot Arms on Long-Horizon Tasks, Zero-Shot｜P0

作者与机构、时间、性质。 Pengfei Ye、Zhiyang Dou、Yuxiang Ma 来自 MIT CSAIL，Haonan Chen、Heng Yang 来自 Harvard University，Edward H. Adelson 来自 MIT CSAIL。arXiv v1 于 2026-11-12 11:05 UTC 提交，性质为预印本与真机系统报告，论文称代码将在发表时公开。入口包括 论文 和 项目页。

Reins 研究通用多模态模型如何处理接触丰富、长时、场景会在模型思考期间变化的真机任务。actor 使用 3D perception tools 和返回接触/抓取状态的 atomic actions，把带条件的动作链放在同一次调用中，条件失败时立即停止。narrator 由另一个模型实例持续观察摄像头，在 actor 等待期间维护 scene change 记录。系统从一帧 head-camera image 构建可进入 MuJoCo 的 simulation-ready twin，用于后续策略学习。方法的关键训练目标是运行时验收和可重规划，当前没有 task-specific policy training。

作者报告 GPT-6.1 Sol 在五个真实任务上的 episode success 88%。去掉 harness 后 shell game 五次均失败，加入 narrator 后 Sol 从无 narrator 的 2/5 提升到完整条件下的报告结果。三种 frontier model 的总体表现相近，但对模型思考期间的场景变化追踪能力不同。实验每个条件只有五个 episode，单一双臂平台，接触主要由 joint current 和 gripper width 估计，结果全部属于作者报告，暂无第三方验证。

它与 Show-Harness、RoboScript、ACE-CaP-0、LEASH 和 Code-as-Policies 的关系，是把“调用原子技能”推进到带条件、带旁观者、带 scene twin 的闭环 Agent。局限包括 narrator 延迟、模型 API 成本、单平台和小样本，scene twin 目前只展示对象动力学，无法证明完整物理复制。值得深入阅读。 轻量路线是先在离线日志中回放 actor/narrator 时间线，构造 shell-game 类 toy environment，比较 raw image、guarded chain、guarded chain+narrator 三组的 state-change detection、错误动作数、重规划延迟和调用成本，避免直接复现真机。

5. Rethinking Actions：Continuity-Aware Priors for World-Model Planning｜P1

作者与机构、时间、性质。 Shaobo Yang、Zichen Ai、Ziyang Ma、Qian Yang、Bin Fang，来自北京邮电大学、阿里巴巴集团与蚂蚁集团。arXiv v1 于 2026-11-12 11:18 UTC 提交，性质为预印本，代码使用 MIT License，权重与固定 world model 资产通过 Hugging Face 分发。入口包括 论文 HTML、代码 和 权重。

它处理冻结视觉世界模型在候选动作搜索中容易提出“局部看起来合理、时间上却不连贯”的问题。LG-DKGP 使用 locality-gated history encoder，把近期动作和较长阶段历史分别编码，neural mean 预测连续动作延续，temporal Gaussian-process residual 建模剩余结构，再用从专家动作增量估计的 exploration scale 初始化 CEM 搜索。训练先拟合 neural mean，再以专家未来动作共同优化 GP residual。冻结 world model 只负责把候选动作 rollout 到目标视觉状态并计算规划分数。

五个模拟任务的 macro success 为 87.07%，对比 INTACT 71.03%、PRISM 61.66%、LeWM 58.66%。PushT、Cube、LIBERO Caddy、LIBERO Scene2、RoboTwin 分别为 97.60%、98.80%、83.32%、76.96%、78.66%。代码仓库提供五任务配置、五个 evaluation seeds、checkpoint binding、数据和环境说明，作者报告包含作者复跑结果，第三方复跑尚无。仓库要求 Linux x86-64、Python 3.10、单张 CUDA GPU，原始数据和 native scene fixtures 需另行下载。

它与 LeWM、PRISM、INTACT、action prior 和 CEM world-model planning 相连，贡献集中在动作时间结构和搜索初始化。局限是全部结果仍在模拟器，world model 与 prior 的绑定容易造成任务特定收益，RoboTwin native success 与 fragment-level goal attainment的定义也需逐项核对。值得深入阅读。 轻量验证可直接下载公开 prior 和 paired LeWM，在 PushT 与 Cube 各运行五个 seeds，再做 history length、horizon/execution、随机 action prior 与无 history 对照，优先验证收益来自连续性还是来自额外搜索预算。

6. ActWorld-JEPA：Action-Conditioned JEPA World Models Meet Latent Planning for End-to-End Autonomous Driving｜P1

作者与机构、时间、性质。 Ziying Song、Shengkai Zhang、Caiyan Jia、Lei Yang、Lin Liu、Yuchen Liu、Ziyang Liu、Zirui Li、Gang Wang、Peiliang Wu、Li Wang、Yadan Luo、Chen Lv，来自南洋理工大学、北京交通大学、大连理工大学、北方工业大学、清华大学、北京理工大学、宁波工程学院、昆士兰大学等。arXiv v1 于 2026-11-12 10:10 UTC 提交，性质为预印本、Apache-2.0 代码与权重发布。入口包括 论文、代码与权重 和 项目页。

ActWorld-JEPA 研究 latent predictive consistency 怎样转化成候选轨迹选择。PC-JEPA 用 global and step-wise trajectory intentions 条件化 latent future rollout，再通过 gated cross-attention 与当前场景融合。Relational Residual Reranking，也就是 R³，建模 plan 与 predicted future 的一致和差异，用 bounded residual 修正基础 planner score。训练目标同时包含 latent future prediction、候选计划排序和 planning feedback，推理时只需要观察上下文与候选轨迹。

作者报告 NAVSIM v1 navtest 94.1 PDMS，NAVSIM v2 navtest/navhard 为 91.6/42.7 EPDMS，nuScenes 1–6 秒平均轨迹 L2 为 1.20 m，预测碰撞率 0.76%。仓库提供 NAVSIM v1/v2、nuScenes 的代码、选择器和模型 bundle，README 明确这是 inference/evaluation release，尚无完整 from-scratch training recipe，官方 GPU clean reproduction 尚未完成独立验证。

它与 Drive-JEPA、DriveWorld、DriveFuture、GraphWorld、Cosmos-Drive-Dreams 和候选轨迹 reranking 工作相连，价值在于把“未来表示”绑定到“哪条轨迹更好”。局限是 NAVSIM 的 candidate set 和 aggregate calibration 会影响分数，offline replay 不能自动推导到真实闭环驾驶。值得深入阅读。 轻量验证可用公开模型跑 12,146-scene regression 的小子集，分别关闭 PC-JEPA、关闭 R³、只保留 baseline planner，记录候选覆盖、score calibration、碰撞预测和单场景 FPS。

7. BlinkMimic：Training a Humanoid Motion Tracker in Minutes on a Single GPU｜P1

作者与机构、时间、性质。 Fuyi Chen，Fortune AI technical report，arXiv v1 于 2026-11-12 07:31 UTC 提交，性质为预印本与 MIT License 代码发布。入口包括 论文 和 代码。

BlinkMimic 研究 humanoid whole-body tracking 怎样把世界模型反向传播和模拟器成本压到单张消费级 GPU。它继承 SuperMimic 的 differentiable world model 和 InstantTrack 的 Muon update、residual policy、EMA policy，引入随训练进度衰减的 step size、由部署失败驱动的 reset allocation，以及把 policy inference、physics、reward 和 reset 放进 CUDA graph 的 host-free iteration。训练目标是同一策略覆盖全部 40 个 LAFAN1 clips，同时压低 late failure。

在模拟 Unitree G1 上，40 个动作片段、三 seeds、单张 RTX 4090 达到 return 0.82 且连续三次 checkpoint 无失败的平均时间 3.38 分钟，最终 return 0.861，14 个 tracked bodies 的 RMS position error 约 4.1 cm。相对重新运行的 InstantTrack 7.36 分钟，训练时间约减半。作者明确报告一个机器人、一套动作库、单 GPU、无真实机器人部署，late flips 仍然存在。代码、逐 seed 结果和锁定环境已公开，暂无第三方复跑。

它与 SuperMimic、InstantTrack、MuJoCo Warp 和 model-based RL 的关系，是把“训练时间”拆成 fit、tail 和 iteration 三个可审计成本。值得深入阅读。 轻量验证只跑公开 5 个 LAFAN1 clips，比较 full recipe、无 failure-directed reset、无 CUDA graph 三组，记录 wall-clock、late failure、RMS error 和 GPU 利用率，先验证成本分解再迁移到其他 humanoid。

今日研究机会与轻量验证

  • Praxis-1 开放 WAM 基线。在一台 80 GB GPU 上只跑 DROID 的单任务 simulator evaluation，记录 video future consistency、action chunk error、success、latency 和显存。随后比较 bf16 与 NVFP4，保持同一 checkpoint、seed、prompt 和 episode。
  • WorldDraft 结构—外观解耦。从 48 个 world families 中抽取 6 个，固定目标文本和动力学，只改变 P0/P1/P2 draft。使用一个开源 renderer 复现 preservation、appearance persistence 和 source leakage，先验证评测代码的 frame sampling 与 mask 对齐。
  • PhysCapBench 语言监督。每个 domain 抽取 30 个样本，比较 metadata caption、通用 VLM caption、物理模板 caption。把三组 caption 接到同一个冻结视频预测器和一个冻结 VLA，分别测 caption F1、reconstruction LPIPS、action success。
  • Reins harness 离线原型。在 toy grid-world 或 MuJoCo 简化任务中记录 actor/narrator 时间线，比较 raw image、guarded chain、guarded chain+narrator。把 success、错误动作、重规划延迟和 API/token 成本绑定到 episode id。
  • Rethinking Actions 小算力复核。优先跑 PushT 与 Cube 的公开五 seeds，做 history length 0/短/长、horizon/execution 25/25 与 10/10、随机 prior 与 LG-DKGP 三组对照。重点检查 action continuity 是否带来候选覆盖变化。
  • ActWorld-JEPA 选择器审计。运行 12,146-scene regression 的小子集，关闭 PC-JEPA 和 R³，检查 candidate set、score calibration、碰撞率和单场景 FPS。offline replay 结果单独记录。
  • BlinkMimic 成本拆分。只训练 5 个 LAFAN1 clips，分别关闭 failure-directed reset 与 CUDA graph，报告 fit time、tail time、late flip 和 RMS error。该实验可在单张 RTX 4090 上完成，适合先验证机制再迁移到 humanoid。
