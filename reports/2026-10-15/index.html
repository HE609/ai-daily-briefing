空间智能与通用 AI 科研晨报 ｜ 2026-10-15

检索窗口为 2026-10-12 09:03—2026-10-15 09:03（Asia/Shanghai）。本轮并行检查了 arXiv cs.RO/cs.CV/cs.AI/cs.LG 最新批次、主要 frontier lab/company 官方入口、GitHub/Hugging Face、Spatial Intelligence/3D-4D/real-to-sim、VLA/WAM/RL、LLM Agent/self-evolution，并用 broader web 做了遗漏兜底。10 月 14 日已覆盖的 Gemini 4 Argon、Pi API beta、Meta Muse 与 Anthropic 行为报告本轮仍在窗口内，但没有新版本、权重、代码或第三方验证，因此只在 Frontier 扫描中留痕，不重复展开。

今天最重要的新增判断是：研究竞争点正在从“生成一段看起来合理的视频”转向四个可检查的接口——共享的 RGB/深度/动作状态、动作后果的潜变量预测、与真实执行配对的世界模型评测、可编译且可校准的 real-to-sim 世界。Thinker-WM、WAVE-0、WorldOracle、Physical Registry、RoboSimStudio 和 Code2Worlds-2 分别占据这条链上的不同位置；它们共同暴露的瓶颈仍是长时漂移、动作因果性、跨本体迁移和第三方可复现性。

本轮先建立候选池，再做选择：LoopWAM、UniW(A)M、D-World、Unravel、HelpMeOut、GLST 等均已从最新批次或项目入口核对；它们未进入重点条目，是因为与本期主线重叠、公开证据仍不足或需要更完整的第三方验证，不是检索失败。对已覆盖的 Argon/Pi API 等重复项，也只有在出现新版本、代码、权重或验证时才会重新升档。

今日精读顺序

A → B → C → D → E

  • A｜Thinker-WM：先看一个把 RGB、metric depth、robot action 放进同一动态表示的统一模型，判断“统一”是否真的带来可迁移的几何与动作信息。
  • B｜WorldOracle：再看评测接口。它把“生成视频像不像”改成“在同一初始观测和同一动作下，是否预测了真实物理后果”，这是当前 WAM 论文最缺的证据层。
  • C｜WAVE-0：随后读轻量潜变量桥接，重点看 counterfactual ranking 如何让未来预测进入动作生成路径，而不是只做辅助损失。
  • D｜Physical Registry：再看一个低参数开销的 video-world-model 机制，适合作为显式动态状态的最小干预基线。
  • E｜RoboSimStudio / Code2Worlds-2：最后看 real-to-sim 与 executable world 基础设施，它们决定世界模型能否成为可校准的训练和评测环境。

重点论文 / 模型 / 项目

1. Thinker-WM: A Unified World Model with Shared Multimodal Representations for Embodied Intelligence｜P0

作者与机构、时间、性质。 Thinker Team (UBTECH)、Peng Gao、Jichao Jiao、Chen Liao、Daqin Luo、Yiming Ma、Baiyu Pan、Hailin Shi、Jiyuan Wang、Xiangming Xu、Xiongwei Zhao；arXiv v1 于 2026-10-13 提交，10-14 有 v2，属于未同行评审的技术报告。官方入口是 arXiv 页面 与 Thinker cosmos。

研究问题与方法。 现有 WM、VLA、WAM 往往把视觉动态、几何和动作拆到不同接口里。Thinker-WM 用 modality-specific encoder/decoder 包住一个共享的 Unified Dynamics Transformer，让 RGB、metric depth 与 robot action 在同一动态表示中共同演化；同一参数化支持 joint video-action generation、world prediction、policy inference、action-conditioned generation、video-to-action/inverse dynamics 等模式。训练混合约 20K 小时 egocentric video、10K 小时 real-robot、1K 小时 simulation，其中约 4K 小时机器人数据有深度监督，并用冻结表示上的 motion probe 检查动作相关信息是否可恢复。

结果与创新。 作者报告 EWMBench、WorldOlympiad、WorldArena 均排名靠前；二次审阅从论文表格读到 EWMBench Overall 4.66 对 Qwen-RobotWorld 4.60、WorldOlympiad Robotics All 0.740、WorldArena Track-1 EWMScore 71.73，但 WorldArena 排名使用了删去 3 个易受采样影响指标的 12-metric protocol，且这些都是作者报告，不是第三方复现。alphaXiv 的逐表复核 还指出，真实机器人闭环效果和长时漂移尚未被证明。相对 MotuBrain/UWM 等统一模型，它的实质增量是把 metric depth 作为共享动态过程中的生成模态，并把几何交互纳入受控训练阶段。

局限、价值与可复现性。 主要风险是深度监督的伪标签质量、WorldArena 协议依赖、单次点估计和真实闭环缺口；Pith 的审阅 明确把“伪深度、无方差/多 seed、无代码和评测脚本”列为需要补强的证据。Thinker-WM 专属代码、权重和训练数据在本轮未核实到公开版本；UBTECH 的 Thinker 基础模型代码与 Thinker-4B 权重 是相邻但不同的发布。值得精读，尤其适合做统一状态接口与几何-动作耦合的结构复核。

轻量验证。 不等完整预训练：在公开机器人视频或 RoboTwin 小子集上冻结视觉编码器，只训练一个 RGB/depth/action 三流小型 UDT；比较“独立头 + 单向深度”与“共享状态 + 双向深度”在 motion probe、短时 action-conditioned prediction、接触后状态一致性上的差异，再用 10–20 条真实视频做漂移和动作敏感性检查。

2. WAVE-0: Bridging VLA Policies and WAMs with Lightweight Latent Future Prediction｜P0

作者与机构、时间、性质。 Haomin Wang、Anqiong Ji、Ke Wang、Zhongshan Liu、Ru Ying、Ran Zheng、Zhipeng Zhang；来自上海交通大学 AutoLab、Awaken Robotics、Baidu AI Cloud 与浙江大学；2026-10-13 arXiv 预印本。项目页为 WAVE-0，代码为 AutoLab-SAI-SJTU/WAVE-0。

研究问题与方法。 视频式 WAM 把大量算力花在与动作选择无关的像素重建上，而普通 VLA 又不显式预测动作后果。WAVE-0 在预训练 π0.5 上加一个约 257M 参数的 latent world model：VLM 产生 latent action plan，世界模型根据当前观测和动作预测 future visual representations，再把这些未来表示送入 action expert。训练分两阶段：先用 ground-truth robot actions 学 action-dependent latent dynamics，并用 counterfactual ranking 区分不同动作后果；再冻结世界模型，把它接进 π0.5 的动作生成路径，整个过程不需要像素重建或额外的大规模视频预训练。

结果与创新。 论文报告 RoboTwin 2.0 91.47%、LIBERO 98.7%、LIBERO-Plus 88.0%、LIBERO-Pro 61.4%、LIBERO-Para 75.0%，三项真实任务上把 π0.5 的成功率从 38.3% 提到 73.3%。这些是作者结果，尚无独立复现。它的关键不是“又一个 latent predictor”，而是让未来预测直接参与 inference-time action generation，位于 VLA 语义计划与 WAM 后果建模之间。

局限、价值与可复现性。 真实实验只有三类任务，完整模型仍约 4.3B 参数，训练依赖 π0.5、LIBERO/RoboTwin 数据和动作标签；counterfactual ranking 是否真的对应因果后果、而不是更容易区分的视觉变化，需要 action-swap/nearby-action 检验。代码仓库已公开 Apache-2.0，包含训练脚本与配置；本轮未核实到 WAVE-0 官方 checkpoint，作者 Hugging Face 主页目前也未显示公开模型。官方仓库 明确给出 8 GPU 默认配置，因此更适合先做小规模复现。

轻量验证。 用 π0.5 base + LIBERO 4–8 个任务，冻结 SigLIP/VLM，只训练 latent world model 和小 action adapter；做三组等算力对照：无未来预测、未来只作 auxiliary loss、未来进入 action expert。重点测 nearby-action ranking、视觉/语言 OOD、接触后状态，而不是只看最终 success。

3. WorldOracle: Benchmarking Action-Conditioned World Models against Real-World Executions｜P0

作者与机构、时间、性质。 Haoyi Duan、Liliang Chen、Nan Wang、Yang Zhang、Yuhang Lu、Xiaotong Chen、Wei-Cheng Tseng、Shenyuan Gao、Zhaoshuo Li、Jingyi Jin、Pooya Jannaty、Dhruv Shah、Yuke Zhu、Ming-Yu Liu、Maoqing Yao、Guanghui Ren；合作作者来自 AgiBot、NVIDIA、Princeton、UT Austin、University of Toronto 等团队；2026-10-13 提交的 arXiv benchmark preprint。

研究问题与方法。 WorldOracle 固定同一初始观测和同一低层动作序列，把 action-conditioned world model 的 rollout 与真实执行逐段配对。它不把“画面逼真”当作充分条件，而是评估四个维度：physical state correctness、interaction spatial alignment、key interaction area fidelity、multi-view action coherence。数据包含长的 multi-segment episodes、成功和失败动作、多种交互动力学与本体，论文声称比较了 7 个 ACWM。

结果与创新。 摘要只承诺“发现不同模型的不同强项和失败模式”，没有在摘要中给出统一的单一排行榜；一份作者主页与论文解读记录了 335 条真实评测 episode，但这仍应视为二手核对。它与 WorldArena、EWMBench 的关系是互补：前者更像生成/动作综合榜单，WorldOracle 把真实执行中的失败、漏抓、错位和多视角不一致纳入同一可审计协议。

局限、价值与可复现性。 benchmark 价值高于单个模型的 headline gain，但本体、相机、动作接口异构，指标需要公开实现和校准。论文承诺 release dataset、evaluation code、leaderboard；截至本轮，公开仓库和可下载数据尚未核实，相关页面也明确记录“repo not verified”。因此它是今天最值得跟踪的“评测基础设施”，还不是已经可复现的公开 benchmark。

轻量验证。 先做 30 条真实 episode 的小套件：固定同一 action trace，手工标注末端位姿、接触点、目标状态和失败类型，计算四个指标；对一个现成 ACWM 做 open-loop 与 closed-loop 对照。这个验证不需要训练，只需要证明“生成视频看起来合理但抓取失败”的样例会被判错。

4. World Models Need a Physical Registry: Learning Internal Predictive States for Physically Plausible World Models｜P1

作者与机构、时间、性质。 Shinseong Kim、Jaeseok Jeong、Jianlong Fu、Youngjung Uh；Yonsei University 与 Microsoft Research Asia；2026-10-12 08:18 UTC（上海时间 16:18）提交的 arXiv 预印本。项目页为 Physical Registry。

研究问题与方法。 视频 world model 的 token 通常同时承担外观和动态，导致“预测的物理状态”不可读也难以被中途筛选。Physical Registry 在 video DiT 中加入按时间对齐的 registry slots：由 observation-conditioned forecast 初始化，与 video tokens 共演化，并接收 future-representation supervision；Physical Registry Selector 则在完整去噪前用中间 registry 读数筛选候选未来。

结果与创新。 作者报告在 Physics-IQ Verified 上相对 vanilla fine-tuning 的 I2V/V2V 提升为 9.9/8.7 分；只增加 0.45% 参数，就让 Cosmos 3 Nano 16B 的 I2V 43.56 超过公开的 Cosmos 3 Super 64B 42.7；PRS 在四个 backbone 上把 I2V 提高 5.6–15.9%，不需要完成视频后再调用外部评分器。它的价值在于提供了一个小而可控的“显式预测状态”接口，而不是重新训练更大的 video model。

局限、价值与可复现性。 这些仍是作者报告，尚无第三方复现；论文和项目页之外，本轮未找到稳定的公开代码、权重或完整训练数据。Physics-IQ/WorldModelBench 的提升是否能迁移到真实机器人动作后果，尚未被证明。值得精读，尤其适合作为视频 world model 的低成本结构干预。

轻量验证。 冻结一个小型 Wan/Cosmos backbone，仅加 8–16 个 registry slots 和一个 future-feature head；在 Physics-IQ 子集比较参数匹配的 LoRA、普通 memory token、Physical Registry 三组，记录物理错误率、registry 可读性、提前筛选的 precision/recall，并加入 nearby-action video 以测试是否捕获动力学而非纹理。

5. GreenWAM: A World Foundation Model for Robotics｜P1

作者与机构、时间、性质。 Gennady Sidorov、Valerii Kornilov、Denis Grankin、Polina Fedotova、Aleksey Postnikov；Sber Robotics Center；2026-10-13 技术报告型 arXiv 预印本。官方资料包括 论文、代码、项目页 与 Hugging Face checkpoint。

研究问题与方法。 不同机器人各自记录动作格式，WAM 与 policy 也常被分开训练。GreenWAM 把 20 个机器人族映射到 79 个共享 anatomical action slots，在 visual、action-conditioned、world-action 三种模式上联合训练，再从 generator 中拆出 action expert；之后可做机器人专门化和单步蒸馏。

结果与创新。 作者报告 WorldArena 1.0 的 trajectory/depth/3D 指标领先对比模型；公开表格给出 RoboTwin 2.0 mean 67.54（clean 86.98、randomized 48.10）、LIBERO 97.4、LIBERO-plus zero-shot 86.8、CALVIN ABC→D 4.64，并声称在真实 humanoid 上高于 π0.5 与 Cosmos 3 Edge。当前没有独立第三方复现，且“top-tier/competitive”依赖作者选择的比较协议。它的研究价值在于把 cross-embodiment 的动作对齐从接口工程提升成共享 world-model 训练问题。

局限、价值与可复现性。 训练数据、robotics-stage base checkpoint 和完整训练 recipe 未发布；共享 anatomical slot 的收益可能与每个本体的 mapping 质量强耦合。与 Thinker-WM 的统一表示相比，GreenWAM 更强调跨本体 action space 与可部署 policy。代码仓库公开了四个 benchmark checkpoint、评测服务器和 WorldArena evaluator；仓库称 200 个请求和 20 个 WorldArena 视频可 bit-identical 重放，但这是作者自检，不是第三方验证。

轻量验证。 先只下载 LIBERO 或 RoboTwin checkpoint，跑 2–3 个任务；将 79-slot shared mapping 与 per-robot adapter 做参数匹配对照，记录 action latency、scene randomization 下的成功率和 action-conditioned future consistency。

6. WoVR+: World Model as Reliable Simulator for Versatile VLA Policy Optimization with RL｜P1

作者与机构、时间、性质。 Shangqing Zhou、Zhennan Jiang、Ning Ma、Xin Fu、Yupeng Zheng、Shuai Tian、Huangrui Li、Jiahao Liu、Chao Yu、Zhongpu Xia、Haoran Li、Dongbin Zhao；合作单位包括中国科学院自动化研究所、中国科学院大学、中关村学院、清华大学、西交利物浦大学与 Anyverse Dynamics；2026-10-13 提交的 arXiv 预印本。项目视频在 WoVR+ 页面。

研究问题与方法。 学到的 world model 在 VLA-RL 中会产生 hallucination，长时 rollout 还会累积误差。WoVR+ 用 VLA-interface-aligned world model 预测 multi-view 与 proprioception，以 chunk-wise noise 保留 flow-policy exploration、减少动作抖动；长时任务采用 stage-entry reset、stage-specific reward、local horizon 和 controllable sampling，缩短生成前缀并做阶段平衡。

结果与创新。 论文报告相对 SFT 在 RoboTwin 与 6 个真实任务上分别提高 21.09% 和 16.7%，long-horizon phone-packaging 从 30% 升到 75%；这些仍是作者报告。相对早期 WoVR，它把“可靠 simulator”从 keyframe-initialized rollout 与 policy-simulator co-evolution 推进到接口对齐、阶段局部化和更实际的 VLA/RL 训练。

局限、价值与可复现性。 真实任务数量仍有限，收益依赖阶段划分和 baseline；本轮未核实 WoVR+ 的公开代码、权重或数据，不能把早期 WoVR 的 RLinf 代码 直接当成 WoVR+ 实现。它适合精读 RL 与 world-model 交互协议，不适合作为已经独立验证的通用结论。

轻量验证。 冻结 π0.5 或一个小型 VLA，只在 2–3 个 RoboTwin 长时任务上比较 full-prefix、stage-reset、stage-reset+chunk-noise；记录 hallucinated success、失败轨迹保真度、policy improvement 和真实/模拟排序一致性。

7. RoboSimStudio: An Interactive Toolkit for Rapid Real2Sim of Robot Manipulation Tasks｜P1

作者与机构、时间、性质。 Kaiyuan Chen、Shuangyu Xie、Uksang Yoo、Xinyue Zhu、Cael Magner、Alvin Zhu、Daehwa Kim、Eric Heiden、Erwin Coumans、Miles Macklin、Spencer Huang、Ken Goldberg；UC Berkeley × NVIDIA；2026-10-13 提交的 arXiv 工具型论文。官方项目页为 RoboSimStudio，代码为 Apache-2.0 仓库。

研究问题与方法。 机器人与物体的接触、耦合动力学、形变、刚度和摩擦很难从一段视频中可靠复现。RoboSimStudio 把 solver、contact model、物理参数做成可编辑对象，让人和 coding agent 根据视觉、力反馈以及 Real2Sim2Real 误差反复改模型；实现基于 open Newton，并支持刚体、关节、线缆、布和软体示例。

结果与创新。 论文摘要报告了 visual evaluation、force-feedback 与 agentic Real2Sim2Real 实验；项目演示展示了从手机视频和一句 prompt 自动构建仿真、在仿真中改进 Graph-as-Policy 后再回到真实机器人。二次阅读记录了一个 56 分钟的 pilot 和 18 个 manipulation simulations，但这些是作者/项目演示，不是独立复现。它的创新在于把 real2sim 变成可被 agent 操作的“参数化模型编辑”问题，而不是一次性 mesh reconstruction。

局限、价值与可复现性。 目前证据更像 workflow demonstration：单任务真实转移的物理一致性主要是定性判断，没有统一的 policy-ranking benchmark，也没有预训练权重。代码和示例公开，仓库为 Apache-2.0；没有需要下载的大模型 checkpoint。对 Spatial Intelligence 和 real-to-sim 研究很值得读，尤其可作为 WorldOracle 的环境生成前端。

轻量验证。 复现 wiping/peeling 其中一个 demo，预先定义接触时刻、接触力方向、物体位姿和滑移阈值；比较人工调参、agent 调参与仅视觉 loss 的三种模型，最后用同一 policy 做 sim→real 排序，而不是只看 render 相似度。

8. Code2Worlds-2: Physically Plausible Agent Harness for Embodied World Simulation｜P1

作者与机构、时间、性质。 Haoyu Zhang、Siming Li、Zeyu Zhang、Yi Zhang、Tat-Seng Chua、Hao Tang；北京大学计算机学院与新加坡国立大学计算学院；2026-10-13 03:30 UTC 提交。代码为 AIGeeksGroup/Code2Worlds-2，数据/评测入口为 SimCode4D。

研究问题与方法。 coding LLM 生成的动态 4D 世界常停留在“看起来合理”的视觉 artifact，缺少 collision geometry、mass、friction、inertia、joint structure。Code2Worlds-2 增加两个模块：SimReady Scene Compiler 将视觉场景编译为带碰撞、材质、支撑图和 MJCF 的可执行世界；Simulator-in-the-Loop 4D Refiner 让 agent 进行 compile→simulate→critique→refine，critic 直接检查 penetration、collision pairs、稳定性、接触力、joint limits 和 robot reachability。

结果与创新。 论文在 SimCode4D 和多类自然/室内/工业/城市/服务场景上报告物理可行、可被 simulator 加载且可被机器人交互。公开仓库把论文本体和 benchmark 做了重要区分：DEV15 的 225/225 是“冻结参考包的完整性/可运行性检查”，不是 Code2Worlds-2 方法成功率；仓库还明确说明大型 authoring .blend、实验输出、ablation 和视频没有随代码发布。这种 provenance 说明本身是优点，避免把 benchmark harness 误写成 SOTA。

局限、价值与可复现性。 生成物理属性仍依赖 VLM 估计和资产库，真实机器人闭环证据尚未出现。代码、15 个 MuJoCo runtime、validators、metrics 和 15-row HF 数据集公开，benchmark 约 3.58GB；没有独立预训练模型权重。它是本轮 Spatial Intelligence 里最适合立即动手的 executable-world 项目。

轻量验证。 直接跑仓库的 demo_scene，检查生成 MJCF 是否能加载；对质量、摩擦、碰撞网格做小扰动，观察 critic 是否能拒绝穿透、失稳和错误接触，再扩展一条新物体而不调用云端 LLM。

9. EmbodiedEvo: Self-improving Coding Agents for Physical Intelligence｜P1

作者与机构、时间、性质。 Wenyi Li、Yizhe Chi、Youjie Zheng、Chunyu Liu、Xiaoqiu Wang、Mingju Gao、Zheng Jiang、Deyao Hong、Calvin Xiao、Kaisen Yang、Qinhuai Na；2026-10-13 17:59 UTC 提交的 arXiv 预印本，作者单位在摘要页未完整展示；评测基于 RoboDojo-Sim。

研究问题与方法。 VLA 把观测和指令直接映射到动作，难以保留可编辑的控制逻辑。EmbodiedEvo 将状态和控制写入 code：agent 在一个 Playground scene 上通过观察、改代码、执行和反馈，演化可复用的 Skills 与 Lessons，然后冻结 harness 给不同 layout 和不同模型的 Test agent 使用；模型权重和原生机器人接口保持不变。

结果与创新。 作者报告 RoboDojo-Sim 平均分 44.48、成功率 37.82%，并称超过此前 officially verified results；Astra 产生的 experience 让 Sol/Luna 比无 experience 分别高 8.86/5.50 个百分点，Skills/Lessons 在相近表现下比 raw history 少 53.0% 执行成本。应把这些视为作者报告；Pith 复核 认为“跨模型 transfer”证据较可信，但对“超过所有已验证结果”的 headline 仍持保留态度。

局限、价值与可复现性。 fine contact control 仍难，experience 先在单场景获得，主要证据在仿真，尚无公开代码、权重和数据包可供本轮确认。它的真正贡献是“外部 harness 的持续改进”，不是模型参数递归自我训练；这让它成为 LLM Agent/self-evolution 与 embodied control 的连接点。

轻量验证。 固定一个 executor 和一个 task family，按 Playground→Test 严格隔离三种 layout；比较 raw trace、Skill-only、Skill+Lesson，报告成功率、失败恢复次数、token/工具成本和跨模型 transfer，避免把同一场景记忆误判为 self-improvement。

Spatial Intelligence / Frontier 扫描

本轮已扫描 World Labs、Generalist AI、Physical Intelligence、Google DeepMind/Robotics、NVIDIA Robotics/Cosmos/GR00T、Figure、Skild AI、Field AI、1X、Meta FAIR、Anthropic、Toyota Research Institute，以及 Stanford、Berkeley、MIT、CMU、Princeton 和主要中国具身团队的公开 research/news/project/GitHub/Hugging Face 入口。

窗口内两项官方 frontier 发布是 Gemini 4 Argon for Robotics（Google，10-13） 和 Pi API beta（Physical Intelligence，10-13），但二者已在 10 月 14 日晨报中详细覆盖；本轮没有发现新的版本、权重、代码或第三方结果，因此不重复展开。Argon 官方说明 给出 ERQA 87%、MuJoCo/Real2Sim/闭环 world-model steering 和一次 56%→75% 的官方案例；Pi API 官方说明 是上传数据、托管 fine-tuning、云端 inference 的 beta 基础设施，未给出可下载权重。两项都应标为“官方发布/作者或公司报告/无公开权重与独立验证”，而不是 peer-reviewed paper。

今日研究地图

统一状态与动作接口。 Thinker-WM 代表“RGB–depth–action 共享动态状态”，WAVE-0 代表“VLA 语义计划→latent future→action expert”，GreenWAM 代表“跨 20 本体的 anatomical action space”。趋势是把 action relevance 从末端 policy head 提前到 world state 或 latent consequence；gap 是这些表示是否真的具有反事实可识别性，而不是从同一轨迹里恢复相关运动。

物理可信与可审计评测。 Physical Registry 试图让预测动态成为 generator 内显式可读状态，WoVR+ 试图控制 imagined RL 的 hallucination，WorldOracle 则把真实执行、失败和多视角对齐写进 benchmark。趋势是从 FVD/CLIP/单次 success 转向 state correctness、contact fidelity、action coherence 和真实/模拟排序一致性；gap 是统一指标、跨本体标定和公开数据仍缺失。

Executable worlds 与 real-to-sim。 RoboSimStudio 把求解器和物理参数暴露给人/agent 编辑，Code2Worlds-2 把视觉 4D 世界编译成 MuJoCo 可执行世界，Unravel 关注单图交互场景重建。趋势是“world model + simulator compiler + agentic verifier”组成新基础设施；gap 是参数可辨识性、真实接触事件的校准和 sim→real 的长时可靠性。

Agent/self-evolution。 EmbodiedEvo 通过 Skills/Lessons 演化外部 harness，Argon/Pi API 则把代码、仿真、数据回流和云端 fine-tuning 接成开发闭环。趋势是改进对象从 model weights 扩展到 memory、skills、harness 和 data loop；gap 是如何证明跨场景 transfer，而不是单场景缓存，及如何让 experiment selection 有真实的 value-of-information。

今日研究机会与轻量验证

  1. Action-causal latent probe。 以 WAVE-0 的 counterfactual ranking 为最小基线，固定 encoder 和 compute，构造 nearby-action、action-swap、same-scene/different-action 三类对照；同时测 future representation 的排序准确率、末端位移和接触后状态，直接回答“latent future 是否包含动作因果”。
  2. Physical Registry × WAM。 在冻结的 Wan/Cosmos 小模型上加入 registry slots，先做 8–16 个 slot 的参数匹配实验，再用 WorldOracle 风格的 action-conditioned clips 检查 registry 是否能提前拒绝错误未来；这比重新训练 16B backbone 便宜得多。
  3. WorldOracle mini。 采集 30–50 条同初始观测、同动作但含失败的真实短轨迹，做四维 metric 的最小实现；把现成 WAM 的“视觉逼真”与“真实状态正确”分开，先得到可复核的 failure taxonomy。
  4. Real2Sim ranking audit。 用 RoboSimStudio 或 Code2Worlds-2 生成一个擦拭/推物体任务，刻意扰动 friction、mass、collision mesh；比较 render similarity、contact-event agreement 和 policy-order agreement，判断哪一个指标真的能预测真实机器人表现。
  5. Cross-embodiment action slots。 在 GreenWAM 可下载 checkpoint 上选两个本体和两个任务，只训练 mapping adapter；报告共享 slot、per-robot adapter、随机 mapping 三组的 OOD success、动作平滑度和延迟。
  6. Harness evolution protocol。 按 EmbodiedEvo 的 Playground→Test 设计，把同一任务分成单场景 acquisition 与三场景 held-out evaluation；除 success 外记录失败恢复、工具调用成本、技能复用率和不同 executor 的迁移，避免把“更长的上下文”误写成自进化。

证据状态与可复现性

  • 论文/技术报告状态。 本期 9 个重点项均为 arXiv 或项目技术报告，除非特别标注，均未同行评审。HelpMeOut（2610.17694）已标注 CoRL 2026 接收，但它是错误监测 benchmark，本轮作为补充候选而未进入 Top 精读。
  • 已公开代码/权重。 GreenWAM 已公开代码、四个 benchmark checkpoint 和评测入口，但训练数据、训练 recipe、robotics-stage base checkpoint 未公开；WAVE-0 已公开 Apache-2.0 仓库和训练脚本，WAVE-0 checkpoint 本轮未确认；RoboSimStudio 已公开 Apache-2.0 toolkit/examples；Code2Worlds-2 已公开 method modules、MuJoCo runtime、validators、SimCode4D DEV15 与 3.58GB HF 数据集。
  • 承诺发布但尚未确认。 WorldOracle 论文承诺 dataset/evaluation code/leaderboard，但本轮未找到可核实的公开 repo；WoVR+ 的论文/视频入口可见，但本轮没有确认对应代码或权重；Physical Registry、Thinker-WM、EmbodiedEvo 也没有确认到可直接下载的专属训练代码/权重。
  • 第三方验证。 本期没有找到能完整复现实验主张的独立第三方运行。Thinker-WM 和 EmbodiedEvo 有二次审阅，主要作用是指出协议和 headline claim 的证据边界；不能把 AI review 当成实验复现。GreenWAM 仓库的 bit-identical 记录、WAVE-0 的成功率、WoVR+ 的真实机器人提升、Argon/Pi API 的案例均应标为作者或官方报告。
  • 算力边界。 公开仓库可以做代码/接口/小子集验证，但不能把小实验称作完整训练或蒸馏结果。对大模型优先做冻结 backbone 的 probe、counterfactual ranking、短 horizon rollout、paired real/sim evaluation 和 action-latency measurement，再决定是否投入多 GPU 训练。

今天先读 Thinker-WM → WorldOracle → WAVE-0，先做一个小规模的 action-swap/nearby-action 评测；如果 WorldOracle 的公开数据随后落地，应优先把它接入现有 WAM 评测，而不是继续堆单一视频质量指标。
