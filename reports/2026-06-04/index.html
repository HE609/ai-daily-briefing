【🚨 今日重点】

① MiniMax M3 正式发布，挑战闭源旗舰模型 国产 AI 公司 MiniMax 于 2026年6月1日 发布开源权重模型 MiniMax M3，一次性结合了多项顶级能力：100万 token 超长上下文、前沿级编程能力（SWE-Bench Pro 得分59%，超越 GPT-5.5）、原生多模态（文本/视频/图像），且成本仅为 GPT-5.5 和 Gemini 3.1 Pro 的 5-10%。API 定价约 \(0.30/M 输入 tokens，\)1.20/M 输出 tokens（发布期5折优惠）。这是全球首个将百万级上下文与前沿编程能力结合的开源多模态模型，被认为是 Agent 开发领域的里程碑事件。 📌 来源：VentureBeat · Tech Times · arXiv

② COMPUTEX 2026 × Build 2026 双料重磅：AI 基础设施和 Agent 安全同步爆发 Computex 2026（台北）和 Microsoft Build 2026（6月1-2日）密集发布多项重磅： - NVIDIA RTX Spark：首款面向 PC 的 Blackwell 架构 AI 芯片，可本地运行 120B+ 参数模型无需调用云端，Jensen Huang 在 Computex 发表主题演讲 - 微软 MXC：OS 级安全沙盒，为 AI Agent 提供内核级隔离和安全防护，OpenAI 和 NVIDIA 已加入合作 - Perplexity 混合推理：本地-云端混合推理系统，在 Computex 联合 Intel 演示，自动决定哪些任务本地处理、哪些上云，号称节省50%成本 - 微软 Surface RTX Spark Dev Box：开发者专用设备，128GB 统一内存，1 PetaFLOPS AI 算力 📌 来源：VentureBeat · CNBC · Reuters

③ Figure AI Helix 机器人在真实物流中大规模验证 Figure AI 宣布其 Helix 02 VLA 模型驱动的人形机器人已在实际物流场景中连续工作8天，分拣25万个包裹，零错误。这一结果被视为 VLA 模型从实验室走向工业化规模应用的重要里程碑，机器人现在可以在真实仓库环境中实现完全自主的长时序任务。 📌 来源：Facebook/Figure AI · Figure AI

【━━━ 顶级研究组新发布 ━━━】

MiniMax M3（国产） MiniMax M3 于6月1日发布，是全球首款将百万 token 上下文、前沿编程能力与原生多模态融合的开源模型。采用 Sparse Attention 架构解决超长上下文计算效率问题。在 SWE-Bench Pro（软件工程基准）上得分59%，超越 GPT-5.5 和 Gemini 3.1 Pro，但成本仅为后者的5-10%。API 现已在 OpenRouter 上可用，定价 \(0.30/\)1.20 per 1M tokens（发布期5折）。 📌 来源：VentureBeat · The Decoder · Tech Times

Google Gemma 4 12B（全球） Google 于今年4月发布的 Gemma 4 系列新增 12B 参数版本，支持文本、图像、音频和视频多模态输入，且可在典型16GB 企业笔记本本地运行（无云端依赖）。完全开源（Apache 2.0 许可），面向企业边缘 AI 场景。目前已在 HuggingFace 和 Ollama 社区广泛使用。 📌 来源：VentureBeat · HuggingFace

阿里巴巴 Qwen3.7-Plus（国产） 阿里巴巴于6月初正式发布 Qwen3.7-Plus，统一支持文本、视频和图像输入，具备完整的 Agent 能力，可操作图形界面和命令行。定价极具竞争力：\(0.40/\)1.60 per 1M tokens（输入/输出）。但该模型为闭源，仅通过阿里云 API 提供。 📌 来源：VentureBeat

arXiv 三日新帖动态（2026-06-02~06-04） cs.AI 新分类周三单日新增 440 条提交，cs.LG/cs.CV 同步活跃。重点关注方向包括：Terminal Agents 训练轨迹有效性、World Model 与 JEPA 最新进展、多模态大模型架构优化。arXiv 上大量关于 VLA、Agent 架构、测试时扩展（test-time scaling）的预印本涌现。 📌 来源：arXiv cs.AI
