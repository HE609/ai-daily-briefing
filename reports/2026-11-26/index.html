今天最重要的新增判断是：世界知识的价值，需要沿着“空间可测量—条件被利用—动作能执行—失败可恢复”逐段证明。 MoGe-4D 提供统一几何与运动查询；OmniAct 把本体运动学放进策略；iWAM 用一次视频骨干计算保留未来信息；SimPWM 直接检验视频是否服从仿真状态。官方入口另发现 NWM 3.0、MAGI-2 和 DeepMind Mass Spec Skills。MAGI-2 的 24 日发布与 SenseNova U1.6 更早已可见的工件，明确作为 Retrieval Failure 回补，不以筛选解释遗漏，也不把今天的阅读日期当首发日期。

今日精读顺序

今天我建议的精读顺序是：MoGe-4D → OmniAct → iWAM → SimPWM → Exploratory Midtraining。

  • MoGe-4D：先理解如何用同一种查询连接几何、相机与动态点轨迹。
  • OmniAct：再看空间与运动学如何共同决定不同机器人的动作，而非只统一动作格式。
  • iWAM：研究无需生成完整视频、仍让策略获得未来信息的训练方法。
  • SimPWM：用冻结物体等干预检查生成器是否真正服从外部状态。
  • Exploratory Midtraining：补上从受扰状态返回可成功状态的数据与学习机制。

P0/P1 表示阅读和跟踪优先级，不表示同行评审、独立复现或部署成熟度。做评测可将 ROAM-Bench 提前；做多模态 Agent 可将 OmniHarness-RSI 与 Mass Spec Skills 连读。

重点论文 / 模型 / 项目

1. MoGe-4D：统一动态几何、相机和密集点跟踪｜P0

MoGe-4D: Efficient, Flexible, and Unified Dense 4D Reconstruction and Tracking；Ruicheng Wang、Linlin Xin、Sicheng Xu 等，中国科大、微软研究院、国科大与清华。24 日 08:45 UTC 提交、25 日公告；预印本，未核验同行评审。 论文｜官方项目。问题是动态场景的几何、相机运动和物体运动往往由不同模块估计，难以保持一致，密集跨帧查询又非常昂贵。

每个源帧到目标时刻的查询，同时输出以源相机和目标相机为坐标系的两张动态 point map；二者对应关系支持闭式求相机变换。约 1B 参数的 context encoder 只计算一次，约 80M query encoder 复用缓存、按需解码。训练使用几何、运动、遮挡/共视、尺度等监督；RigIDTrack 将共同运动的面片压成共享仿射变换，减少轨迹存储。所谓任意时刻“精确恢复”受压缩容差约束，不应理解为没有近似误差。

作者报告 V-JEPA 版本的跨基准 camera-space all-point AUC 为 75.83，4RC 为 67.22；不同骨干并非每项都最好。50 帧全帧对密集跟踪约比 4RC 快 4 倍。对 Open-D4RT 的约十倍比较包含对后者去重加速的假设，不能当作原版 D4RT 的直接实测。训练最长 32 帧；DINO 版本的 500 帧相机轨迹泛化不等于 500 帧密集动态跟踪全部可靠。

值得首先精读表示与计算拆分。 相对 VGGT 等重建模型及 D4RT / 4RC，它统一查询接口；仍有细结构、边界飞点、长序列二次注意力成本和跨域精度问题。项目明确代码与 RigIDTrack 数据正在合规审查、coming soon，本轮未核验权重。完整训练为 64 张 A100-40GB、160k 步。轻量验证可先用现有几何/跟踪模型在 20 段短视频建立双坐标一致性与遮挡分层评测，等工件开放后只测查询预算、静态背景漂移和动态前景误差，无需重训大骨干。

2. OmniAct：用场景中的运动学图控制不同本体｜P0

OmniAct: One Policy, One Million Embodiments；Xiang Fan、Yuheng Wang、Jiayuan Yan 等，华盛顿大学、Allen Institute for AI、UNC-Chapel Hill 与新加坡国立大学。24 日 18:59 UTC 提交、25 日公告；预印本，未核验同行评审。 论文｜官方项目与完整结果。它研究的不只是同一动作表示能否迁移，而是机器人臂长、关节轴与可达范围不同，策略是否会主动改变操作方式。

系统把关节、夹爪、指尖与工具中心组成运动学图，通过正向运动学和相机外参放入各观察相机坐标系，再与图像、语言共同送入 400M flow-matching Transformer。模型预测各节点相对关节运动与末端位姿。程序生成并过滤百万种机械臂，规划器为可执行任务生成轨迹；实际训练集为 1,029,605 条轨迹、800,196 个有成功轨迹的本体、约 2,740 小时，不能称为百万台实体机器人经验。

作者报告 2,000 个未见本体×未见场景 episode 上，成功率 63.0%，同数据多视角 UMI 为 57.9%、π0.5 为 17.8%。Franka 与 OpenYAM 真机各 20 个匹配初态，OmniAct 分别成功 14/20、13/20；MolmoAct2 为 14/20、7/20。“近两倍”只适用于这组未见 OpenYAM 的小样本。GPT-6 Astra 对比只覆盖部分任务族，不能与全任务均值直接比较。

值得深入读运动学与场景对齐。 相对共享末端动作或事后 retargeting，它允许形态直接影响抓取策略；但程序化本体分布、相机标定和规划器示范仍限制泛化，训练本体数消融也需结合总数据量理解。项目 Code / Data 均标 soon，本轮未核验权重。轻量替代是在同一仿真场景选 6–12 种机械臂、固定总示范数，对比正确图、无图和交换图，独立测可达性、碰撞及任务成功，检验收益是否来自真实运动学信息。

3. iWAM：一次视频骨干前向保留未来信息｜P0

iWAM: Efficient Action Prediction from World Models without Explicit Future Prediction；Vansh Kapoor、Max Sobol Mark、Sreyas Venkataraman、Max Simchowitz、Aviral Kumar，CMU。24 日 18:56 UTC 提交、25 日公告；预印本，未核验同行评审。 论文及附录。它追问 FastWAM 的速度是否以丢失未来条件为代价，以及如何避免先生成完整未来视频再做逆动力学。

训练先利用可逆 flow，将示范未来反演到对应噪声，再学习双向 flow map，把多步生成计算摊入训练；动作专家读取该位置一次骨干计算的中间特征。部署时从先验采噪声、只做一次视频骨干前向。两阶段分别学习跨时间 flow 映射与动作条件策略；DROID 使用 Wan2.2-5B 加 1B 动作专家。单次视频前向仍不等于整个动作策略只计算一步。

作者报告 三个真机任务每项 20 次，iWAM-MIP 平均 85.0%、生成未来的 IDM 为 80.0%、FastWAM 为 13.3%；DROID 仿真对应 iWAM-MIP 91.7%、IDM 96.7%。约 6 倍低延迟来自 A100 上的特定计时协议：所有方法按两步动作去噪计时，但 IDM/FastWAM 成功率仍来自八步评测，不能把图上的点当作完整同配置实测。LIBERO-PRO 的位置/任务扰动仍很难，统一未来信息没有解决所有分布外问题。

值得与昨日 Native LAM 连读。 前者把世界模型变成动作教师，iWAM 则保留可区分未来的内部计算。随机先验直接训练在 LIBERO 较有效、在 DROID 仿真不足 3%，提示“有预测信息”和“与动作监督对齐”应分开验收。论文给出的项目 URL 本轮返回 404，未核验专属代码、权重或训练包。轻量验证先在小数据上冻结骨干，对比当前帧、随机噪声、示范反演噪声三种特征的动作预测和 latent 交换，再用同一去噪步数重测成功—延迟曲线。

4. SimPWM：显式仿真状态是否真的控制了生成视频｜P0

Simulator-as-Proxy World Model for Robot Manipulation；Tingting Liao、Mingjia Huo、Hao Li 等，MBZUAI、UC San Diego 与 Pinscreen。24 日 15:14 UTC 提交、25 日公告；预印本，未核验同行评审。 论文｜项目｜代码。研究问题是仿真渲染作为视频条件时，模型究竟服从状态，还是根据机械臂动作自行补出一个看似合理的抓取。

单帧加相机标定构建机器人三维模型与物体点表示，无训练参数的规则模拟器执行动作并输出 RGB/深度 proxy；视频模型再生成真实外观。训练在 proxy 条件下适配视频生成器，部分 H3 实验只用仿真与真实抓取一致的数据。关键诊断是保持机械臂轨迹、冻结模拟物体，检查视频是否仍擅自把物体举起。它把模拟状态和视频同时交付，使两者分歧成为可测对象。

作者报告 三种视频骨干的 robot IoU 为 0.75–0.78，但机器人单独渲染已能提供主要提升。加入物体状态将漏掉拾取的比例从 54% 降至 38%。在刚体冻结测试中，H3-C 的举起率 42%→10%，LTX-2.3 同条件为 57%→49%，后者更像忽略物体状态、从手臂运动推断抓取。这是作者内部干预实验，不是第三方复现，也不是控制任务成功率。

非常值得读其反事实协议。 相对纯生成世界模型或完整物理 twin，规则点模拟器更便于审计，但刚性携带布/绳、隐藏物体与标定错误限制了物理含义。源码及小示例公开；链接的 H3-C 权重 元数据与文件 API 本轮均返回 401，不能称本轮已验证可下载。仓库的渲染示例要求 4×80GB GPU，论文部分单卡视频生成需数百至上千秒。轻量验证先跑三段 proxy 或仅复核状态日志，比较正常、冻结、错位物体条件；不要用“视频漂亮”替代状态跟随率。

5. Exploratory Midtraining：用受扰后继续完成的数据准备自主改进｜P0

Exploratory Midtraining for Robot Policies；Kshitiz、Zheyuan Hu、Robyn Wu 等，CMU、华盛顿大学、Toyota Research Institute 与 Princeton。24 日 18:52 UTC 提交、25 日公告；预印本，未核验同行评审。 论文｜项目与逐任务结果。标准成功示范很少覆盖从尴尬状态恢复的路线，多给 rollout 时间可能只增加无效重复；本文将这种缺口称为 connected behavioral coverage（CBC）。

β-Data 由操作者和对抗者共同采集：后者可逆地移走物体、重连积木或改变目标，前者不重置、继续完成。轨迹按局部结果重新分段和标注语言，策略以近期动作历史为条件做行为克隆式 midtraining，随后测试在线微调。CBC 统计抽象物体—位置状态间的不同有向转移；同状态集下更多边，比仅报告看过多少状态更接近恢复路线覆盖。

作者报告 匹配记录时长后，真机包装数据的转移边为 125 对 72；固定两组共有状态仍为 121 对 72。每项 20 次真机评测，单 LEGO 组装拆解 5/20→19/20、包装 4/20→12/20、裤子折叠 3/20→14/20；双 LEGO 仍只有 6/20，不能笼统称恢复问题已解决。数据约 4–8 小时/领域，记录时长匹配不等于两名采集者的总人时相同。

值得精读数据设计和失败后行为。 相对 PostBC 的动作不确定性路线，本文直接增加能连接受扰状态的经验；相对仅存成功 skills，它关注回到可成功状态的路径。CBC 依赖抽象粒度，人工可逆扰动也未涵盖所有自然失败。项目代码仍标 soon，未核验完整 β-Data、策略权重或在线训练包。轻量验证在两个小任务固定示范总时长，配对采集标准与不中断恢复数据，再做动作历史开/关对照，报告完整成功、恢复时间和原有成功回归。

6. RFW-W：把刚体、关节与可形变资产接入任务场景｜P1

RFW-W: Scaling Physical Asset Universes for Generative Embodied Simulation；Jiawei Weng、Rui Zhang、Saining Zhang 等，阿里、清华、南洋理工、北大、南京大学与港科大。24 日 17:32 UTC 提交、25 日公告；预印本，未核验同行评审。 论文｜源码。此前跟踪过 RFW-S，本次新增为 RFW-W 总体系统与 RFW-R 刚体实验，不把旧可形变数据重新称为首发。

刚体流水线依次做类别条件生成、多视角检查、部件标注、碰撞几何与物理属性组合，任务场景侧再检索资产并验证布局；关节资产保留程序结构，可形变资产保留各自的结构与求解器验收。论文报告 1,010,386 条资产记录，来自 524,611 刚体、402,410 关节和 83,365 联合验收可形变资产；2,228 是数据集—类别条目之和，不代表跨库语义去重后的类别数。训练目标随所调用模型与下游策略而异，不是一个端到端资产世界损失。

作者报告 五个 RoboTwin 任务、每资产源每任务 100 条示范，RFW-R 策略平均成功率 clean 71.2%、randomized 41.8%，ManiTwin 为 55.4% / 31.2%。随机化 Pillbottle-Pad 上 PhysX-3D 仍以 9% 高于 RFW-R 的 6%；这些都是仿真闭环，真机轨迹回放不是新策略真机泛化证明。524,611 个保留刚体中，论文称 49 个尚无完整仿真导出，不应写成所有资产均已可执行。

值得跟踪资产—任务收益链条。 相对只有 mesh 的对象库，它强调可执行表示；但估计质量/摩擦不是材料测量，跨求解器一致也不是现实真值。代码、配置与部分复现文档公开；ModelScope 页面本轮只返回外壳，未核验全量 manifest 和文件数。公开复现范围 明列完整库未覆盖，Isaac / 完整五后端场景 / 动态机器人任务仍有 blocked 或 not_run。这是仓库自报，不是本轮测试。轻量验证先取十个资产，分开验收 export、load、step、接触、抓放，再测同示范预算的真实下游收益。

7. ROAM-Bench：答对问题与完成必要探索分别评分｜P0

ROAM-Bench: Evaluating Embodied Active Spatial Intelligence through Evidence Verification；Xingjian Ran、Xiaoye Mo、Sihao Liu 等，港大、电子科大、上海创智学院与京东。24 日 18:56 UTC 提交、25 日公告；预印本，未核验同行评审。 论文｜代码与任务｜场景数据。它研究主动空间智能中的一个评测盲点：碰巧报对数量，不代表看完了必要房间、打开了隐藏容器或完成了交互。

250 个人工验证任务覆盖 27 场景、11 类型、5 组能力。VLM 选择原子动作，平台处理机器人运动/碰撞；评估器用状态和记录分别检查结果 A、必要观察与动作 N、更强佐证 S，严格成功为 T = A ∧ N。S 是额外诊断，即使通过也不保证答案正确。这是评测框架，没有提出新的策略训练目标。

作者报告 GPT-6-astra 的 A 为 73.2%、T 为 69.2%；人工在分层抽取的 100 任务为 84% / 84%，与模型全 250 任务不是完全相同样本。139 问题×七模型的诊断中，原结果正确率 45.2%，补齐目标观察后 58.4%，替换成 GT 轨迹 RGB 为 64.9%，再共同加入深度/位姿/标定为 77.6%。这些是联合 oracle 条件，不能把所有提升单独归因于某一种传感器。

值得深入读评分契约与诊断设计。 相对静态空间问答，它把证据获取纳入验收；局限是合成室内、平台执行的原子技能和任务规定的覆盖要求，不能直接外推到自由控制真机。实际读取 manifest，确认 250 任务 / 27 场景；HF 列出 27 个场景归档、总目录约 17.1GB，代码和许可可见，未下载或启动 Isaac Sim。项目首页的机器人演示明确为脚本示意，不能当 VLM 成功录像。轻量验证先审十任务的 A/N/S 边界、重置及状态隔离，再运行少量固定预算 episode。

8. OmniHarness-RSI：按模态能力诊断并修改多模态 Agent｜P1

OmniHarness-RSI: Modality-Aware Harness Evolution for Omnimodal Understanding；Shilin Ma、Xingming Shui、Jinglin Chen 等，清华深圳国际研究生院。24 日 16:53 UTC 提交、25 日公告；预印本，未核验同行评审。 论文。问题是音频、视觉、时间定位和多模态协作混在一起时，Agent 自改 harness 很难知道究竟该修改哪一部分。

作者将演化空间分成模态路由/协作、证据定位、专门感知三部分，以冻结的 Qwen3.8-27B 作 planner、感知专家与检索工具作执行模块，GPT-6.1-Sol 最多进行十轮代码修改。数据约按 40:10:50 分为演化、验证和测试，验证选择候选，最终测试及跨数据集评估。优化对象是可执行工作流与正确率，不是更新基础模型权重；诊断既看救回案例，也检查原本正确案例是否退化。

作者报告 WorldSense、Daily-Omni、OmniVideoBench 的 test accuracy 从 54.20 / 74.08 / 42.17 提高到 63.06 / 82.21 / 48.40，即 +8.86 / +8.13 / +6.23 点。WorldSense 演化后的固定 harness 在另两全量基准上为 82.12 / 54.00；部分使用更强模型的已发表系统仍更高。planner 调用和观看帧数减少，但两个数据集的工具调用增加，因此不能直接称总成本都下降。

值得阅读其归因与留出设计。 相对不区分模态的 RSI，它把修改目标结构化；相对 Sage 等改变观察方式的路线，它同时修改路由与感知工作流。迭代选择噪声、基准污染和演化教师总成本仍待审计。本轮未核验到专属公开代码、演化轨迹或完整运行包。轻量替代为固定小候选库，在音轨缺失、帧遗漏、时间错位三类可控错误上比较结构化诊断与普通反思；冻结测试集，报告净救回数、回归数与全部工具成本。

9. MAGI-2：大规模音视频生成与后训练能力回归｜P1

MAGI-2: A 480B Frontier Video Generation Model；Sand.ai 团队，11 月 24 日官方研究发布。 官方技术说明。这是相对 8 月 MAGI-2 Preview 的旗舰升级；前一期漏掉窗口内官方发布，本次记为 Retrieval Failure 回补。它研究稀疏音视频模型如何同时扩模型、数据与训练系统，支持最长 30 秒、1080p、25fps 及多参考条件生成。

官方披露 480B 总参数、约 28B 激活、4T 预训练 token；Multi-Head Latent MoE 将 token 按 head 分片后交换，再做本地专家路由，配合并行、优化器与 kernel 共设计。单流 Transformer 联合处理文字、视频与音频；后训练包含 RL，另有注入原参考的时空上采样。官方报告 匹配 FLOPs 下约 22% 训练加速，四任务平均 Arena Elo 998.5→1150.3；后者是公司引用的评测汇总，本轮未核对独立榜单原始记录。

更值得研究的是官方展示：关闭外部提示增强时，预训练模型出现部分规则推理与跨语种表现，而小规模审美后训练后这些行为更难触发。这是观察与工作假设，尚非系统证明“对齐损害世界理解”。相对 Wan / 既有音视频生成，它强化规模与系统协同，但没有机器人动作干预、可执行状态或长期物理验收。完整新版技术报告与开源工件仍为未来计划，Preview 的开放不能代替旗舰权重。建议精读系统和能力回归部分；轻量实验用可获得的小模型固定提示增强与采样预算，在微调前后分别测审美、规则遵循和事件先后，报告回归而非只看偏好。

10. NWM 3.0：观测与潜空间两种闭环训练｜P1

NIO WorldModel 3.0；蔚来团队，任少卿在 11 月 25 日 NIO IN 2026 发布；官方技术/产品公告。 蔚来官方新闻。核心问题是世界模型上车时的响应时延与训练成本。官方介绍 tubelet 时空编码压缩，以及观测空间、潜空间两个强化学习闭环：前者重建传感观测用于检查，后者以低成本更新表示。

官方报告 注意力所需车端计算减少 36 倍、整车控制时延减少 54%、训练效率为前代五倍、接管需求减少 40%。这些指标的基准硬件、路线、里程、干预定义与统计区间未在该新闻中完整披露；36 倍只指注意力计算，不能写成整车推理快 36 倍。12 月计划推送仍以备案与许可为前提，发布不等于本轮已验证用户部署。

值得跟踪，不建议将新闻当作可复现论文。 相对 Dreamer / 潜空间模型式 RL 与观测级仿真，双闭环体现效率和验收并存的趋势；架构、奖励与损失细节不足以重建系统。未核验公开代码、权重、数据或独立性能测试。轻量替代是在同一小驾驶/导航模拟器固定策略和模型，比较纯潜空间更新、周期性观测重建审计和每步观测审计，测每单位计算的真实环境成功及模型误差；这是机制研究，不是 NWM 3.0 复现。

11. Mass Spec Skills：成熟科学工具让小模型接近大模型｜P1

From spectrum to structure: Identifying molecules with Mass Spec Skills for Google Antigravity；Robert Brunck、Stefan Ganscha、Swaroop Guntupalli 等，Google DeepMind 与分析化学合作者；11 月 25 日官方研究发布。 官方说明与实验。它把谱库检索、分子式估计、候选查找、碎片解释等工具装进 Agent skills，解决模型只凭峰表难以准确识别分子的问题。

Agent 执行既有计算与数据库查询，再展示支持候选的碎片和化学证据；没有发布一个新的专门训练基础模型。官方报告 在 100 个已有公共参考谱的化合物上，每谱三次尝试，加入 skills 后三个大小不同模型的精确匹配均约 97%；仅给网络或仅给峰表显著更差。超一小时计失败，暂时性基础设施/配额错误被排除。Flash 的生成 token 近四倍减少，只测该协议，不代表全部费用同幅下降。

值得作为 Agent 基础设施案例读。 相对临时写检索脚本，稳定工具约束了数值、检索与证据接口；但库内检索成功不是发现未知分子，镜像分子和近似异构体仍需其他测量。官方称插件已在 Antigravity 可用，本轮未安装、调用或复跑；未核验独立完整实验包、训练数据与第三方系统性验证。轻量验证用十个有谱库真值和十个不在库中的样本，固定工具/API 预算，对照普通脚本与 skills，分别报精确匹配、弃答、证据正确率和完整失败成本。

持续地图的本轮变化是：空间、形态、未来条件、仿真状态和恢复经验都开始成为可单独干预的研究变量。研究机会在于证明模块连接处的因果贡献：有坐标是否真的影响动作、有状态是否真的控制画面、有工具是否真的改善证据、有更多经历是否真的带来留出任务收益。这些机会是基于今日资料的研究推断，尚未验证。

今日研究机会与轻量验证

  • 优先一：条件服从性。 选 20 段短轨迹，固定相机和机械臂动作，对比正常、冻结、错位物体条件；分别测状态正确、画面跟随和接触违规。即使只做 proxy 和人工视频审计，也能先验证指标是否区分“忽略条件”和“模拟器本身错了”。
  • 优先二：本体信息净收益。 6–12 种机械臂、固定示范总量，正确图/交换图/无图三组；按可达性、碰撞、成功和 OOD 形态距离分层。先验证表征是否被用，再扩大本体数。
  • 优先三：恢复经验的成本收益。 两任务各配对采集等时长示范，记录全部采集者人时；同时控制动作历史、任务分段与训练步数。比较一次成功、受扰后恢复、时间预算翻倍收益和原有成功回归。
  • 优先四：Agent 演化是否可靠。 固定候选和外部测试，注入帧缺失/音轨替换/时间错位；比较普通反思与模态归因。记录整个演化过程、所有候选失败、工具和教师成本，避免只汇报选中版本。

经典参照继续保留：用 VGGT / D4RT 理解几何与运动查询；用共享末端控制和 retargeting 理解 OmniAct；用 Dreamer / 模型式 RL 理解潜空间闭环；用行为克隆和 PostBC 理解 β-Data；用固定 harness 与外部 verifier 理解自进化收益。经典工作服务于机制比较，本期不把它们包装成新发布。
