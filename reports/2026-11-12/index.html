空间智能与通用 AI 科研晨报 ｜ 2026-11-12

本期检索窗口为北京时间 2026-11-09 09:03 至 2026-11-12 09:03，资源核验延伸至成稿。候选池并行覆盖 arXiv Robotics、AI、CV、ML 最新批次，World Model、Spatial Intelligence、3D/4D 世界生成、real-to-sim、VLA/WAM、Robot Learning、Agent/self-evolution、GitHub、Hugging Face，以及主要公司和高校官方入口。相对 11 月 11 日，Gemini Robotics 2.5、Steel、RoboScript、LingBot-Touch、SWAM、WanderBench、SoftPAT3D、Compass 1、Fable 5.2 和 InfraRSI 没有新版本、代码/权重、基准结果或第三方验证，本期不机械重复。Long-WAM 只有在 11 月 9 日刷新 RoboCasa GR-1 19.2 秒 checkpoint 后重新纳入，属于资源证据更新。

今天最重要的新增判断是，世界模型正在从“生成合理视频”分化成三种可检验的系统能力。PAN 2 和 NTT 把世界预测接到候选动作筛选，UGG 把 RGB、深度和相机几何放进同一个 4D 场景补全问题，MetaWAM 与 LaST0.5 则在 WAM 内部重做机器人信号接口和交互状态。与此同时，记忆 VLA 的“幻觉进度”、三回合动力学适配和事件门控自演化都指向同一件事：评测必须检查状态是否真的改变、适配是否真的迁移、更新是否真的可持续。本期展开十一项，其中 PAN 2、UGG、MetaWAM、Few-Shot Residual Adaptation 和 Memory Clock 最值得先读。

今日精读顺序

今天我建议的精读顺序是：PAN 2 → UGG → MetaWAM → Few-Shot Residual Adaptation → Memory Clock。

  • PAN 2。先看一个官方开放世界模型怎样把语言状态、视频生成和多步计划放到同一个模拟闭环里，同时审查长计划失败和提示词敏感性。
  • UGG。再看空间智能的几何边界，尤其是稀疏观测下的相机、深度和跨模态一致性，而不是只看视频质量。
  • MetaWAM。接着看机器人动作、未来本体状态和值函数如何压缩进视频潜空间，并用冻结去噪器诊断接口是否真的对齐。
  • Few-Shot Residual Adaptation。它用三个交互回合适应质心和摩擦变化，适合直接改造成低预算的 frozen-twin 验证。
  • Memory Clock。最后用空事件、时钟缩放和事件索引审计记忆 VLA 是否把“时间经过”错误当成“任务进度”。

重点论文 / 模型 / 项目

1. PAN 2 - A Foundation World Model for Physical Intelligence｜P0

PAN Team，Institute of Foundation Models，MBZUAI。官方技术博客标注发布时间为 2026 年 11 月，具体日未列，发布性质是官方技术报告、开放模型与代码发布，尚无同行评审论文。它要解决的是如何让 Agent 在执行前模拟动作后果，并把模拟结果用于多步计划和物理推理。官方技术博客 · Hugging Face 模型 · GitHub 代码

PAN 2 使用 Generative Latent Prediction（GLP）。概念推理骨干把观察和文本动作写成带时间、参与者、动作和相机运动的结构化世界状态，29B 参数的 MMDiT 感知骨干再预测视频潜变量，最后用 Wan 2.2 VAE 解码。模型支持文本到视频和图像到视频，官方模型卡给出的输出最高为 704×1248、24 fps、20 秒。训练目标是让文本状态、潜空间和下一观察保持一致，推理时由外部 Agent 比较候选计划的模拟结果。架构与 checkpoint 说明

官方报告结果是单步完成率 75.1%，完整多步计划完成率 34.0%，在其比较的开放模型中排名第一，在 Physics-IQ Verified 的公开排行榜设置中报告为总体第三。官方还给出了 6D-PI、Physics-IQ、RBench 和 140 个提示的人类盲评。以上均是作者/官方报告，比较中混用了不同概念推理器和闭源模型，尚无独立复跑。评测口径

创新在于把“语言层的状态转移”和“视觉层的物理细节”拆成可检查的两层接口，并把 world model 直接用作 simulative reasoning。局限也很明确，官方承认约三分之二的计划至少有一步没有执行，提示词敏感，长时交互从单个起始帧开始会出现外观漂移，文字动作对灵巧接触表达较粗，模拟可能在中间状态违反物理约束。它与 Cosmos 3、RBench 和视频世界模型路线的关系，是把评价对象从视频逼真度推进到计划完成和可验证状态。

值得深入阅读，优先看结构化状态的生成协议、失败计划的统计方式和 Agent 是否真正依据模拟结果改写计划。官方开放 29B 权重、训练代码、推理代码，Apache-2.0，HF 模型卡和 GitHub 仓库均可见。完整运行仍是大算力工作。轻量验证可固定五个短计划，用同一初始图像比较“只看最终视频”和“读结构化状态再选计划”两种路径，先用人工或规则验收器记录动作顺序、接触发生和中间状态是否可达。训练不需要先做，先验证模拟是否能区分候选动作。

2. NTT 物理控制适配器世界模型｜P0

NTT, Inc. R&D 团队于 2026-11-11 发布官方研究新闻。性质为公司官方研究发布和技术演示，没有公开论文、权重或代码，也没有同行评审或第三方验证。它解决的是堆叠、碰撞、掉落等任务中，普通视频世界模型无法显式追踪物体质量和动力学的问题。NTT 官方发布

方法是在视频生成模型中加入 proprietary physics control adapter，从视频估计物体的位置、姿态、速度和质量，再用运动方程计算未来状态，并把计算结果反馈给视频生成器。系统接收 VLA 或运动规划器给出的多个候选动作，分别生成未来视频并判断是否会发生碰撞、堆垛坍塌或掉落，再选择成功概率较高的候选动作。训练目标、适配器结构和物理量估计误差没有公开到可复现程度。

官方结果包括 public OBJ3D 碰撞视频基准上的 LPIPS 优于传统方法，以及小型机器人货架装载任务成功率从 73.1% 提高到 92.3%。这些数字都是 NTT 报告，实验规模、动作候选数量、人工介入、重复次数和独立验收脚本尚未公开。NTT 计划与 Mujin 推进机场行李装卸场景，技术将在 NTT R&D Forum 2026 展示。

它的研究价值在于把“world model 预测”变成带物理量解释的候选动作评估，和 PAN 2 的语言状态路线互补，也与 ObjectWorld、Tiresias 等工作形成从视频到可执行动作的桥接问题。局限是适配器、数据、动作接口、控制延迟和物理外推边界都未公开，92.3% 不能直接等同于通用机器人能力。值得追踪官方技术细节，不宜当作已复现方法。

可行的轻量替代实验是用 MuJoCo 或 PyBullet 做箱体堆叠，固定候选动作生成器，比较普通视频预测、显式质量/摩擦状态和两者融合的候选排序。先只测碰撞、掉落和堆叠稳定性三类状态验收，再连接策略成功率。当前代码、权重、数据均未核实，证据状态停留在官方发布。

3. UGG - Unified Generative Geometry Model｜P0

Amani Kiruga、Zhiyi Li、Ruojin Cai、Hansen Lillemark、Xiaoshan Wu、Ayush Tewari、Yilun Du，Harvard University、MIT、UC San Diego、University of Cambridge。论文于 2026-11-10 提交，arXiv v1，备注为 NeurIPS 2026 接收，项目页和代码同时开放。论文 · 项目页 · 官方代码

UGG 把 RGB 视频、深度和相机几何统一成空间对齐的多模态 token，用带不同模态和时间噪声模式的 diffusion forcing，把视频生成、深度预测、相机姿态预测、稀疏观测补全和 text-to-4D 视作同一个条件补全问题。相机姿态用 dense ray maps 表示，Mixture-of-Transformers 的共享自注意力在 RGB、depth、ray 三类 token 间交换信息。测试时可以采样多个场景假设，再用 RGB 重投影一致性筛选几何结果。

作者结果显示，UGG 在一视图相机控制生成的 RealEstate10K、SpatialVID、DL3DV 三个数据集上同时取得最优 PSNR、LPIPS、SSIM。两视图时，RealEstate10K 为 25.73 / 0.061 / 0.849，SpatialVID 为 16.99 / 0.288 / 0.535，DL3DV 上 SEVA 略优。几何预测中，UGG 在五个数据集的 dense 相机误差和 sparse 相对姿态指标优于对比方法，作者还报告稀疏图像证据驱动的 test-time search 能改善几何预测。结果来自作者论文，尚无独立复跑。论文实验表

创新点是把“可生成场景”和“可测几何状态”放在同一个生成对象中，适合 real-to-sim、相机控制和交互式 4D 世界。局限是生成任务对 seed 和 caption 敏感，camera-only 或 depth-only 属于零样本条件，论文也承认跨数据集归一化、稀疏观测和生成质量之间仍有耦合。它与 World Labs Atlas 的产品化空间模型不同，UGG 把几何监督、公开数据协议和可量化相机误差明确放在论文评测里。

值得深入阅读，尤其是 test-time search 是否真正提高几何真值一致性，而不是只提高重投影分数。代码仓库包含训练、推理、数据配置和样例资产，Apache 许可信息需以仓库 LICENSE 为准。官方 Hugging Face 权重 30 GB bf16，单次推理建议一张 80 GB GPU，峰值约 40 GB，尚无独立权重复跑。轻量验证可以只跑 video_to_4d 和 first_last_to_4d 两条公开样例，固定三个 seed，分别测 depth scale、相机轨迹 ATE、重投影误差和生成视频质量，先验证几何是否随 seed 稳定。

4. From Video Frames to Robot Meta-Frames - MetaWAM｜P0

Guoqiang Liang、Yiqi Lin、Yanzhe Chen、Kevin Yuchen Ma、Mike Zheng Shou，National University of Singapore、Guangzhou Research Translation and Innovation Institute。论文于 2026-11-10 提交，项目仓库与模型 checkpoint 在 11 月 11 日 更新，性质为 arXiv 预印本、CoRL 2026 接收稿、Apache-2.0 代码和权重发布。论文 · 官方仓库 · RoboCasa checkpoint

MetaWAM 研究的问题是，如何把动作、当前本体状态、未来本体状态和值函数注入预训练视频扩散模型，而不为每种信号单独占一帧。它用 2D DCT 频域通道带打包信号，通过 inverse DCT 形成一个 input meta-frame 和一个 output meta-frame，再用 slot-aware masks 区分条件和预测目标。训练目标包括视频扩散重建、动作 Huber loss、未来本体状态 Huber loss、value loss 和 off-slot 惩罚，冻结去噪器诊断则用相对重建误差衡量不同注入方式的兼容性。

作者结果为 RoboCasa 24 任务、每任务 50 个示范、三随机种子平均 68.9%，高于同数据量 Cosmos Policy 的 67.1%。LIBERO 原始四套件平均 98.1%，LIBERO-Plus 总体 83.44%。真实 Franka 三任务、每任务 ID/OOD 各 20 次，项目页报告 ID 85.0%、OOD 68.3%。查询延迟从 0.479 秒降到 0.291 秒，约 39%，同时统一 meta-frame 在同一延迟下优于空间象限和紧凑区域打包。上述均为作者实验，尚无第三方控制复跑。实验细节

创新在于把“信号接口”本身当成 distribution-alignment 问题，而不是格式化细节。它承接 Cosmos Policy、UWM、UVA 等 joint WAM 路线，和 Elastic-WAM 的推理预算优化正交。局限是 4 个 H200、约 64 小时训练的完整配方仍偏重，现实任务只有三类，跨骨干和跨机器人仍需验证。值得深入阅读并可直接做公开 checkpoint 验证。

仓库已核到训练、评测、推理代码和三组 HF 模型，包含 RoboCasa、LIBERO、RealWorld checkpoint 以及校验和。训练数据沿用 Cosmos Policy 的统计和嵌入文件，完整原始数据需按上游许可取得。轻量验证可先只跑 pack/unpack 和冻结去噪器 probe，再在两个 RoboCasa 任务上比较 Separate Spatial Duplication、Meta-Compact 和 Unified Meta-Frame，记录动作成功、未来本体误差、value MAE 和端到端延迟。

5. LaST0.5 - A Generalist World Action Model with Interaction-Centric Latent Reasoning｜P0

Xuheng Zhang、Yiming Zhang、Jialin Gao、Hao Chen、Jiaming Liu、Ji Li、Runzhong Huang、Yinxi Wang、Chenyang Gu、Zihan Yang、Yaowei Liu、Zhonghao Yan、Ziyu Guo、Renrui Zhang、Peng Jia、Pheng-Ann Heng、Shanghang Zhang，Peking University、The Chinese University of Hong Kong、Simplexity Robotics。论文于 2026-11-10 提交，arXiv v1，同行评审状态待核。论文

LaST0.5 认为全局场景表示对世界演化有用，但可能忽略机器人与目标物体的局部交互。它在 world expert 和 action expert 之间加入 interaction-centric latent expert，用视觉交互线索和物体 affordance 构造 latent target，采用 Mixture-of-Transformers 进行层级推理。Adaptive World-to-Action Transfer（AWAT）同时预测未来表示和 progress value，根据进度一致性调整动作执行长度并触发未来重采样。训练语料超过 14,000 小时，混合机器人示范、UMI 和人类第一视角数据。

作者结果为 LIBERO 平均 99.5%，十个 RLBench 任务平均 88.0%，真实 Tianji 双臂四任务平均 63.8%，高于同表中的 52.5% 和 Cosmos Policy 的 43.8%。这些结果来自作者自建协议，真实任务数量有限，尚无第三方验证。它与 WAM 的世界预测-动作生成路线一致，但把中间表示改成“交互中心”并显式加入进度控制。

创新价值在于把可预测的世界状态和真正用于动作的局部接触状态分离，再用 progress value 将预测置信度接入执行控制。局限是 14k 小时混合数据、交互提示构造、AWAT 和模型规模同时变化，公开论文尚未给出代码或权重入口。值得精读方法与消融，不适合把 99.5% 直接当作可复现基线。

轻量验证可以用单一 RLBench 任务做三组对照，global latent、interaction latent、interaction latent 加 AWAT，固定同一 action expert 和数据量，分别测动作成功、未来表示 cosine、progress calibration 和失败时的重采样次数。代码、权重、训练数据和独立结果本轮未核实。

6. Elastic-WAM - Adaptive Spatiotemporal Imagination for Efficient Robot Control｜P0

Haitian Li、Tianfu Li、Xuxi Zhao、Zizheng Liu、Yangcheng Yu、Yiwen Hou、Zeyu Xiao、Mutian Xu、Ziqian Yang、Haonan Chen、Lin Shao，National University of Singapore、RoboScience、HKUST Guangzhou、Zhejiang University、HIT Shenzhen、Tsinghua University、NTU、Xi'an Jiaotong-Liverpool University。论文于 2026-11-10 提交，arXiv v1，项目页提供演示和完整结果表。论文 · 项目页

Elastic-WAM 处理 WAM 迭代视频去噪的固定预算问题。它学习一个统一的 spatiotemporal refinement demand field，决定 何时停止世界 refinement、每次去噪推进多远、刷新哪些未来空间区域。三阶段 action-grounded supervised training 冻结预训练 WAM，稀疏更新固定刷新未来 196 个 token 中的 96 个，动作 refinement 继续复用缓存世界表示。

项目页报告 RoboCasa-GR1 57.4%、LIBERO 98.8%、LIBERO-Plus 73.7%、LIBERO-Pro 54.1%。真实四阶段茶水准备任务上，Joint-WAM 的 nominal/lighting OOD 全任务成功率为 30%，Elastic-WAM 为 50% / 50%，object OOD 为 30%，但阶段完成度更高。作者还报告 LIBERO-Plus 上 adaptive progression 加 commit 比只做 spatial selection 高 2.00 个百分点。指标均来自作者项目页，未见独立复跑。

创新点是把“视频未来的哪一部分值得算”变成一个可学习、可审计的控制对象，和 MetaWAM 的表示压缩互补。局限是项目页没有明确公开代码、权重或训练数据，真实实验任务数少，计算节省与物理成功率之间的关系还需端到端墙钟评测。值得阅读推理预算分解，复现优先级低于 MetaWAM。

轻量替代实验可以在已有 WAM checkpoint 上只实现三个 oracle controller，固定步数、随机空间刷新和基于动作梯度的空间刷新，测同一成功率下的 denoising steps、刷新 token 数、GPU 显存和总延迟。这样可以先验证“少算未来”是否真的保留闭环动作信息。

7. Long-WAM - 11 月 9 日 checkpoint refresh｜P0

Wei Huang、Bohan Zhang、Chenzhi Liu、Isabella Liu、Shuai Yang、Weian Mao、Luozhou Wang、Yicheng Xiao、Weifeng Lin、Qixin Hu、Bryan Chu、Sifei Liu、Linxi Fan、Xiaojuan Qi、Song Han、Yukang Chen，NVIDIA、MIT、HKU、UCSD。论文首发在 10 月 7 日，本期纳入原因是 2026-11-09 02:42 UTC GitHub 提交刷新了 RoboCasa GR-1 19.2 秒 checkpoint，HF 资源同步更新，属于窗口内代码/权重证据，不是重复报道。论文 · 仓库与更新提交 · 19.2 秒 checkpoint

Long-WAM 先做机器人和人类视频的自回归视频预训练，再保留 history-to-future 结构进行 world-action adaptation。Streaming observation encoding、异步执行和硬件特化加速让长历史预测进入实时控制，发布包还把 IDM、COD、RoboCasa、RoboTwin、LIBERO 和 YAM 的 checkpoint/config/statistics 分开列出。

项目页报告 19.2 秒历史下 RoboCasa GR-1 78.7%，LIBERO-Long 99.5%，RoboTwin 2.0 平均 94.4%，RTX 5090 每个动作 chunk 含未来预测 107.4 ms，Unitree G1 动态叠杯 19/20 = 95%。这些数字来自作者论文和项目页，论文与大部分结果早于本窗口，本期新增只确认了 checkpoint refresh 和可下载的完整 policy bundle。

它和本期 Memory Clock 形成有价值的对照。Long-WAM 强调更长的历史是否被模型真正使用，Memory Clock 检查时间采样是否把无事件间隔错误读成进度。局限是模拟器、数据和外部模型版本复杂，真实部署资源昂贵，独立复跑尚未完成。值得精读资源契约和长上下文消融。

代码采用 Apache-2.0，HF 已有公开权重、配置、统计文件和 SHA256SUMS，但仍需下载 RoboCasa、RoboTwin、LIBERO 资产。轻量验证可只做 --dry-run 配置检查，再在单个 RoboCasa 任务比较 0、2.4、9.6、19.2 秒四个历史长度，记录延迟、显存、动作抖动和成功率。不要把 README 的 author result 写成已经完成的独立复现。

8. Few-Shot Residual Adaptation of Pretrained Latent World Models｜P0

Jakub Suliga、Pankhuri Vanjani、Nisarga Nilavadi、Wolfram Burgard、Rudolf Lioutikov，Karlsruhe Institute of Technology、University of Technology Nuremberg。论文于 2026-11-10 提交，是 NeurIPS 2026 Continual World Models Workshop 论文，CC BY 4.0，同行评审状态按 workshop 录用信息记录。论文 · CoRL/Continual World Models workshop 页面

它研究部署时质心和摩擦变化导致的 dynamics shift。预训练 DUET-DINO 保持冻结，在线用实际转移预测误差学习 residual adapter，同时改正 latent predictor 内部和 predictor 输出的两个位置。控制器是固定的 CEM，适配不依赖奖励，也不需要先估计变化了哪一个物理参数。三次交互回合后冻结 adapter。

作者结果中，质心变化和摩擦变化让冻结模型真实成功率接近 0。双位置 adapter 在真实机器人上分别恢复 90% 和 100%，单位置方法明显更弱。仿真中双位置 sequential training 为 56.7%，joint training 为 44.0%。论文还发现，降低预测误差本身不足以保证控制成功，仿真训练的 adapter 向真实环境迁移较差。以上是作者实验，尚无独立复跑。

创新点是将 frozen world model 的快速现场修正与控制闭环分开，适合 real-to-sim 和 sim-to-real 之间的短程校正。局限是适配器具有部署特异性，正常动力学任务成功率从冻结模型的 85.3% 降到 54.0%，摩擦设置只在真实机器人上稳定，不能把三回合结果理解成通用动力学识别。值得深入阅读并优先做小规模验证。

代码、权重和数据入口本轮未核实。轻量实验可在 MuJoCo 中固定一个 latent predictor，先做质心、摩擦、颜色和相机背景四类 shift，比较 no-adapt、内部 residual、输出 residual、双位置 residual，严格分开预测误差、候选动作成功和适配墙钟。

9. Is Your Robot's Memory Just a Clock? Temporal Shortcuts in Memory-Augmented VLA Policies｜P0

Chubin Zhang、Bo An，Nanyang Technological University。论文于 2026-11-10 提交，代码、模型和复现实验在 11 月 11 日公开，MIT 许可，研究对象是 RoboMME 记忆增强 VLA。论文 · 代码与复现脚本 · HF 模型

论文构造 pause、wrist fidget 和 air-grasp 等不改变任务状态的 null event。时间采样的 memory 仍会把这些帧写入固定槽位，因此模型把 elapsed time 错当成 task progress。作者进一步用 time-stamp rescaling、NoClock、hidden-memory 和 event-indexed memory 区分“时间编码问题”和“记忆索引问题”。

作者结果是 PickXtimes 成功从 47/50 降到 16/50，SwingXtimes 从 44/50 降到 10/50。同样的物理暂停若隐藏在 memory 之外，成功基本恢复。时钟加速会让模型提前停止，减速会让模型重复。去掉 time encoding 仍不能消除失败，测试时改为 event index 能恢复损失的一半以上，而 pause augmentation 没有修复问题并损害无事件计数。

创新在于把 memory VLA 的“记忆能力”转成了可执行的状态不变性测试，直接连接 Long-WAM 的历史建模、RoboMME 的记忆基准和 persistent state 评测。局限是实验集中在两个计数任务和公开 RoboMME 设计，事件索引仍依赖可检测的重复状态，尚无第三方验证。强烈值得深入阅读，因为它给出了一个可以跨模型复用的失败协议。

代码仓库包含 null-event evaluation、clock scaling、NoClock、event index、pause augmentation 和多组 checkpoint，默认 50 paired episodes，单 GPU 可先做约两分钟 smoke test，完整训练需要 Linux 和 80 GB 级 GPU。轻量验证先只跑 visible 与 hidden memory 对照，再加入随机延迟、遮挡和真实 API latency，记录成功、提前终止、重复执行和 memory slot 变化。

10. CIALLO - Learning Shared Intent Representations for Cross-Embodiment Manipulation｜P1

Choo Sin Wai、Dake Zhong、Jingye Zhang、Zhifang Liu、Siyao Xiao、Zirong Ding、Yuhong Zhang、Kangjie Chen、Dongbin Zhang、Guorui Song、Guocun Wang、Peng Jiao、Haoqian Wang，清华大学。论文于 2026-11-10 提交，arXiv v1，同行评审状态待核。论文

CIALLO 把动作、视觉变化和观察条件下的语言对齐到短时行为意图空间，再用 embodiment-conditioned decoder 映射回不同机器人动作。新本体只需一段最多 10 秒的记录更新 embodiment embedding，意图 codec 和策略主体保持冻结。政策实例是 Qwen3.5-4B，目标是把控制接口适配从任务学习中分离出来。

作者结果为真实 SO-101 和 Piper、每任务 20 个示范平均 76.7%，高于完全微调 π0 的 70.0%。仿真中 LIBERO 97.3%、RoboTwin 2.0 52.7%，LIBERO-Plus 80.8%，以上均为作者结果。它与 OneLA、跨本体 WAM 和人类视频对齐路线相关，但把共享接口定义成“意图”而不是直接动作重建。

局限是八本体预训练、10 秒校准和 decoder 微调仍把 embodiment 覆盖写进训练协议，真实任务规模不大，尚未看到代码、权重或完整数据入口。值得作为跨本体对齐线索阅读，优先审查 one-record calibration 是否真的只学习本体，而不是泄露任务分布。

轻量验证可用同一任务在 SO-101、Piper、Franka 三种控制接口上固定视觉和语言输入，只替换 embodiment embedding，比较 action reconstruction、intent linear probe 和闭环成功。无公开代码时可先实现一个小型意图 bottleneck，验证接口分离是否优于直接动作回归。

11. When Should Agents Remember? Falsification-Gated Self-Evolution for LLM Agents｜P1

Runxuan Tang、Haoyu Gao、Yuyan Ding、Junyi Yao、Zihao Zheng、Zecheng Sheng、Liwei Hou，Nanyang Technological University、Georgia Institute of Technology、University of Washington、Washington University in St. Louis、University of Sydney、National University of Singapore。论文于 2026-11-10 提交，arXiv v1，属于 Agent/self-evolution 方向，尚未核实公开代码或权重。论文

FGSE 把一次经验更新写成包含 precondition、behavior change、expected effect、verifier 的结构化假设。候选更新先只写入 temporary state，再用 target-transfer、falsification、archived-regression 三类 probe 测试，最后 commit、refine 或 reject。方法的重点是让“记忆写入”成为可验证的状态转移，而不是默认把 episode lesson 永久加入 prompt。

作者报告 WebArena 成功率 39.8，AppWorld 平均完成率 78.8，τ-Retail/τ-Airline 的 Pass1 为 0.724 / 0.487，falsification failures 为 5.0%，regression damage 为 1.3%，harmful committed updates 为 3.6%。这些结果依赖可执行 verifier、探针构造和作者控制的基准协议，尚无独立复跑，也没有物理机器人闭环证据。

它与 Memory Clock 的共同问题是区分“表面进步”和“状态真的变好”，与 InfraRSI、RoboScript 的验收器路线互补。局限是 verifier 失真、probe 过拟合、临时状态并不能撤销外部写操作，理论保证只覆盖指定分布。值得深入阅读评测协议，不宜直接外推到真实机器人自我改进。

轻量验证可做一个三任务 mock tool 环境，强制每条 lesson 经过 source、near-transfer、boundary、regression 四类 probe，比较 direct-commit、temporary-test 和 temporary-test 加 precondition refinement 的成功、回归和调用成本。代码与权重状态本轮未核实。

近期趋势可以概括为三个方向。第一，Spatial Intelligence 正从“生成一个看起来像世界的画面”转向“恢复可检查的几何、状态和相机关系”。第二，WAM 的主战场从单纯扩大数据量转向信号接口、历史利用和推理预算。第三，Agent 与机器人自改进越来越依赖冻结验收器、可回滚状态和失败归因，而不是直接把轨迹写进记忆。

今日研究机会与轻量验证

  • PAN 2 × NTT 物理可检验性。在同一个 MuJoCo 堆叠任务中生成 8 个候选动作，分别用视频相似度、显式物理量和二者融合排序。指标包括碰撞、掉落、堆叠稳定、排序校准和一次真实执行的成功率。
  • UGG 几何稳定性。只用公开样例跑 3 个 seed，比较 video-to-4D、first-last-to-4D、camera-to-4D 的深度尺度、相机 ATE、重投影一致性和生成多样性。先确认模型是否能区分几何错误与视觉漂亮。
  • MetaWAM × Elastic-WAM 等预算复核。固定 backbone、数据和动作 chunk，只改变信号打包和未来 token 刷新策略。记录成功率、未来本体 NEE、value MAE、denoising steps、刷新 token 数、显存和墙钟。
  • Few-Shot Residual frozen-twin。用三个交互回合做质心和摩擦 shift，加入颜色、背景和相机扰动作为非动力学对照。报告 adapter 对预测、候选排序和真实成功的分别贡献，避免把泛化误写成适配成功。
  • Memory Clock 四联测试。在 PickXtimes 类任务加入 pause、fidget、air-grasp 和隐藏事件，分别使用 visible/hidden memory、clock-scale、NoClock 和 event index。统一记录提前终止、重复执行、memory slot 内容和 total latency。
  • FGSE × 机器人验收器。把一条经验更新写成可执行假设，只允许在 mock world 或 resettable simulator 中验证，再比较 direct commit、temporary test、temporary test 加 refinement 的长期保留率和回归率。

以上均是轻量验证建议，本轮完成的是论文、官方材料、公开代码/权重入口和实验协议核验，没有运行模型推理、GPU 训练、真机实验或独立基准复现。
