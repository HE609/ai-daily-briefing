━━━ 顶级研究组新发布 ━━━

  • Lift3D-VLA（北大 + 港中文 + AI² Robotics）：用增强的 2D→3D 提升策略把点云直接送进 VLA 视觉编码器，搭配 GC-MAE 双目标自监督（重建当前点云 + 预测未来几何演化）+ 分层时间动作建模，在 MetaWorld / RLBench / 真实世界 8 个任务上比 SOTA VLA 平均成功率 +10.8% / +11.1%。来源：arXiv 2607.06564, 2026-07-08。

  • RynnWorld-4D（阿里达摩院 + 香港具身 AI Lab + 港中文）：以同步的 RGB / Depth / Flow 为物理 grounding，从单张 RGB-D + 语言指令联合预测未来 RGB、深度、光流，三分支架构 + 逐帧 3D RoPE，搭配自建 Rynn4DDataset 1.0（2.544 亿帧） 与 RynnWorld-4D-Policy（一次前向输出动作），在真实灵巧双手操作上 SOTA。来源：arXiv 2607.06559。

  • RynnWorld-Teleop（同上团队）：把"操作员手部姿势流 → 视频 DiT → 机器人动作"做成"数字遥操作"，单张 H100 上 40+ FPS 实时生成，纯生成数据训练的策略可在多种灵巧任务上零样本 Sim2Real，真实数据 + 数字遥操作数据混训持续提升成功率。来源：arXiv 2607.06558。

  • SenseNova-Vision（商汤 + NTU + CUHK + 北大 + 上交 + 浙大）：把 CV 整体重写成"统一多模态生成"，无任何任务专属预测头——检测、OCR、关键点、分割、深度、法线、点图、相机姿态全部用"自然语言指令 + 视觉提示 + 文本/图像/图文混合输出"统一表达，单个统一模型对齐多个 SOTA 专用系统。来源：arXiv 2607.06560, 2026-07-08。

  • CAIRN（清华 + BIGAI + 哈工大 + 北大 + 牛津 + 微软 + 西蒙弗雷泽）：把 Transformer 注意力按"房间级 + 对象级"分层对齐，引入 图神经网络 + 房间 token + 带几何偏置的分层注意力掩码，发布 CAIRN-MR 基准（HM3D 多房间），在跨房间问答上大幅超越现有 3D-LLM。来源：arXiv 2607.06534。

  • HypoExp（RSS 2026, 新加坡国立大学）：开放世界机器人规划框架，让机器人自动生成 / 验证 / 更新世界模型假设——基础模型提假设，自动规划器同时验证假设 + 执行任务，迭代扩展抽象知识库。来源：arXiv 2607.06501。

  • Embodied Human-Robot Interaction via Acoustics（UCL + 马来亚大学, RSAI 2026 接收）：用 8×8 超声相控阵 + TurtleBot3 做"声控机器人"，每个机器人悬浮一颗 1-10 cm 高度的粒子表示人口/噪音/交通，MARL 选避障动作 + GS-PAT 控制器稳定陷阱，单机器人 / 双机器人成功率 90% / 80%。来源：arXiv 2607.06563。

  • RSF-GLLM（Adobe Research, ICML 2026 全文）：用 GRU 引导的 query updater 在多跳 KG 上传播连续相关分数 + 流稀疏正则化把软概率收敛到离散路径，再文本化微调 LLM，在 WebQSP / CWQ 上比计算昂贵的 LLM 方法更高效。来源：arXiv 2607.06527。

━━━ 生成模型 / 新范式 ━━━

  • Seedance 2.5 系列（字节豆包）：新版本主打"9:16 竖屏 + 电影级运镜 + 音画同步"，面向短视频和电商场景大幅降价，已经在小红书 / 抖音上被刷屏。来源：公众号、抖音创作者社群。

  • ReChannel（UCSD + HKUST）：用 DiT 现有的 patch→token→patch 晶格直接做"像素空间密集预测"——砍掉目标侧 VAE 解码器，33K 参数的 token-local 线性头把每个 token 映射到 p×p×Kₜ 像素补丁。在 FLUX-Klein 4B 上，无 trimap 抠图、KITTI 深度、引用分割全部 SOTA，比"编辑 + 潜空间解码"对应版本准确率更高、速度快 2.48 倍。来源：arXiv 2607.06553。

  • ProxyPose（多伦多大学 + Vector Institute）：把 6-DoF 姿态跟踪重新定义为 video-to-video translation——微调后的视频扩散模型把任意视频（无纹理、透明、反射、可变形都行）翻译成"已知几何的代理视频"，用经典 PnP 求解姿态，SOTA 精度且只需首帧一个标记像素。来源：arXiv 2607.06555。

  • Vision as Unified Multimodal Generation（SenseNova-Vision）：见上节"顶级研究组"。

  • MiMo / Qwen3-8B / Kimi K2 等开源 LLM 在 Hugging Face 持续上分：本周趋势榜出现多款 7B 级新模型，主打 Agent / 推理 / 长上下文。来源：Hugging Face trending、Reddit r/LocalLLaMA。

━━━ 多模态 / VLM ━━━

  • MonoIR-RS（中石油克拉玛依 + 贵州大学 + 北大深圳 + 上交）：第一个大规模红外遥感视觉-语言基准（60 万合成红外图 + 5.9 万 IR 标注 caption），CLIP 微调 Recall +12.8 点，VLM captioning IR-cue 覆盖率 100%。来源：arXiv 2607.06552。

  • FreqDepthKV（人工视觉研究所）：长上下文推理的 KV 缓存压缩——把相邻层 KV 分解为"低频共享深度 + 稀疏高频残差"，在线探测器按头分配到 shared / residual / exact 三种缓存模式，32k 预填充下 3.9× 有效压缩率，TTFT 2.06s，70.4 tokens/s，精度几乎不掉。来源：arXiv 2607.06519。

  • Lychee-FD（哈工深 + CUHK 深圳）：定位"全双工 SLM 的模态干扰根因"——声学 & 语义共享深度参数空间会产生梯度冲突，用分层参数分离解耦但保留跨模态语义对齐通道。Spoken QA +7.4%，FullDuplexBench 1.5 +28.5%。来源：arXiv 2607.06540。

  • ELSA3D（UIUC）：用 Anchor Tokens 把语义线索路由到匹配的 3D 尺度，scale-aware 八叉树令牌化器 + 轻量逐块路由器，在 image-to-3D / text-to-3D / 3D caption 三任务上 SOTA，FLOPs 与延迟减半。来源：arXiv 2607.06565。

  • CAIRN（多房间 3D-LLM）：见"顶级研究组"。

━━━ 具身 / VLA / 机器人 ━━━

  • Lift3D-VLA：见"顶级研究组"。

  • RynnWorld-4D / RynnWorld-Teleop：见"顶级研究组"。

  • UniLM-Nav（清华 + BIGAI + 哈工大 + 北大）：用同一个 MLLM 后端做"视图选择 → 功能接地 → 几何感知基础姿态推理"零样本最后一英里导航。在 OVMM 基准上比 MoTo SOTA +3.13pp，已部署到 Unitree B2 + Z1 机械臂做真实移动操作。来源：arXiv 2607.06537。

  • CE-MPPI（华盛顿大学, IROS 2026）：把 MPPI 的"采样平均"硬伤用 DBSCAN + 碰撞衍生参考点的方向特征切成簇，选最小代价（静态）/ 反障碍物流（动态）。在 UR5e 真实测试中目标到达时间 -48%，末端路径 -12%。来源：arXiv 2607.06499。

  • AcoustoBots（UCL + 马来亚大学）：见"顶级研究组"。

  • Neural-ESO（休斯顿大学 + 莱斯大学, IEEE RA-L）：双路径 ESO——预测路径用 NN 加速收敛、校正路径用传统 ESO 兜底，Lyapunov + 小增益证明一致最终有界，四旋翼强地面效应着陆任务上明显提升鲁棒性。来源：arXiv 2607.06535。

  • 国内具身智能半年 900 亿融资 + WAIC 7/17 开幕：财联社援引 IT 桔子数据，2026 上半年国内具身智能融资总金额已超 900 亿元，同比 +5 倍，融资事件超 300 笔。7 月进入"星动纪元、墨奇智能"等接力阶段，10 亿级融资已成常态。2026 WAIC 将于 7/17-20 在上海举办，智元、宇树、银河通用等 200+ 家企业参展，智元六款新品、宇树无人工厂首次公开，强化学习之父 Richard Sutton 与 Yoshua Bengio 发表主旨演讲。来源：财联社、新浪、官方公众号。

  • 国产算力支撑万亿模型训练：美团 LongCat-2.0-Preview 与 DeepSeek V4 同日亮相，全程依托国产算力集群，动用 5-6 万张算力卡，万亿参数训练推理首次完成国产闭环。来源：公众号、今日头条。

━━━ Agent / 大模型 ━━━

  • GPT-5.6 Sol / Terra / Luna + Superapp（OpenAI）：7 月 9 日向所有 ChatGPT 用户全量推送 Sol（旗舰对话）/ Terra（更长上下文）/ Luna（多模态生成）三件套，"Superapp"统一入口同步上线。Codex 移动端正式登场。来源：buildfastwithai、X/Twitter、TBPN 直播、Yahoo Finance。

  • Meta Muse Spark 1.1：扎克伯格打破 3 年 X 沉默，在 X 上直接发布 Muse Spark 1.1——Meta 首个付费 AI API，比同档定价更激进。来源：Yahoo Finance、X/Twitter。

  • Doomed from the Start（人大 + 中科院计算所 + 浙大 + Duke）：通过召回控制的探测级联在 LLM Agent 第一轮就预测失败——TextCraft 上 90% 召回目标下节省 47.1%（Qwen-2.5-7B）/ 37.2%（Llama-3.2-3B）推理计算。来源：arXiv 2607.06503。

  • DynaKRAG（上交 + 上海飞机制造 + 同济）：把多跳 RAG 表述为"原子证据操作上的状态条件控制"，有效性层动态构建动作集、控制器选下一个操作，在 HotpotQA / 2Wiki / MuSiQue 上 F1 0.5998 / 0.5340 / 0.3061。来源：arXiv 2607.06507。

  • VAORA（台湾大学 + UC Merced, ICML '26 RLxF Workshop）：通过"视觉对齐奖励 + 视觉-动作对齐奖励"抑制 VLM 的幻觉 CoT，并在 PHYRE / Virtual Tool 上验证可泛化到新任务和未见环境。来源：arXiv 2607.06522。

  • ChatGPT Skills 模块化：ChatGPT 推出模块化"Skills"功能（面向个人理财 + 企业），允许用户把银行业务、任务流等串成可发现可安装的 Skill。来源：站长之家 AI 日报。

  • 小红书 Dots 部门 + RED Skill：小红书在 4 月底成立 AI 一级部门 Dots，6 月上线 RED Skill——创作者笔记挂载 AI Skill 组件，用户点复制口令后跳到外部 Agent 安装。平台内 AI Skill 创作者已达 30 万，相关话题曝光 6 亿次。来源：公众号、CSDN。

  • 小红书 AI 搜索"点点"升级：语音"问一问"全量上线——73% 月活有搜索行为、近 90% 搜索由用户主动发起，AI 搜索后社区留存率反而提升 2-3%，颠覆了"问完就走"假设。来源：商学院杂志、公众号。

━━━ AI for Science ━━━

  • 天鹜科技 MatwingsVenus（晓鹜）AI 蛋白质设计平台：将传统蛋白质研发周期从 2-5 年压缩到 2-6 个月，实验次数从上万次降到约 100 次，研发成功率从 1% 提升到 30%。6 个月内设计出高效塑料降解酶，已在循环经济产业化应用。将在 2026 WAIC 上正式展示。来源：界面新闻、公众号。

  • 洞察时空"星阙"物理世界大模型：全国首个面向物理世界的 AI 基础模型，融合 400TB 卫星遥感数据，气象预测精度较传统方案提升 8-12%。来源：中华网、网易。

  • RMISC 时间序列基础模型语料库（南京大学 + 西门子）：约 200 个数据集、1420 亿个时间点的真实世界多元数据，预训练 4 个先进 TSFM，证明真实多元数据显著提升零样本泛化。来源：arXiv 2607.06504。

  • Cytokine Graph Convolutional Attention（宾大 + 胡安·卡洛斯国王大学 + 斯坦福）：把"图卷积注意力"用在图去噪 / 图扩散（DiGress）上，证明 softmax 在注意力后还能提供"近似投影到干净特征空间"的额外去噪能力，比纯线性注意力更稳健。来源：arXiv 2607.06546。
