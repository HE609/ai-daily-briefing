AI 前沿情报日报 ｜ 2026-05-12

【🚨 今日重点】

① Figure AI 发布 Helix 02 — 具身智能迈向全自主家庭长链路任务

Figure AI 宣布 Helix 02（VLA 模型）完成全尺寸厨房自主全套流程：卸载+装载洗碗机，全程无需人类介入，时长 4 分钟。这意味着 VLA 已从单一技能学习进入多步长链路具身任务泛化的新阶段，人形机器人进入家庭场景路径已清晰。具身智能从实验室走向真实物理世界的重要节点。

② Meta AI 发布 V-JEPA 2 — 首个以世界模型驱动的视觉理解基准

Meta AI 发布 V-JEPA 2 及配套世界模型评测基准（Physical AI Benchmark），首次提出"世界模型应该能预测物理未来"的系统化评测框架，覆盖空间推理、多步动作预测、机器人模仿学习等多个 suite。与此前 EU 36kr 报道的"物理具身智能静默范式转移"相呼应——隐式世界模型+物理具身已从学术圈进入工业主流。

③ LMArena 完成 1 亿美元种子轮融资 — 大模型评测进入商业化赛道

LMArena 从 LMSYS 正式分拆为独立公司，由 a16z 和 UC Investments 领投完成 1 亿美元种子轮融资，估值 6 亿美元。这标志着大模型评测从学术开源社区正式进入商业化生态竞争阶段，未来评测将深度整合 API 计费、模型营销与红队安全。开源评测平台商业化的里程碑事件。

━━━ 世界模型 & 空间智能 ━━━

① NVIDIA 发布 Isaac GR00T N1.7 具身基础模型（2026 Early Access）

来源：GitHub NVIDIA/Isaac-GR00T | 2026年5月6日

NVIDIA 正式发布 GR00T N1.7（跨具身 VLA 模型）Early Access 版本，支持多机器人形态（人形+其他形态）的技能迁移，并开源仿真数据管线。与 2025 年 3 月发布的 GR00T N1 相比，N1.7 在跨本体迁移、视觉-语言-动作统一建模、长序列动作规划上均有架构级改进。另有 NVIDIA GTC 2026 手术机器人报道（2minutemedicine.com）。下一代物理具身基础模型的行业标杆已立。

② NVIDIA Cosmos-Tokenizer 开源 — 世界模型tokenizer统一标准确立

来源：GitHub NVIDIA/Cosmos-Tokenizer；arXiv:2501.03575 | 2025年1月

Cosmos-Tokenizer 是 NVIDIA Cosmos 世界模型平台的核心组件，已在 GitHub 开源并持续维护。它实现了8倍总压缩率和12倍处理速度提升（对比其他 tokenizer），并支持视频/图像统一离散化表征。平台论文 arXiv:2501.03575 全面描述了 WFM（World Foundation Model）平台架构。世界模型从生成走向标准化tokenizer基础设施的重要信号。

③ Figure AI Helix 02 全自主家居任务发布

来源：Figure AI Helix 02 | 2026年1月27日

Helix 02 在 Figure 03 人形机器人上完成厨房全程自主任务（4分钟端到端卸载+装载洗碗机），实现了全上身 autonomy（自主）+ 长链路 loco-manipulation。对比 Helix V1（2025年2月发布），02 版的突破在于从单技能演示升级为真实物理世界泛化的多步任务，即 VLA 核心从"技能记忆"到"任务规划"的质变。具身智能走向真实物理世界的里程碑事件。

④ 上海AI Lab/北大/清华联合发布《具身智能发展报告2025》

来源：清华电子系×信通院；SH Lab；量子位报道

2025年末至2026年初，国内顶级机构联合发布多份具身智能白皮书，指出三大核心转变：① 技术范式从"数字模拟"转向"物理交互"；② 隐式世界模型成为预训练发力重点；③ RL成为决策智能关键路径。 SH Lab 明确：隐式世界模型将成为大模型预训练与空间具身智能的发力重点，聚焦隐式变量、轨迹与动作的生成与预测。清华12月宣布成立具身智能与机器人研究院，汇聚计算机视觉、机器人学、控制系统等多领域科研力量。国内最权威机构对世界模型发展方向的一次集体定调。

⑤ 北京大学/极佳科技推进世界模型在机器人中的落地

来源：EAIRCon 2025；arXiv:2510.04678

北大、极佳科技团队在具身世界模型研讨会上展示最新进展，涵盖多步工具使用、多智能体协同策略优化（MATIPO）等方向。arXiv 2510.04678 的 MATIPO 框架专注于多轮工具调用下的具身决策规划，直接支撑 VLA 从"感知"到"执行"的完整链路。国内具身世界模型的代表性工作之一。

━━━ 大模型 & 多模态 ━━━

① 阿里云通义发布 Qwen3-VL — 国产最强开源多模态模型

来源：arXiv:2511.21631；GitHub QwenLM/Qwen3-VL；HuggingFace Papers

Qwen3-VL 是通义系列迄今能力最强的视觉-语言模型，在广泛 benchmark 上实现 SOTA，核心升级：① 上下文窗口扩展至超长多图；② 视觉编码器全面升级，精细物体定位与视频理解大幅提升；③ 已完全开源。 对比 Qwen2.5-VL（arXiv:2502.13923），3系在推理能力与跨模态泛化上有系统性突破。国产开源多模态模型的重要里程碑，直接对标 InternVL3.5。

② 字节跳动 Seed1.5-VL 发布 — 多模态新势力

来源：MarkTechPost 2025年5月15日；Seed官方平台

字节 Seed 团队发布 Seed1.5-VL，定位通用多模态基础模型，聚焦 GUI 控制、视频理解、视觉推理 三大方向，在 60 个公开 VLM benchmark 中取得 38 项第一，包括视觉导航、视频动作预测等。视频理解+GUI控制方向的最强开源竞品之一。

③ 上海AI Lab/OpenGVLab 发布 InternVL3.5 — 开源VLM新标杆

来源：arXiv:2508.18265；InternVL官方博客；GitHub OpenGVLab/InternVL

InternVL3.5 由上海 AI Lab（OpenGVLab）发布，Cited by 629+，在视觉推理、文档理解、视频动作等多维度上均实现 SOTA，提出的 Mono-InternVL（LLM与视觉编码器 monolithic 整合）新架构显著降低推理延迟。开源VLM领域持续领跑，核心力量对标GPT-4V。

④ Meta AI 发布 Llama 4 系列 — 原生多模态+超长上下文

来源：Meta AI 官方博客 | 2025年4月5日；Ars Technica 2025年4月报道

Meta 发布 Llama 4（含 Scout/Maverick 等多型号），首次引入原生多模态能力（图像+文本统一输入），声称上下文窗口达 10M tokens（但实测遭质疑）。LlamaCon 2025（2025年5月首届）进一步明确开放生态战略。Llama 4多模态化标志着开源基础模型进入原生多模态竞争时代。

⑤ Google Gemini 3.0 Flash/Pro — 旗舰多模态升级

来源：Google DeepMind 官方 | 2025年12月17日

Gemini 3 Flash 正式发布，主打"更快更便宜同时能力不降"，在复杂编程任务上超越 Gemini 2.5 Pro，大幅提升可视化生成速度。Gemini 3 Pro 定义为"迄今最智能模型"，主打深度推理与科学计算。多模态旗舰持续系统性升级的旗舰玩家。

⑥ DeepSeek V4 发布 — 国产最强开源基础模型

来源：Mashable 2026年4月报道；Yingtu.ai 对比分析

DeepSeek V4（2026年4月）正式发布，API 价格约为 GPT-5.5 的 15%，在 SWE-bench、AIME、GPQA 等关键指标上逼近顶级闭源模型。开源大模型能力边界全面突破，国产正式进入第一梯队竞争。

━━━ 顶会论文追踪 ━━━

① JEPA-VLA: Video Predictive Embedding is Needed for VLA Models ⭐⭐⭐⭐⭐ 必推

arXiv: 2602.11832 | 2026年2月

核心贡献：系统论证了视频预测嵌入（VPE）在 VLA 模型中的关键作用，发现当前 VLA 瓶颈在于缺乏无泄漏的视频未来预测能力。在 LIBERO 四个 benchmark suite（空间推理、物体理解、目标指令、长期规划）上综合验证，提出 JEPA-VLA 框架。

关键方法：采用 JEPA 风格的无泄漏状态预测，训练 VLA 的世界模型分支，使其在潜在空间中预测未来，而非直接重建像素。

与研究方向关联：直接契合 JEPA / 世界模型 / VLA / 具身智能 核心方向。理解世界模型与 VLA 融合的最系统性文献之一。

② VLA-JEPA: Enhancing Vision-Language-Action Model with Latent World Model ⭐⭐⭐⭐⭐ 必推

arXiv: 2602.10098；HuggingFace Papers | 2026年2月

核心贡献：提出 VL-AJEPA 框架，将隐式世界模型嵌入 VLA 架构预训练阶段，使视觉-语言-动作模型能同时学习感知表征和世界动态预测，两分支通过联合目标函数协同优化。

关键方法：使用泄漏抑制的状态预测作为辅助任务；提出 VLA 与 JEPA 世界模型统一训练新范式，已开源。

与研究方向关联：JEPA / VLA / 世界模型 方向直接对应，是 Helix/GR00T 类 VLA 架构的理论基础。对具身智能研究有直接指导意义。必推。

③ Value-guided Action Planning with JEPA World Models ⭐⭐⭐⭐ 推荐

arXiv: 2601.00844 | 2025年12月

核心贡献：将 JEPA 世界模型与基于价值的动作规划（VAP）结合，通过塑造表征空间使负目标条件（NGC）更具区分性，提升规划能力。

关键方法：基于 JEPA 表征空间的负目标条件塑造；结合 RL 价值函数进行动作规划搜索。

与研究方向关联：JEPA + RL + 规划的直接应用，与 世界模型 / 具身智能 / 空间推理 方向强相关，方法简洁可直接复现。

④ Learning 4D Embodied World Models（ICCV 2025 Oral）⭐⭐⭐⭐ 推荐

ICCV 2025 Oral Paper | CVF Open Access PDF

核心贡献：提出 4D 世界建模框架，首次将时序 3D 表征（4D = 3D + 时间）与具身智能决策结合，可生成逼真的 3D 交互（物体抓取、抽屉打开等），细节达照片级。

关键方法：使用 Gaussian Splatting 与时序世界模型联合训练；提出 4D Embodied World Model（4D-EWM）在真实物理环境中的零样本规划能力。

与研究方向关联：4D Gaussian / 世界模型 / 具身智能 / 空间推理 方向交叉，展示了从视觉预测到时空物理建模的跨越。最接近用户研究方向的论文之一。

⑤ ACM CSUR 2025: World Models 综合 Survey ⭐⭐⭐⭐⭐ 必推

ACM Computing Surveys | GitHub tsinghua-fib-lab/Awesome-Embodied-World-Model | 2025年6月

核心贡献：清华具身智能实验室联合推出的世界模型综述，梳理从 Yann LeCun JEPA 基础到具身智能应用的完整技术路线图，覆盖隐式/显式世界模型、RL-based 世界模型、LLM-based 世界模型、视觉-语言-动作统一世界模型四大分支。

关键方法：系统性分类与对比；从表征学习、动作规划、RL整合三个维度评析；提出具身世界模型未来挑战。

与研究方向关联：世界模型 / JEPA / 具身智能 / 空间推理 方向的顶级综述，与用户研究方向完美对齐。必推。

━━━ Coding & Agent ━━━

① Search-R1: RL驱动的推理+搜索联合训练新范式

来源：arXiv:2503.09516；GitHub PeterGriffinJin/Search-R1 | 2025年3月

核心：将 GRPO/PPO 等 RL 方法与外部搜索结合，使 LLM 能够自主判断搜索调用时机，实现推理与知识更新的联合训练，在 TruthfulQA、MuSiQue 等知识密集型 benchmark 上实现 SOTA。

点评：Search-R1 代表从"CoT 推理"到"Agentic Search 推理"的范式升级——模型不仅推理，还主动判断何时搜索，是 MCP 类工具使用的理论基础。与 GRPO/DPO 等对齐技术联合使用，将显著提升 Agent 工具调用效率。MCP + RL = Agentic 核心路径。

② MiroRL: 首个 MCP-First 深度 RL 框架支持 Research Agent

来源：GitHub MiroMindAI/MiroRL | 2025年8月

核心：MiroRL 是首个深度集成 MCP 工具调用的 RL 框架，训练时直接调用 MCP 工具进行多轮搜索与信息整合，支持 deep research agent 的端到端 RL 训练。

点评：MiroRL 将 MCP 工具调用能力内嵌为 RL 训练的核心部分，而非外挂式 API 调用。这意味着 Agent 在训练阶段就学会根据任务动态选择工具，真正实现了"工具使用"的内生泛化。MCP 生态从 API 层进入 RL 训练层的标志性工作。

③ VL-JEPA: Vision-Language JEPA 统一框架

来源：arXiv:2512.10942；Themesis 博客 2026年1月解读

核心：Meta AI 提出 VL-JEPA（Vision-Language JEPA），将 JEPA 扩展至视觉-语言跨模态联合嵌入学习，首次实现图像级 JEPA 目标与文本级 JEPA 目标的联合优化，为 VLM 提供无需重建像素的高效表征学习路径。

点评：VL-JEPA 是 VLM 表征学习与世界模型预测学习在架构层面的一次重要融合。它证明了 JEPA 风格的目标函数在多模态（而非仅视频/动作）场景下同样有效，且训练效率远超 MAE-style 自编码器。为后续 VLA-JEPA、JEPA-VLA 等工作奠定了理论基础。多模态 + 世界模型的理论基石。
