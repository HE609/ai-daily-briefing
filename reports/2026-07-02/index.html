【🚨 今日重点】（2-3条最值得关注的新发布，附来源）

  1. Claude Sonnet 5 正式发布，全面替换 Free/Pro 默认模型 — Anthropic 6月30日推出 Claude Sonnet 5，原生 1M token 上下文、原生 extended thinking、官方称在 agentic 命令行工程任务上达到 80.4%，定价\(2/\)10 per Mtok（优惠至8月底）。来源：Anthropic Newsroom / TechCrunch / Simon Willison Blog（科技媒体 + X）。

  2. Together AI 拿下 $8 亿 C 轮，估值 $8.3B — 7月1日，AI 算力 Neocloud Together AI 完成 $800M Series C（领投 Aramco Ventures，跟投 NVIDIA），16 个月内估值从 $3.3B 涨到 $8.3B。来源：TechCrunch / NYT DealBook / HPCwire（科技媒体 + LinkedIn）。

  3. TwelveLabs 拿下 $100M Series B 建设"视频超智能" — 7月1日，视频理解平台 TwelveLabs 完成 $100M B 轮（NEA 与 NAVER Ventures 领投，跟投 Amazon/AWS），同签 AWS Trainium 算力协议，向 agentic video intelligence 转型。来源：Bloomberg / TechCrunch / TwelveLabs Blog（科技媒体 + LinkedIn）。

━━━ 顶级研究组新发布 ━━━

  1. Twitter / X 推出 hosted X MCP，AI 智能体可付费直连 X API — 7月1日，X 平台官方上线 hosted MCP 服务，支持 Grok、Cursor 等 agent 按量付费调用 X API。来源：X 官方 (@op7418 转发) / 公众号 卡尔的AI沃茨（X + 公众号）。

  2. Anthropic 发布 Turn-Averaged SAE，提升长对话可解释性 — 提出新稀疏自编码器训练方法，侧重 AI 行为的高层特征提取，对长上下文 session 的外推能力显著优于传统 SAE。来源：Anthropic Transformer Circuits（arXiv / 研究博客）。

  3. Anthropic Claude Science 科研工作台上线 — 面向科研人员，整合文献分析到计算生物学多步骤研究的全流程工具，集成 Claude Opus 4.8 推理能力。来源：Anthropic Newsroom（科技媒体 + 公众号）。

  4. Google DeepMind 发布 Nano Banana 2 Lite 与 Gemini Omni Flash — 7月1日，前者为该系列速度最快、成本最低的图像模型，后者支持高画质视频生成。来源：Google DeepMind Blog（RSS / X）。

  5. ByteDance Seed 发布 Seed2.0 Model Card — 7月2日，字节跳动 Seed 团队发布 Seed2.0 model card，主打"real-world complexity"前沿智能。来源：arXiv（企业发布 + arXiv）。

━━━ 生成模型 / 新范式 ━━━

  1. Prover-Verifier LLM 循环攻克 9 个未解数学难题 — 研究者采用 prover-verifier 循环方法，解决了理论计算机科学中 9 个重大开放问题，引发可解释性社区讨论。来源：X (@AISafetyMemes) / arXiv（X + arXiv）。

  2. OpenAI 发布 GeneBench-Pro：计算生物学研究级基准 — 包含 129 个真实复杂问题的评估基准，测试 AI 在模糊基因数据与分析场景下的能力。来源：OpenAI 官网动态（RSS / arXiv）。

  3. 美团 LongCat 发布旗舰 LongCat-2.0（1.6T MoE + 1M 上下文） — 7月1日，硅基流动代理宣布 LongCat-2.0，主打 Agentic Coding + 原生长上下文。来源：X (@SiliconFlowAI) / 知乎（X + 知乎）。

  4. OpenAI GPT-5.6 Sol 部署至 Cerebras Wafer-Scale 芯片 — 7月1日披露，OpenAI 计划对部分客户将 GPT-5.6 Sol 跑在 Cerebras 上，速度 750 tokens/sec。来源：TechCrunch（RSS / 科技媒体）。

━━━ 多模态 / VLM ━━━

  1. Google 发布 Gemini 3.1 Flash Image 与 Gemini 3 Pro Image — 在 Gemini 3.5 Pro 延期背景下，提供成本可控与高质量两档图像生成档位替代。来源：Google Blog（RSS / 科技媒体）。

  2. NotebookLM 短视频导览全量上线 Web 英文版 — 7月1日，免费英文 Web 端用户可将复杂资料一键生成 60 秒竖屏讲解视频。来源：X (@NotebookLM) / Google Blog（X + RSS）。

  3. arXiv 7月2日 VLM 方向：AdaBoosting Text Prompts for Vision-Language Models — ECCV 2026 accepted，提出 AdaBoost 风格的 prompt tuning 方法，提升少样本 VLM 性能。来源：arXiv cs.LG + ECCV 2026（arXiv）。

  4. Cross-Embodiment Dexterous Manipulation（CEDex）ICRA 2026 最佳路线 — 提出跨形态灵巧操作新框架，200 episodes per task 验证可迁移性。来源：IEEE ICRA 2026 Program（arXiv / 顶会）。

━━━ 具身 / VLA / 机器人 ━━━

  1. arXiv：Multi-scale Mixture of World Models for Embodied Agents (ECCV 2026) — 提出多尺度混合世界模型方法，让具身智能 agent 在动态变化环境中保持鲁棒。来源：arXiv cs.AI + ECCV 2026（arXiv + 顶会）。

  2. arXiv：Self-Improving Robot Policies via RISE World Model Reasoning — 针对 VLA 模型长链路操作难题，引入世界模型推理回路实现自我策略升级。来源：Open Robotics Discourse / arXiv（arXiv + 论坛）。

  3. Cybercab 量产版启动奥斯汀公开道路工程测试 — 7月1日，特斯拉首批量产无人驾驶（无方向盘/踏板）正式上路验证硬件可靠性。来源：IT之家（公众号 / RSS）。

  4. Acti：AI 智能体直接嵌入手机键盘 — 基于 Google Gemini 的"agent 键盘"发布，允许用户用自然语言快捷方式代替 app 内操作。来源：TechCrunch（RSS / 科技媒体）。

━━━ Agent / 大模型 ━━━

  1. Claude Code 默认全面升级为 Sonnet 5，CLI 智能体循环官方文档 — 官方发布 Sonnet 5 migration guide 与四个智能体循环（回合、目标、时间、主动触发）。来源：Claude Blog（RSS / 公众号）。

  2. X MCP + Together AI $800M 共同支撑 agent 经济基础设施 — 7月1日 agent 生态关键拼图到位：算力侧 Together AI、API 侧 X MCP，使 agent 商业闭环初现。来源：TechCrunch / X 官方（科技媒体 + X）。

  3. Anthropic 解除 Fable 5 出口管制，Mythos 5 同步恢复 — 商务部解除了 Claude Fable 5 等模型的出口管制，Anthropic 即将恢复主流访问。来源：X (@AnthropicAI)（X）。

  4. ADK Go 2.0 发布：构建可靠的多智能体应用 — 引入基于图的工作流引擎，新增 HITL 与动态编排，统一了多智能体运行模型。来源：Google Developers Blog（RSS / 知乎）。

━━━ AI for Science ━━━

  1. Claude Mythos 发现 Squid 代理 29 年漏洞 Squidbleed (CVE-2026-47729) — Anthropic 模型发现 Squid proxy 长期被人类审计漏掉的关键内存泄漏漏洞，被评为本月最强 AI4Security 案例。来源：TechCrunch / Anthropic Blog（科技媒体 + arXiv）。

  2. AlphaFold 系列持续渗透生命科学 — 6月底 Nature 报道 Isomorphic Labs 的 AlphaFold 4 推动了结构生物学的新一波"AI 驱动材料"研究浪潮，'An AlphaFold 4' 引发学界关注。来源：Nature / Isomorphic Labs（科技媒体 + arXiv）。

  3. OpenAI GeneBench-Pro + Claude Science 双线布局计算生物学 — OpenAI/Anthropic 本周同时发布计算生物学研究工具，反映顶厂对 AI for Science 战略级投入。来源：OpenAI / Anthropic 官网（RSS / 公众号）。
