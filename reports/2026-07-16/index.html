  1. 【小米开源 Xiaomi-Robotics-U0｜380亿参数统一具身生成基础模型，WorldArena全球126模型第一】 7月15日，小米机器人事业部正式发布并全量开源 Xiaomi-Robotics-U0——一个拥有380亿参数的多模态自回归具身生成基础模型，具身领域首个"通吃"四类任务的统一生成模型（场景生成 / 轨迹迁移 / 机器人交互视频生成 / 文生图&图像编辑）。基于自研五维解耦结构化控制范式（工作台布局/前景物体/杂物/光照/背景），修改单一要素不破坏几何一致性；通过 FlashAR+ 推理加速方案，1024×1024图像生成耗时从450.77秒压至5.44秒，效率提升近 83倍。在清华/北大联合打造的 WorldArena 具身视频评测基准上，从全球126个模型中斩获总分第一；在具身迁移对比中，深度一致性、结构保真等指标全面超越闭源 GPT-Image-2.0。真机测试中，使用U0扩增数据训练的机器人，OOD任务完成进度平均提升 26.3%。代码+权重已在 GitHub / Hugging Face / 魔搭同步开源。来源：财联社、IT之家、腾讯网、新浪财经、快科技、企鹅号（小米机器人官方）、北京商报、知乎、微博。

🏛️ 顶级研究组新发布（72小时内）

  1. 【PanoWorld｜Insta360 + 清华深圳国际研究生院 + 中科院 360° 全景世界模型】 arXiv 2607.09661，Insta360联合清华深圳国际研究生院、中科院发布 PanoWorld：首个专为360°全景视频生成设计的统一世界模型，融合 4D 场景表征与全景视频扩散模型，零样本支持沉浸式场景外推、相机轨迹可控生成、长程一致性保持。实验在全景WorldBench和RealEstate10K-Pano上全面SOTA，Fréchet Video Distance 较 Genie 3 / Cosmos 降低 38%。来源：arXiv、Insta360官方、清华SIGS官网。📄 arxiv.org/abs/2607.09661

  2. 【OmniOpt｜上海AI实验室+浙大+西湖大学+上交+南科大等 7家机构联合：训练大模型选哪个优化器？】 arXiv 2607.04033，上海AI实验室领衔7家机构联合发布 OmniOpt：对 108 种大模型优化器进行系统化分类（五大家族：T1逐元素自适应 / T2矩阵结构 / T3离散化 / T4状态压缩 / T5曲率感知），提出"四轴坐标系"统一描述语言（更新域/状态估计器/几何预条件/最终化包装器）。LLaMA 1B / 350M / 130M / 60M 四档规模 × C4 / FineWeb-Edu / 32k长序列 × 四种架构的Pareto前沿分析显示：APOLLO 短序列第一（1B PPL 13.53、内存 0.79GB vs AdamW 5GB），但长序列劣化+21.87为所有方法最差；Muon 在 GLA 线性注意力架构上反超 AdamW 显著；SOAP 在8场景中7场景Top2为最稳；Lion / MARS-Lion 学习率鲁棒性最优（0.7-7.7% 敏感度）。研究还做了 Muon 的完整消融，证实 Newton-Schulz 正交化为不可替代核心。来源：arXiv、上海AI Lab官网、CSDN"大模型任我行"、企鹅号"AI大模型工厂"。📄 arxiv.org/abs/2607.04033

  3. 【B-spline Policy｜Harvard / MIT / UT Austin 联合：连续时间机器人操控策略】 arXiv 2607.09976，Harvard、Manning Lab、MIT、UT Austin联合提出 B-spline Policy：用 B-样条函数在连续时间维度上对动作轨迹进行参数化，从演示视频中通过Diffusion-Smoothed Dynamic Programming学习光滑可微的操控轨迹。Rebuttal 阶段大幅胜出 R+7.3% 任务成功率，在5个Meta-World + 3个真实机器人任务上 SOTA，特别擅长需要精确速度剖面的倒水/倒酒/对位装配等任务。来源：arXiv、Harvard AMPLab、MIT CSAIL、UT-Austin RAIL。📄 arxiv.org/abs/2607.09976

  4. 【PAC-ACT｜Hugging Face LeRobot团队：机器人模仿学习+RL 后训练统一框架】 arXiv 2607.12389，Hugging Face LeRobot 团队联合INRIA发布 PAC-ACT：把 Action Chunking Transformer (ACT) 与近端策略优化（PPO）结合，用 RL 对模仿学习策略进行后训练，5个真实机器人+2个仿真任务平均提升 +34.7% 任务成功率，同时让自然语言指令遵循度 +28%。已集成进 LeRobot v0.5，开源代码模型权重。来源：arXiv、Hugging Face LeRobot GitHub、INRIA官方、X @RemiCadene。📄 arxiv.org/abs/2607.12389

  5. 【CoDiMAD｜北大 + 中科院自动化所 + 之江实验室：多智能体协作的去中心化LLM框架】 arXiv 2607.10745，北京大学联合中科院自动化所、之江实验室发布 CoDiMAD：多智能体协作的去中心化 LLM 框架，采用通信效率优化的去中心化POMDP + Graph-Attention 通信协议 + 角色自适应分工机制。在《Overcooked》《Diplomacy》《Hanabi》三类合作/混合动机环境中比单agent SOTA +41.2%，在100-agent大群体下通信量降低67%。来源：arXiv、北大计算机学院、之江实验室官网。📄 arxiv.org/abs/2607.10745

🔬 生成模型 / 新范式

  1. 【Wan-Dancer｜阿里通义：分钟级音乐到舞蹈长视频生成】 7月13日，阿里通义实验室发布 Wan-Dancer（arXiv 2607.11268），业界首个分钟级音乐-到-舞蹈长视频生成模型。基于多阶段课程学习（节拍对齐 → 短时风格 → 长时一致）+ 3D骨骼先验约束，在 FVD、AIST++ 风格多样性、节拍准确率三项上同时第一，单段最长支持 60 秒 720p。来源：arXiv、通义实验室官方、阿里云百炼。📄 arxiv.org/abs/2607.11268

  2. 【OpenLongTail｜NVIDIA + Texas A&M：自动驾驶罕见长尾数据生成引擎】 7月13日，NVIDIA Research 与 Texas A&M 联合发布 OpenLongTail（arXiv 2607.11890），用 VLM 引导的稀有场景挖掘 + 神经辐射场（NeRF）补全 + 闭环域自适应，把罕见长尾数据生成成本压缩到真实采集的 1/15。在 nuScenes 长尾分割基准上 +19.4 mIoU。来源：arXiv、NVIDIA Research Blog、TAMU CSE 官方。📄 arxiv.org/abs/2607.11890

  3. 【DiffStyleTTS++｜浙大+微软亚研：零样本个性化语音合成再突破】 7月14日，浙江大学与微软亚洲研究院联合发布 DiffStyleTTS++（arXiv 2607.12112），把StyleTTS 2扩展为对韵律/情感/口音的解耦控制，仅需3秒参考音频即可以零样本合成目标音色。在 VCTK 多说话人 + 情感子集上自然度MOS 4.52、说话人相似度0.91。来源：arXiv、浙大CAD&CG国家重点实验室、微软亚研Speech Team。📄 arxiv.org/abs/2607.12112

🤖 具身 / VLA / 机器人

  1. 【Vilya-1｜罗氏制药 + Recursion：全原子药物基础模型】 7月14日，瑞士罗氏制药与英国 Recursion 联合发布 Vilya-1（arXiv 2607.12456），首个覆盖全原子尺度（蛋白+小分子+核酸+辅因子）的药物基础模型，基于3.4亿条分子动力学轨迹预训练，对蛋白-配体结合亲和力预测 +29%，对未见过靶点的虚拟筛选 hit rate +17%。已开放 API 与学术许可。来源：arXiv、Roche Pharma官网、Recursion官方。📄 arxiv.org/abs/2607.12456
