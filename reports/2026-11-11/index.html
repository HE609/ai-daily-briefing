本期检索窗口为北京时间 2026-11-08 09:01 至 2026-11-11 09:01，资源状态核验延伸至成稿。候选入口覆盖 arXiv Robotics、AI、CV、ML 的 new/recent 与交叉投稿，机构官方研究发布，GitHub、Hugging Face，独立的 Spatial Intelligence、3D/4D 生成与 real-to-sim 主线，以及 VLA/WAM、Robot Learning、Agent 与自演化。相对上一期，已报道项目按新版本、可用资源、基准结果和第三方验证去重。Claude Fable 5.2、Steel 与 SoftPAT3D 的公开时间已早于上一期成稿，上一期候选记录未覆盖，本期将其明确作为 Retrieval Failure 回补。

今天最重要的变化是，机器人基础模型、可执行仿真和通用 Agent 正在形成更完整的学习闭环。Gemini Robotics 2.5 带来工业试点与具身安全评测，Steel 降低异构仿真的计算成本，RoboScript 用仿真反馈形成可迁移任务记忆。空间智能同时出现动态世界重访评测、可变形场景生成和长时导航记忆三条实质进展。本期展开十项，优先阅读其中五项。文中的数值均注明作者或官方来源，研究机会与轻量实验属于本报分析。

今日精读顺序

今天我建议的精读顺序是：Gemini Robotics 2.5 → RoboScript / WICL → WanderBench → LingBot-Touch → Steel。

  • Gemini Robotics 2.5。先看通用 VLA 在真实工业任务、灵巧操作与安全约束上的新证据，重点审查试点成功率的统计范围。
  • RoboScript / WICL。理解示范、仿真练习、冻结记忆与新场景部署之间的接口，同时核算“一条示范”背后的交互和推理预算。
  • WanderBench。把空间世界模型的阅读标准推进到事件时间、相机控制和动态重访一致性，适合据此设计评测。
  • LingBot-Touch。看一个具有公开编码器权重的跨传感器表示模型，关注几何标准化、JEPA 目标及真实策略收益。
  • Steel。核对异构机器人仿真的吞吐、内存、接触精度与求解器配置，为大规模机器人学习建立成本基线。

1. Gemini Robotics 2.5｜P0

Google DeepMind Gemini Robotics 团队发布，官方文章署名 Carolina Parada，官网日期为 2026-11-10。性质为官方模型与合作伙伴部署发布，技术披露主要来自研究博客和模型页面，同行评审状态待核。它关注多本体灵巧操作、工业可靠性和物理安全，同时把具身推理模型与动作模型接入同一工作流。官方发布

公开机制包括 Gemini Robotics ER 跟踪任务工作流、2.5 动作模型控制手臂与手部、推理时 guidance 处理物理约束。Gemini 4 Argon 参与从相机场景构建数字孪生、生成仿真练习和分析失败视频。完整架构、数据配比及训练损失尚待进一步披露，当前能够审查的是系统接口、示例和官方评测设计。

官方结果覆盖 200 多种任务。发布页称不同任务类别的成功率相对提升 30%–100%，完成时间减少 20%–30%。Apollo 2 在奔驰两处生产线的零件分拣、排序试点报告 96% 成功率。该数字对应具体 automotive kitting proof-of-concept，累计运行时间、人工介入和长期停机情况仍需补充。ASIMOV-Jailbreak 上，Argon 的官方抗越狱率为 99.5%。结果与评测范围

它承接 Gemini Robotics 的推理—动作分工，与上一期 GR00T 2 的联合世界—动作学习形成可比较的系统路线。本报更关注语言约束如何真正改变运动轨迹，以及工业成功如何随任务复杂度变化。值得精读，优先读安全 steerability 和试点协议。本轮尚未找到这些机器人指标的独立复跑。

模型正向合作伙伴开放，主权重、完整训练代码和训练语料的公开交付仍待核。ASIMOV 数据仓库可见评测脚本与 Parquet，标注 CC BY 4.0，访问带自动许可门槛。轻量验证可从公开机器人策略出发，固定二十个场景，比较约束 guidance 开关，并同时记录任务成功、碰撞、拒绝率和延迟。ASIMOV 官方数据与评测入口

2. Steel — Scaling Simulation Across Robots, Tasks, and Worlds｜P0

Skild AI 与 NVIDIA 联合发布。官方仓库将开源日记为 2026-11-09，首个公开提交时间为当天 08:51 UTC。性质为物理求解器与代码发布，配套官方性能研究。Steel 面向同时包含不同机器人、关节规模、任务与接触结构的 GPU 仿真批次。官方技术文章 · 发布仓库

方法结合 约化坐标关节动力学、Projected Gauss-Seidel 约束求解、关节空间质量矩阵分解复用，按关节数量组织计算，并依据每个环境的接触负载分配工作。它作为 Newton 的求解器服务于机器人学习，优化目标是物理仿真的吞吐与内存效率。公开测试使用 Newton 1.8 release candidate，并启用 reuse_kinematics=True。

官方在单张 RTX PRO 6000 Blackwell 上报告，二十项任务的吞吐相对 PhysX 几何平均为 3.8 倍，相对 MuJoCo Warp 约 1.3 倍。二十任务异构混合的最优批量比较达到 13.0 倍。在双方同为 61,440 环境时，吞吐约为 361 万与 30 万 env-steps/s，显存约为 11 与 29 GiB。统计对象为 simulation-step throughput，训练收益还取决于渲染、策略更新与数据传输。硬件、批量与测量条件

创新价值在于降低任务和本体多样性带来的 padding 与求解开销，这对跨本体基础策略和仿真课程很重要。物理误差、接触稳定性、不同批量和开关配置都需要配合速度评测。值得精读并做小规模复跑，本轮独立性能验证状态待核。

已核到 Newton 内的实际求解器、示例和测试，以及 WebGPU 实现，采用 Apache-2.0，资产另按来源授权。轻量验证可固定四种机器人任务、时间步、求解迭代和随机种子，在 64–1,024 环境下测吞吐、峰值显存、穿透、能量漂移，再比较达到同一策略成功率所需的墙钟时间。Newton 求解器源码 · WebGPU 实现

3. World In-Context Learning for Agentic Robot Manipulation — RoboScript｜P0

Heng Fang、Zehui Guo、Yuehan Zhang、Mingyang Du、Dingkang Liang、Xiang Bai，华中科技大学与 ArcheOne AI。预印本 v1 提交于 11-09 18:59:45 UTC，即北京时间 11-10 02:59:45。研究问题是，冻结的通用模型如何通过世界反馈，从一条示范形成能够部署到新场景的操作知识。论文 · 项目页

WICL 的链路为 技能构建 → 示范初始化 Task Memory → 仿真 rehearsal 与记忆修订 → 冻结记忆部署 → 跨批次反思。Agent 侧使用可部署的观测、几何与动作工具，控制平面持有训练期监督和官方验收。学习对象是可读任务记忆与指导规则，参数保持冻结。附录给出了模拟器信息隔离、坐标检查及练习停止条件，适合与 Reflexion 和经验驱动 Agent 学习共同阅读。

作者结果为 RoboTwin 2.0 五十任务、每任务每设置十回合，共一千个测试回合。GPT-6.1-Sol 的 clean/randomized 成功率为 83.6% / 83.2%，均值 83.4%。论文的最强训练策略比较项为 61.7%，适用其 clean-only 训练和表中基线范围。消融中，十任务上的完整部署流程为 78.5%，直接把示范写入记忆为 69.0%。真机四任务各十次，分别成功 10、7、7、6 次，使用仿真记忆适配后的离线动作计划。论文与完整协议

最值得审查的是交互预算。Sol 平均每任务 rehearsal 约 12.5 个实例，部署每回合平均 54.7 次模型调用、233 万 tokens。五十任务学习加一千次评测，作者按标价估算约 1,911 美元。一条示范之外还包含世界交互、工具和基础模型先验。值得精读，优先看信息边界、恢复与成本表，独立复现状态待核。

Apache-2.0 仓库已包含 core、wicl/rsi/skill_builder、视觉服务及 RoboTwin 流程，真实机器人部署代码仍列在 TODO。模拟器资产和模型 API 需另行准备。轻量验证先用内置 Mock 检查状态流，再取三个任务，比较示范记忆、rehearsal、rehearsal 加反思三组，固定测试种子并计入全部练习、推理和失败成本。代码与运行入口

4. LingBot-Touch — Learning Heterogeneous Tactile Representation for General Dexterous Manipulation｜P0

Bing Han、Yichuan Peng、Haoyu Dong 等，Robbyant 蚂蚁灵波团队，项目负责人 Wei Ning。论文 v1 为 11-09 18:12 UTC，北京时间 11-10 02:12，伴随编码器与推理代码发布，同行评审状态待核。它研究压阻、磁式与视觉触觉传感器之间可迁移的接触表示。论文 · 官方项目

模型将 taxel 的位置映射到 canonical fingertip geometry，以模态专属 tokenizer 接入共享 Haptic Transformer，通过 Tactile-JEPA 预测被遮蔽时空区域的潜表示，并使用 EMA target、布局与信号增强。预训练语料为 4,983 小时、464,431 episodes、约 13.3 亿帧。下游冻结编码器，通过 attention query 接入现有策略，HaT-Tiny 约 546 万参数。

作者真机实验涵盖两种手、二十六任务，报告每任务二十次试验。主控制表使用 4K 小时预训练的 Tiny，LingBot-VLA 的平均成功率从 48.3% 提高到 73.1%，π0.5 从 48.1% 到 69.9%。十二项仿真 RL 任务报告三种子结果。语料总规模、4K 主表与额外 5K 缩放实验应分别记账。实验表与训练设置

它把 JEPA 的表示预测推进到异构触觉，与 BAT-WAM 的未来触觉—动作联合预测可以组成互补研究问题。局限包括电容传感器覆盖、掌面接触不足，以及跨传感器几何和信号规范的依赖。值得精读并优先做公开权重验证。目前所列控制收益来自作者实验，第三方任务复跑待核。

已核到 Tiny/Small 的 config.json 与 encoder.pt，HF API 显示公开且无 gating，权重约 21.9/87.1 MB。仓库公开冻结编码器推理、传感器适配及样例，完整预训练语料和训练链交付待核。轻量实验可用两类样例做固定编码器 probe，比较原始触觉、CNN 和 JEPA 特征，并独立扰动 taxel 布局及标定误差。代码与模型卡采用 Apache-2.0。代码 · Tiny 权重 · Small 权重

5. SWAM — Scaling World Action Models with Cross-Modal Alignment｜P0

研究整理约 47,016.7 小时 general、ego、UMI 与 robot 数据，系统改变语言标注细度、环境描述、视频与动作监督、数据混合和模型结构。视频分支从 Wan2.2-TI2V-5B 初始化，动作分支随机初始化，两者通过 masked attention 交互，以视频与动作 flow-matching 目标联合训练。其研究价值是把标注质量、监督来源与结构放入可比较的缩放实验。方法与消融

作者结果为仅用五十任务 clean 示范后训练，RoboTwin Easy/Hard 成功率 88.10% / 61.56%。真实双臂 Flexiv 的三个任务分别后训练，每任务每设置十布局、每布局三次，Hard 平均成功率 40.00%，最强报告基线 OpenWAM 为 23.33%。Hard 指 clean-to-random 泛化，Easy 及部分完成率 PSR 的分母和含义单列。跨论文比较还需对齐数据、后训练和动作接口。结果与真实评测协议

它连接 DreamZero、OpenWAM、GR00T 2 的视频—动作学习路线，本报建议优先看 detailed caption 与环境信息的控制收益。局限是数据质量、来源和规模仍可能共同变化，三项真实任务也限制了推广范围。值得精读配方与消融，本轮独立复现状态待核。

已核到公开训练、checkpoint 转换与 RoboTwin 评测代码，以及 HF 的分批 TAR 数据。数据卡明确 UMI 仍待 Noematrix 后续发布，部分上游视频需自行取得，当前主模型权重下载入口仍待核。轻量验证可固定一个小型 video-action backbone 和同量数据，仅改变短/详细标注、环境描述和 ego/UMI 混合，联合测语言遵循、动作成功与视频预测。代码 · 数据范围与上传状态

6. WanderBench — Can World Models Explore Dynamic Worlds from Video?｜P0

Yuhang Chen、Jiheng Li、Jiale Wang、Zai Wang、Guangyue Liu，华中科技大学。v1 提交于 11-09 15:23:53 UTC，北京时间 11-09 23:23:53。性质为视频条件世界探索基准与免训练方法预印本。它把“探索一个已记录的动态世界”作为独立空间智能问题，要求保留人物身份、事件进程和返回地点时的当前状态。论文

基准包含 745 段真实及生成单镜头视频，长度 3–25 秒，用键盘动作定义相机路径，以六个维度、二十四个子指标评估输出。生成帧与源视频按同一事件时间对齐。WanderLand 将同一时刻的源帧持续输入冻结模型，并在重访时复用此前的静态内容，目标是同时维持源动态与空间记忆。评测与机制

作者测试八个模型，五个受长度限制的模型按可生成的前缀计分，Medium/Hard 主要比较三个全长度模型。Hard 层的平均源动态保真分约 37.2/100，动态重访也是共同弱项。WanderLand 在五个模型的六维度上均有提升，源动态保真最大提高 8.3 分。这些是该基准中的作者测量，指标与机器人闭环成功之间仍需建立实证联系。

相对 VBench、WorldScore 等工作，它新增了源视频事件时间和动态返回的明确约束。本报认为，这能识别长期生成中的“场景仍像原处、事件已偏离”的失败。局限包括 VLM/几何估计器参与评分、真实与生成源视频混合，以及不同模型可评时长的差异。值得精读，适合用于评测设计。结果表与评测条件

本轮尚未核实本论文专属代码、完整视频集和评分包的稳定下载入口，第三方复跑待核。轻量验证可先制作二十条有已知事件时间的路线，包含离开、遮挡、返回和物体状态改变，分别标注主体身份、相机路径、事件时序和返回状态，再与感知质量分数比较。用公开小型视频模型测试源帧条件和重访记忆两个开关即可开始。

8. Compass 1 — Open-World and Persistent Embodied Navigation｜P1

Hai Zhang、Siqi Liang 等，香港大学、上海创智学院、Archon Robotics、Spatial Robotics 与华为。论文 v1 提交于 11-09 09:04:48 UTC，北京时间 11-09 17:04:48，项目公告日期为 11 月 10 日。它研究单目 RGB 导航中的长时历史使用、开放环境探索与回到过去目标的能力，同行评审状态待核。论文 · 项目页

10. InfraRSI — Harnessing Recursive Self-Improvement for Training Infrastructure｜P1

作者四个 dense/MoE 训练工作负载覆盖 8×H100、8×H200 与双节点 16×H100。几何平均加速为 1.83 倍，最大值 2.75 倍，平均 MFU 从 17.4% 到 30.0%。作者还审计 1,212 条执行记录与十六项验收不变量。最大加速、平均加速、失败搜索成本和最终训练吞吐需要分别统计。实验与验证器

今日研究机会与轻量验证

  • 优先做动态重访评测。构造二十个带事件时间的场景，包含物体移位、状态改变和遮挡。比较纯视频递归、静态记忆、时间对齐记忆，指标为身份保持、事件时序、相机误差、返回状态和视觉质量。先验证各指标能否识别同一组可控错误。
  • 审计一条示范的实际学习成本。固定三个 RoboTwin 任务与二十个留出种子，比较示范记忆、仿真练习和反思。记录示范、练习回合、API tokens、墙钟、首次成功与错误完成声明，给出达到同等成功率的总成本。
  • 验证触觉表示的独立增益。先用 LingBot-Touch Tiny 的公开样例测试信号、布局和几何接口，再比较 raw/CNN/JEPA 与线性/attention probe。只有 probe 通过后再接固定策略，检验接触质量和任务成功之间的关系。
  • 连接仿真速度与训练收益。固定四任务、两种接触难度及同一策略，分别计量物理步、渲染、更新和端到端时间，同时测穿透及成功率。InfraRSI 的小模型实验也使用相同总成本原则，计入全部失败搜索与最终复验。
