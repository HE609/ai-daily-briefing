━━━ 顶级研究组新发布 ━━━

【arXiv · 5月22-25日新帖精选】

  1. EVE-Agent: Evidence-Verifiable Self-Evolving Agents - 作者：Yamato Arai, Yuma Ichikawa - 提出证据可验证的自演化Agent框架，Agent能够自主验证自身输出并持续优化，无需人工干预。 - 来源：arXiv cs.AI（2026-05-22）

  2. SkillOpt: Executive Strategy for Self-Evolving Agent Skills - 作者：Zhipu/清华团队（Chong Luo等） - 研究Agent如何自主获取、选择和执行技能策略，实现技能组合的最优化执行。 - 来源：arXiv cs.AI（2026-05-25）

  3. MemAudit: Post-hoc Auditing of Poisoned Agent Memory - 作者：多机构联合 - 通过因果归因和结构异常检测，对被污染的Agent记忆进行事后审计，提升Agent安全可靠性。 - 来源：arXiv cs.AI（2026-05-25）

  4. Foundation Protocol: A Coordination Layer for Agentic Society - 作者：多机构联合（Bang Liu等） - 提出"Agent社会"的协调层协议，为多智能体协作提供标准化协调机制。 - 来源：arXiv cs.AI（2026-05-25）

  5. RMA: Agentic System for Research-Level Mathematical Problems - 作者：Zelin Zhao, Bo Yuan等 - 构建可解决研究级数学问题的Agent系统，结合推理与工具调用。 - 来源：arXiv cs.AI（2026-05-25）

  6. LLMs as Noisy Channels: A Shannon Perspective on Scaling Laws - 作者：徐欧阳、Thomas Hartvigsen等 - 从信息论角度重新审视LLM缩放定律，将LLM建模为噪声信道，提出新的容量和扩展理论。 - 来源：arXiv cs.LG（2026-05-25）

  7. CVSearch: Empowering Multimodal LLMs with Cognitive Visual Search - 作者：arXiv cs.CV（2026-05-22-25） - 为多模态LLM注入认知视觉搜索能力，提升高分辨率图像感知性能。 - 来源：arXiv cs.CV

  8. Any2Any: Efficient Cross-Embodiment Transfer for Humanoid Whole-Body Tracking - 作者：Ming Yang, Tao Yu等 - 实现跨构型人形机器人全身跟踪的高效迁移，一个策略可泛化至多种机器人形态。 - 来源：arXiv cs.AI（2026-05-25）

  9. PhotoFlow: Agentic 3D Virtual Photography Missions - 作者：郭嘉瑞等 - Agent可执行3D虚拟摄影任务，融合具身感知与生成式AI。 - 来源：arXiv cs.AI（2026-05-25）
