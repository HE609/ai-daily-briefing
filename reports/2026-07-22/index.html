━━━ 生成模型 / 新范式 ━━━

  • 昆仑万维 Matrix-Game 3.5 Patch 级长期记忆：从 Frame-level FOV Memory 升级为 Patch-level FOV Memory，将历史帧切分为带 3D 坐标的 Patch Memory（Depth+Pose Lift 至世界坐标系），推理时按当前相机视锥检索可见 Patch 并重投影到当前视角形成 Mosaic。来源：腾讯新闻 / 智东西

  • Matrix-Game 3.5 三方面系统级加速：①采样步数压缩至 3-step + 分块因果推理（Chunked Causal Inference）+ KV Cache + Patch/Predict Latent；②DiT 优化（FFN INT8 量化 + Memory Retrieval Optimization + Torch.compile）；③MG-LightVAE 对 Wan2.2 VAE Decoder 75% 结构化剪枝 → 单卡 720p 20FPS 实时流式。来源：智东西

  • Matrix-Game 3.5 三大自动化数据生产管线——UE5 自主探索 + 跨 3A 游戏（GTA V/荒野大镖客 2/赛博朋克 2077）自动控制 + 开放平台视频自动挖掘；已积累 500 万 + 视频切片 / 1 万 + 训练小时 / 1200 + 游戏场景；Pose+Depth+Camera 内参自动标注。来源：智东西

  • 昆仑万维 Mureka v9.5 + O3 音乐大模型——MusiCoT 路线让旋律/编曲/情绪更自然（指令精准度 6.92→7.62），O3 通过 test-time scaling 持续推演+回看偏差+自我修正；Character 功能（一段声音+一张照片生成专属歌手角色）贯穿歌曲/MV 全链路。来源：腾讯新闻

  • 英伟达 Cosmos 3 三层应用——①多模态图文大模型；②世界模型/视频基础模型（仿真物理环境、预判场景未来状态）；③世界动作模型（WAM）主干网络（辅助训练机器人完成专项任务）。Cosmos 3 Super/Nano 已发布，Edge 版即将上线。来源：NVIDIA Developer 博客
