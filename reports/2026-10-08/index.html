今日精读顺序

今天我建议的精读顺序是：

A → AIM：先看 real-to-sim 中“关系随形变更新、全局状态保持一致”的动力学接口，适合建立可验证的物理世界状态基线。

B → PEARS：再看冻结流策略外接物理先验、触觉和力位控制的低交互适应，连接 world model 的预测与真实接触。

C → QF3：随后读 flow policy 的离线数据复用与 Q 梯度过滤；它给“策略如何在有限交互下继续变强”提供了清晰的 RL 机制。

D → WorldSonus：补上生成世界的声音、空间和交互控制，检查视觉 world model 是否正在扩展成多感官环境模型。

E → ScienceClaw：最后读 replay-gated 的程序级自进化，把“经验变成可回滚能力”的评测协议迁移到机器人技能和 verifier。

重点论文 / 模型 / 项目

1. WorldSonus: Bringing Sound to Worlds｜P1

作者与机构、发布时间、性质。 Pengjun Fang、Jingyi Fa、Kam Man Wu 等 12 位作者，来自香港科技大学、Noiz AI、MetaX、上海交通大学等；arXiv:2610.08760，2026-10-06 UTC 提交，是 CC BY-NC-SA 4.0 的研究预印本，尚非同行评审。论文与项目页见 arXiv 和 WorldSonus 项目页。

它解决的是生成式世界“能看、能动，但没有与视角和事件同步的声音”的问题。模型把外部视频 world model 当作上游，只读取已经生成的视觉流，不要求访问上游动作空间或内部结构；因此更像可插拔的空间音频层，而不是完整的 world-action model。

核心是流式因果自回归 Transformer 加 rectified-flow 音频头：每 100 ms 输出一块 48 kHz 立体声，环形 KV cache 让历史内存有界；两种时间尺度的视觉条件分别负责长程语义和帧级定位；训练时用冻结的 Synchformer 做 ShiftNCE 时间对齐，真实立体声和 FOA 环绕声解码提供左右声道的空间监督；提示词可以在 chunk 边界中途切换。训练目标是因果条件概率与 ShiftNCE 时间对齐损失的组合。

作者报告在单张 H100 上每 100 ms 音频块耗时 41.2 ms（RTF 0.41），5 秒清晰立体声 VGGSound 的 VGGish-FAD 为 1.73，30 秒交互视频为 2.03，并在开放域视频到音频和交互基准上达到或超过所比较的双向模型；这些都是作者实验结果，当前没有第三方复现。局限是音频因果表示、有限的高质量立体声数据和长期会话稳定性，且还没有证明声音能改善机器人规划或接触判断。相对 LingBot-World 2.0、GameGen-X 等视觉/交互 world model，它补的是“空间化、可中途修改的听觉状态”。值得深入阅读，尤其适合做多感官 world state；代码、权重和训练集未在本轮确认公开，项目页主要提供论文、演示和说明。

轻量验证：用一个冻结的视频生成器或公开视频流，先只实现 100 ms chunk 的 causal V2A 小模型；做“左/右声源互换、提示词中途切换、遮挡后声源保持”三组反事实测试，同时报告首块延迟、累计漂移和 stereo balance，不要把 41.2 ms 直接当成完整端到端交互延迟。

2. AIM: Adaptive Interaction Modeling Networks for Real-to-Sim Soft-Body Simulation｜P0

作者与机构、发布时间、性质。 Tiancheng Yang、Dingshuo Chen、Tianle Chen、Zhaocheng Liu、Qiang Liu，主要来自中国科学院自动化研究所 NLPR/MAIS 与中国科学院大学，Zhaocheng Liu 为独立研究者；2026-10-05 UTC 提交，arXiv 预印本，论文链接：AIM。

AIM 针对布料、薄片和食物等软体对象的 real-to-sim：仅按当前空间邻域连边会漏掉折叠后仍有结构耦合的远距离粒子，误差在自回归 rollout 中累积；按单个场景拟合的模拟器又难以换物体、换动作、换场景。

它把动力学拆成可解释的局部—全局交互。候选边是“当前空间邻域 ∪ 上一步保留的高置信关系”，用运动历史、几何和最近控制点推断边的关系嵌入与权重；同时通过 geometry-conditioned global token 协调对象级响应。统一的 kinematic control-point 接口表达不同操控器和动作，不需要 action-category 标签；训练用多步自回归监督，让模型在自己的预测状态上继续学习，而不是只拟合一步真值。

在 PhysTwin 和 PGND 上，作者报告相对 PhysTwin 的未来预测跟踪误差下降 20.0%，相对 PGND、六类对象的长期粒子误差下降 22.8%，并展示跨动作、对象、场景，以及从机器人交互到人类操作的 zero-shot transfer。这些是作者报告，尚无第三方验证；它和 PhysTwin、PGND、SoMA 的关系是把固定局部图推进为带历史记忆的自适应结构，而不是把视觉重建本身做得更精细。局限是 learned simulator 仍然依赖粒子标注、控制点定义和数据分布，论文没有给出真实机器人闭环成功率；本轮也没有确认公开权重或完整训练代码。值得精读，因为它把“几何一致性”直接落到 action-conditioned transition 上。

轻量验证：在公开或自建的布料粒子模拟器上固定控制点，做四个小实验：静态邻域、保留边、自适应边、自适应边+global token；用同一动作序列报告 1/10/30 步 rollout MDE、折叠后远距离粒子的一致性，以及 robot→human 控制轨迹迁移。先验证关系保留是否真的减少长程漂移，再考虑大规模 real-to-sim。

3. PEARS: Physical-Prior-Guided Efficient Adaptation via Failure Reasoning and Diffusion Steering for Tactile Manipulation｜P1

作者与机构、发布时间、性质。 Kun Song、Yiming Wang、Yilin Chen、Tianyi Ding、Jiaxin Tian、Tianqi Gong、Daolin Ma、Jia Pan，来自香港大学、上海交通大学、Xense Robotics、宾夕法尼亚大学；2026-10-06 UTC 提交，arXiv 研究预印本，论文与演示见 arXiv 和 项目页。项目页标注代码仍在整理/under review。

研究问题是：预训练策略在部署中遇到接触力、定位或时序偏差时，如何用少量昂贵甚至有破坏性的交互恢复性能。PEARS 不更新基础 flow-matching policy，而是在其外部放置两个互补环节：PFR 用 VLM 中的物理先验、视觉结果和触觉历史判断“力太小/太大、位置错误还是运动错误”，更新下一回合的接触力边界；tactile-conditioned diffusion-steering RL 调整流策略的 latent noise，修正自由空间轨迹与接触时刻；stage-aware hybrid force-position controller 负责把边界落实到接触轴。

作者报告在三项仿真接触任务上比最强逐任务基线高 12.4–37.4 个百分点，达到目标成功率所需交互回合最多减少 53.2%；实机白板擦除 19/20、移液吸取 18/20。结果是作者/官方页面报告，任务数量和试验预算仍小，VLM 的失败归因可能成为新瓶颈，也没有独立实验室复现。它与 Residual RL、触觉策略适应和 force-position control 的关系，是把“失败解释”转成边界调节，把策略更新约束在冻结基础模型周围；值得深入阅读，尤其适合作为 WAM/VLA 后训练的低成本适应基线。

可复现性：论文、项目页和视频公开，完整代码/权重/数据包未确认；非同行评审。轻量验证：先在二维推拉/擦除接触模拟中冻结一个小 flow policy，比较“只做 latent steering”“只改力边界”“两者联合”，记录达到 80% 成功率的回合数、失败类别混淆矩阵和接触峰值；然后再迁移到真实触觉设备。

4. QF3: Fast Flow RL with Filtered Q-Gradients｜P1

作者与机构、发布时间、性质。 Chung Min Kim、Brent Yi、David McAllister、Hongsuk Choi、Himanshu Gaurav Singh、Jinkun Cao、Ken Goldberg、Pieter Abbeel、Carmelo Sferrazza、Angjoo Kanazawa，团队信息指向 UC Berkeley 与 Amazon FAR；2026-10-06 UTC 提交，是 arXiv 预印本，含项目页 QF3 与 论文。

QF3 处理 flow policy 的一个实际矛盾：flow matching 能从示范学会动作，但在线 RL 的 critic 梯度可能把策略推离 replay buffer，进入 critic 不可靠的区域。它用一条 one-step flow prediction 估计最终动作，再按动作维度检查预测是否仍接近 replay action，只让可靠维度接收 Q-gradient；未通过过滤的维度保持 flow-matching 目标。这相当于一个在动作维度上的局部信赖域，而不是把整个动作向量粗暴裁剪。

作者报告这是首个从零训练 humanoid locomotion flow policy 并 zero-shot 迁移硬件的 off-policy flow RL 方法；在配合高吞吐 replay 训练配方时，humanoid locomotion/motion tracking 相比 FPO++ 达到约 10× wall-clock speedup，并在 ABC-Sim 和 RoboMimic 上微调预训练 manipulation policy。当前指标全是作者报告，10× 是特定任务与整套训练配方的结果，不应归因于过滤器单一组件；项目页没有确认公开 checkpoint 或完整复现实验包。

它和 FPO++、FlowRL、QSM 的关系是从 on-policy flow RL 转向 replay reuse 与局部 Q 指导；对 WAM/VLA 的意义在于可以把昂贵的 rollout 变成更有效的后训练，而不是替代 world model。值得读机制和 ablation，尤其是 Direct-Q 崩溃与 action-space clipping 的对照。轻量验证：先在 2D toy flow 或小型 Robomimic 上做同一 replay buffer 的 Flow Matching、Direct Q、QF3 三组，固定 actor/critic 学习率，报告 critic 外推距离、每维过滤比例、成功率和 wall-clock；再做三种随机种子。

5. ScienceClaw: Benchmarking Continual Self-Evolution of AI-for-Science Agents｜P0

作者与机构、发布时间、性质。 Mingda Zhang、Wenjin Liu、Tiesunlong Shen、Zikai Xiao、Zhenghong Lin、Qing Xu、Erik Cambria、Xiaoying Tang、Haoran Luo，来自香港中文大学（深圳）、南洋理工大学、Duke-NUS、浙江大学、中国法学相关机构等；2026-10-06 UTC 提交，arXiv 预印本，论文见 ScienceClaw，代码已在 GitHub 公开，ScienceClaw-Eval 数据入口在仓库中指向 Hugging Face。

它问的是一个常被“反思记忆”掩盖的问题：一次执行中修好的 workflow，能不能在干净回放、独立学科和后续任务上真正成为持久能力，而不是只留在上下文里。ScienceClaw 固定基础模型参数，只更新可版本化的 Skills（策略/分解/恢复）和带 type、shape、unit、provenance 合约的 Operators。候选修复必须先在源任务 reset replay 重现，再在独立验证任务上严格改进；否则保留 incumbent，并且每次更新可回滚。

作者报告 ScienceClaw-Eval 覆盖 23 个自然与社会科学学科；七轮进化中平均 OOD 增益 +16.45%，OOD macro success 从 77.72% 升到 91.30%，98.23% 实例通过全部科学硬约束，161 个候选中 70 个被提升，平均遗忘 0.13 个百分点。GitHub 还给出约 19 GB 的完整 profile 权重需求和可接入 OpenAI-compatible endpoint 的运行方式。上述数字来自作者仓库/论文，尚无第三方验证；任务主要是 AI-for-Science，不能直接等价于机器人技能的真实安全性。

它相对 Reflexion、ReasoningBank、技能库和工具演化工作的独特处，是把“回放、独立验证、成本预算、保留与迁移”写成程序级 gate，而不是由 LLM judge 单次投票。值得精读并迁移到 embodied agent：机器人中可把 Skill 绑定到动作前置条件，把 Operator 绑定到可执行轨迹和碰撞/接触 verifier。轻量验证：先用三个确定性工具任务（数据变换、规划、仿真控制）构造失败→修复→reset replay→独立任务，比较无 gate、只回放、回放+独立验证三种设置的成功率、负迁移和回滚正确性；再接入 LIBERO 或 RoboTwin 的有序中间状态。

6. Claude Haiku 5.5｜P1

性质与发布时间。 Anthropic 于 2026-10-07 发布 Claude Haiku 5.5，这是官方模型发布与平台更新，不是论文或同行评审工作；官方页面为 Claude Haiku 5.5。模型 ID 为 claude-haiku-5-5，现已在 Claude Platform、AWS、Google Cloud、Microsoft Azure 可用。

它解决的是高频、低延迟 agent 子任务的成本和吞吐：摘要、压缩、分类、数据库查询、浏览器/电脑操作，以及给更大模型做 coding subagent。官方报告的对比包括 OSWorld 2.1 离线子集 72.4%、Humanity’s Last Exam 无工具 45.9%/有工具 57.4%、Terminal-Bench 4.0 39.2%；价格页显示输入/输出为每百万 token \(0.10/\)0.50（≤100k prompt），并同步降低 Sonnet 5.5 cache-read 价格。指标、客户案例与安全结论均为 Anthropic 自测或客户早期反馈，非独立第三方验证；模型权重不公开，SDK 的 computer-use/browser-use 仍标为 beta。

它不是 world model，但会直接改变 Agent 基础设施的分层：让“大模型规划 + 便宜快速子代理 + 浏览器/工具执行”更容易做高频闭环。限制是 OSWorld 等基准的真实部署相关性、闭源评测可审计性和 API 依赖。值得作为工程侧精读，尤其关注成本—延迟曲线，而不是把官方 benchmark 当成机器人能力证据。轻量验证：在固定 10 个浏览器/终端长任务上，对 Haiku 5.5、一个本地小模型和更大模型做相同工具权限、相同重试上限的 A/B，记录每成功任务 token 成本、端到端延迟、工具错误率和需要升级到大模型的比例。

今日研究机会与轻量验证

  1. 几何—力—动作统一的轻量 WAM。 以公开的 RoboTwin/DROID 片段为输入，把 AIM 的关系保留思想或 ACG-WAM 的几何辅助目标接到小型 flow policy，再用 PEARS 的力边界作为接触 verifier；主要指标用中间位姿、接触顺序、后接触稳定性和 counterfactual action，而不是只看最终成功。
  2. 空间音频作为世界状态观测。 在 WorldSonus 的 causal 音频层上加入“声源左右/遮挡/接触事件”标签，测试有无音频时的导航、抓取和异常恢复；最小实验只需公开视频、合成双耳音和一个冻结策略。
  3. Replay-gated embodied self-evolution。 把 ScienceClaw 的 R_src ∧ H_val ∧ Q_val(new)>Q_val(old) gate 迁移到机器人技能，候选更新必须在源任务回放和独立场景都提升，并保留回滚点；先在 3 个仿真任务做 7 轮，量化遗忘和负迁移。
  4. 统一后训练预算。 在同一 replay/interaction budget 下比较 QF3、PEARS 式 latent steering、普通 residual RL；报告每次真实交互的成功增益、计算成本、接触峰值和跨对象迁移，避免把训练吞吐误写成样本效率。

证据状态与可复现性

  • 论文性质： AIM、PEARS、QF3、WorldSonus、ScienceClaw 均为 2026-10-05/06 提交的 arXiv 预印本；本轮没有把它们写成同行评审结论。ScienceClaw 的代码已公开；PEARS 有项目页但代码仍标记 under review；WorldSonus 有项目页和演示入口；AIM/QF3 的完整权重与可直接运行的训练包未在本轮确认。
  • 官方模型性质： Claude Haiku 5.5 是 Anthropic 官方发布，API/云平台可用但权重闭源；其 benchmark 和价格是官方报告，客户引用属于早期反馈，不等于第三方复现。
  • 结果边界： 所有成功率、FAD、误差下降、速度提升和 OOD 增益都标为作者/官方报告；本轮没有可靠独立复现实验。WorldSonus 的 41.2 ms 是单 H100 模型块延迟，QF3 的约 10× 是特定任务与整套吞吐配方，PEARS 的 95%/90% 来自两个 20 次实机测试任务，ScienceClaw 的 19 GB 是完整 profile 安装规模。
  • 检索与筛选边界： arXiv、官方 lab/company、GitHub/Hugging Face、空间智能/real-to-sim、VLA/WAM/RL、Agent/self-evolution 和 broader-web 兜底均已执行；窗口外的 ACG-WAM、Artemis、ProactiveVLA、LEAP 不作为本期新增主条目。若下一期出现权重、代码、版本、基准或第三方验证，再重新提升它们的优先级。
