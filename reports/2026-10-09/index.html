重点论文 / 模型 / 项目

1. Long-WAM: Scaling the Context of World-Action Models｜P0

作者与机构、时间、性质。 Wei Huang、Bohan Zhang、Chenzhi Liu、Isabella Liu、Shuai Yang、Weian Mao、Luozhou Wang、Yicheng Xiao、Weifeng Lin、Qixin Hu、Bryan Chu、Sifei Liu、Linxi Fan、Xiaojuan Qi、Song Han、Yukang Chen；NVIDIA、MIT、HKU、UCSD。论文于 2026-10-07 提交，是 arXiv 预印本加官方项目页，尚未确认同行评审。入口：论文、官方项目页、代码、Hugging Face 模型集合。

研究问题与方法。 Long-WAM 问的是：视觉历史从几秒扩到十几秒，是否真的帮助机器人判断运动阶段和任务进度，同时还能满足实时控制。它先用约 10,000 个 window-equivalent 小时的机器人和 egocentric 视频做自回归、无动作标签的下一片段预测，再做 causal-to-causal 的 WAM 适配。模型用 asymmetric Mixture-of-Transformers 让视频查询不读取动作 token；运行时用 streaming VAE、异步执行、NVFP4、KV reuse、CUDA Graph 和设备专用 kernel，把“先预测未来、再输出动作 chunk”压到部署预算内。

结果与创新。 官方页面报告 RoboCasa GR-1 在 19.2 秒历史下为 78.7%，LIBERO-Long 为 99.5%，RoboTwin 2.0 平均为 94.4%，Unitree G1 动态杯子堆叠为 19/20，RTX 5090 每个 action chunk 107.4 ms；YAM 长任务平均 81.7%。GR-1 从 2.4 秒到 19.2 秒由 63.3% 升到 78.7%，LIBERO-Long 由 94.5% 升到 99.5%，说明历史长度与 AR 预训练的组合比单纯增加窗口更关键。它相对 OpenWAM、Fast-WAM 和此前 context-free WAM 的推进，是把上下文扩展、训练初始化和推理系统一起做了可部署的协同设计；项目页还公开了 RoboTwin、LIBERO、RoboCasa365 与 LongLive2.0-Robot 的 checkpoint。

局限、证据和复现。 以上为作者/官方项目页结果，没有第三方验证；官方明确说生成视频片段只是 prediction，不是已执行的 rollout。38.4 秒设置中约 80% 帧是 padding，不能当成真正的记忆上限；107.4 ms 依赖 RTX 5090 和定制 kernel，也不能直接外推到普通 GPU。代码和多组权重已公开，复现状态是本期最强的一项，但训练规模仍然很大。建议先下载一个小模型，在单张 GPU 上比较 0/2.4/19.2 秒历史的相同任务子集，记录 success、action-chunk latency 和 history mask；再用 5 个随机种子做“真实历史、打乱历史、零历史”对照，验证提升是否来自可用信息而不是序列长度。

是否值得精读。 值得，优先级最高。它把“长上下文”变成了可测的 context-success-latency 三元关系，同时保留了对真实机器人执行的证据；最值得追问的是上下文对接触后状态和恢复动作的增益，而不是只看终点成功率。

2. RoboJEPA: Scaling Robotic Latent World Models｜P0

作者与机构、时间、性质。 Artem Zholus、Nicolas Beltran-Velez、Jianhao Yuan、Sarath Chandar、Tushar Nagarajan、Daniel Severo、Koustuv Sinha、Michal Drozdzal、Adriana Romero Soriano、Jeannette Bohg、Nicolas Ballas、Mahmoud Assran；Meta FAIR 主导，合作作者机构见论文首页。论文于 2026-10-07 提交，是 arXiv 预印本；论文、项目页、Hugging Face 论文页。

研究问题与方法。 机器人 latent world model 往往需要真机 rollout 才能知道是否有用，RoboJEPA 试图建立一个可外推的 scaling law。它用 JEPA predictor 在 12 种机器人本体的数据上预测未来 latent，而不是直接生成像素；训练和评估围绕 imagination error、模型/数据/计算量的扩展，以及从单个 goal image 出发的长时程规划。论文把 latent rollout 误差当作可提前计算的质量代理，再检验它与实际 planning 成功率的相关性。

结果与创新。 作者报告 imagination error 随计算量服从二阶 power law，并能预测超出拟合规模的模型质量；下游机器人 planning 随 compute 可预测改善，且 imagination error 与 planning 表现强相关。论文还报告 8B JEPA predictor、跨本体真实数据训练，以及在真机上根据目标图像零样本规划完成长时程任务。它与 V-JEPA/V-JEPA2 和既有 latent WM 的关系，是把“latent 预测”从表示学习问题推进成了规模规律和部署评估问题；如果代理指标稳定，真机评测可以从每个 checkpoint 一次昂贵 rollout 变成少量校准。

局限、证据和复现。 指标为作者报告，尚无第三方复现；论文写明会释放 checkpoint、训练和部署代码，但本轮访问到的项目页仍只有 “Project page coming soon”，没有可直接下载的 RoboJEPA 权重或代码链接，因此不能把“承诺发布”写成“已可复现”。规模规律也可能受固定 encoder、12 种本体的分布和数据饱和影响，不能直接外推到新机器人。轻量验证可以用公开的 JEPA/V-JEPA2 基线，在 1-2 种本体上训练 100M 级 predictor，按 3 个计算预算拟合 log-log 曲线，再用简单 goal-image MPC 验证 imagination error 是否预测 ordered-state success；这一实验不需要 8B 模型。

是否值得精读。 值得。它给出了一个可形成论文的评估问题：latent rollout 的误差是否比像素 FVD、单步 action loss 更能预测接触后状态、恢复行为和跨本体迁移。当前的主要阅读重点不是 8B 规模本身，而是 scaling fit 的数据划分、误差定义和规划相关性是否足够严格。

3. Video Prediction Policy 2: Predict Better, Act Better｜P0

作者与机构、时间、性质。 Yanjiang Guo、Haodong Yan、Zhide Zhong、Zhongru Zhang、Qingyuan Yang、Qingzhou Lu、Xiaoyu Chen、Yen-Jen Wang、Shuying Deng、Chenghan Yang、Puzhen Yuan、Chenxin Liu、Tun Ban、Xiang Zhu、Yichen Liu、Kun Feng、Haoang Li、Jianyu Chen；公开索引列出 RobotEra、清华大学、香港科技大学（广州）、UC Berkeley、上海交通大学等合作机构。v1 于 2026-10-07 提交，v2 于 2026-10-08 更新；arXiv v2。这是预印本，项目页和代码/权重仍未在本轮确认。

研究问题与方法。 VPP2 认为现有 WAM 在开放环境中预测了错误运动，原因一是通用视频模型没有针对 manipulation 优化，二是直接塞入 action 模态会损害视频泛化。方法包括大规模操作视频继续预训练、细粒度 caption、event-level 目标、固定 horizon 的视觉 planner、post-training 后的 consistency distillation，以及一个 0.9B 的 Mixture-of-Transformers action expert 学习隐式 inverse dynamics。关键数据处理是把不同数据源的 workspace 和 end-effector 坐标对齐，使视频事件与动作语义共享坐标系。

结果与创新。 作者报告 VPP2-14B 在开放任务视频指令跟随上比 Cosmos3-64B 高 11.0 个百分点，在真实 ALOHA 零样本操作上比最强基线高 18.5 个百分点；按各 benchmark 的 post-training，LIBERO-Pro、LIBERO-OOD、RoboDojo 均为所比较方法最高。创新不在于单个模块，而在于“事件级视频预训练 → 单步固定 horizon 规划 → MoT 动作专家”的组合，使 video prediction 与 action generation 共享可用的未来表示；它延续了早期 Video Prediction Policy，也与 Long-WAM 的 causal video-to-action 路线形成互补。

局限、证据和复现。 结果是作者报告。外部的 Pith AI review 指出视频评测每个域只有 50 个 image-instruction 对，使用未公开 rubric 的 GPT judge，且没有 policy-level ablation 证明“视频预测提升是动作提升的因果原因”；这属于第三方文字审阅，不是第三方实验复现。代码、checkpoint 和训练数据在本轮没有可下载确认，因此复现性低于 Long-WAM。轻量验证应固定 action head，只替换 event-level 与 fixed-step video target，在 20-50 个人工核验片段上做独立物理完成度评分，并在一个小型 ALOHA/仿真任务上做 policy-level ablation；不要只重现视频观感分数。

是否值得精读。 值得，但应以“因果链审计”为阅读目标。若 event-level 预训练只提高视频外观而没有提升 ordered action state，这个结论会退化成又一个视频模型规模结果；若政策层面也成立，则它是 WAM 训练目标设计的重要基线。

4. SMART: Zero-Shot Sim-to-Real Articulated Object Manipulation via Large-Scale Synthetic Pretraining｜P1

作者与机构、时间、性质。 Jicong Ao、Shuhan Jiang、Yuling Zhong、Yanwen Liu、Yuhan Gao、Jiangyuan Zhao、Yang Zhang、Shiqiang Zhu、Chenjia Bai、Xuelong Li；公开索引列出中国电信人工智能研究院、慕尼黑工业大学、哈尔滨工业大学、上海交通大学、清华大学、浙江大学等合作机构。论文于 2026-10-06 提交，标注为 Technical Report；论文、Hugging Face 论文页。

研究问题与方法。 关节物体操作需要识别可动部件、遵循 joint limit、维持接触并完成约束轨迹，真实演示昂贵且难覆盖。SMART-Sim 为此加入 articulation-aware 资产、part/joint 语义和约束轨迹生成；上层用 agentic task generation 构造任务，下层用分布式合成生成 SMART-Data。论文报告数据量超过 1M demos，覆盖 44 个 atomic task types、5 个 robot setups、2,507 个 articulated objects，再用这些数据预训练 VLA。

结果与创新。 作者报告在仿真 benchmark 上具有竞争力，并能零样本 sim-to-real 到真实关节物体操作；二手论文摘要还列出 3 个机器人平台和跨平台任务，但本轮没有找到完整可下载数据包或独立复现。SMART 的创新是把“接触约束和部件语义”写进数据生成接口，而不是只扩大通用随机化场景；它与 ArticuBot、部件感知的 3D/RL 管线相比，更强调可规模化的合成 demonstration 生产线。

局限、证据和复现。 真实成功率与每个任务的 trial 数仍应以论文完整表格为准；二手摘要指出完整资产库有 88 类，但实际轨迹覆盖约 23 个功能类别，说明“资产规模”不等于“有效行为覆盖”。本轮未确认公开 SMART-Sim、SMART-Data、VLA 权重或代码，也没有第三方结果，故可复现性为低。轻量替代实验可用 Isaac Lab 或 MuJoCo 选 2-3 种抽屉、旋钮、翻盖，生成四类受限接触任务，比较 synthetic-only、10 条真实 demonstration 微调和 real-only 三种设置，评价 joint-limit violation、接触稳定、未见物体和终点后状态。

是否值得精读。 值得作为数据和仿真路线的精读对象，尤其适合检查“合成规模是否真的转成接触泛化”。不要把 1M demos 当成已经公开可训练的资产；第一步应先拿到数据格式和资产许可，再决定是否投入大规模重建。

5. Agentic RSR: Real-to-Sim-to-Real through Scene Reconstruction and Execution-Grounded Robot Policies｜P1

作者与机构、时间、性质。 Yihan Li、Yating Feng、Shengjiu Sun、Jianing Chen、Hao Ren、Bowen Yang、Weisheng Xu、Qiwei Wu、Hui Cheng、Renjing Xu；公开作者页显示 Renjing Xu 与 HKUST(GZ) 关联，论文为多机构合作。论文于 2026-10-07 提交；论文。这是预印本，代码和重建场景“将公开”，目前未确认已发布。

研究问题与方法。 Agentic RSR 试图把真实工作空间视频、任务描述、已知机器人模型和仿真策略放在一个闭环里，而不是把 scene reconstruction 与 policy learning 分开。系统先恢复 metric scale，在视觉反馈下反复修正场景，并在 MuJoCo 检查任务相关接触；coding agent 再从 privileged object pose 过渡到真实可见的视觉观测和随机化仿真。策略一次调用中可交替多次 observation/action，执行失败后由 agent 继续、重试或改写；同一个 task interface 把策略和经验传到真实机器人，并加入安全检查。

结果与创新。 18 个重建场景、2 个机器人上，作者报告四视图 Depth MAE 0.1057 m、Lab ΔE76 11.04、灰度 SSIM 0.6990，真实成功率为仿真成功率的 80%。这项工作的价值是把“重建是否足以支持任务”变成 execution-grounded 迭代，而不是只优化视觉重建指标；它连接了 Real-to-Sim、代码生成和 real-world recovery。

局限、证据和复现。 这些指标是作者报告；深度参考来自视频推断而非独立激光/深度真值，真实完成判定与 agent 的执行循环也有耦合。第三方 Pith AI review 因此把 80% retention 视为待审计的系统证据，而非独立成功率；它不是人类或硬件复现。代码、场景和闭源 agent 依赖仍未公开。轻量实验应只选一个桌面场景和 pick-place 任务，用独立深度相机或网格扫描作 geometry ground truth，用外部 success checker 判定状态，并重复 5 个 seed；这比复刻 18 场景更能判断闭环是否真的有效。

是否值得精读。 值得，尤其是 Real-to-Sim 研究。阅读重点应放在任务级接口、重建停止条件和执行反馈如何改变场景，而不是只看最终 sim-to-real 比例。

6. EmbodiedRSI: Active Continual Robot Learning Through Hypothesis-Guided Co-Evolution｜P1

作者与机构、时间、性质。 Python Song、Zhixuan Liang、Kelsey Fu、Mengdi Wang、Junfeng Yang、Shilong Liu；公开索引把团队标为 Columbia/Princeton 关联，完整机构以论文首页为准。论文于 2026-10-07 提交；论文。这是预印本，无公开代码、权重或数据包已被确认。

研究问题与方法。 EmbodiedRSI 不更新冻结的 robot foundation model，而是让围绕模型的 harness 用有限物理试验主动寻找改进方向。Fast-Slow Dual-System 维护互相竞争的 code/skill hypotheses，Hypothesis Graph 保存证据；Value-of-Information Experiment Selection 选择最能区分假设的下一次物理实验；结果驱动 Code-Skill Co-Evolution。Slow System 形成 hierarchical memory，Reward-Grounded Memory Learning 再按未来改进价值筛选记忆。

结果与创新。 作者报告 RoboCasa365 overall 77.0%、Composite-Unseen 71.3%，相对最佳 baseline 40.1%；LIBERO-Pro 为 86.8%，零样本真实机器人为 71.3%。论文的可贵之处是把“自我进化”拆成实验选择、代码、技能和记忆四个可审计对象；它与一般 test-time adaptation 或反复 prompt search 的关系，是把每次机器人试验同时当作 rollout 和 hypothesis test。

局限、证据和复现。 所有数字为作者报告，尚无第三方实验；冻结的 VLA backbone、每个任务的 trial budget、失败标签和跨 seed 方差需要在全文中逐项核查。没有公共代码/权重/数据，实际复现门槛高。轻量验证可以冻结一个小型开源 VLA，给 20 个 matched episodes，比较 random experiment selection、只进化 code、只进化 skill、联合进化四组；报告每次试验成本、假设校准、ordered-state success，而不是只报告最终平均成功率。

是否值得精读。 值得作为 Agent/self-evolution 主线的当前代表。它最可能形成可复现论文的部分不是 77.0% 这个数字，而是“在固定物理预算下，VOI 是否比随机探索带来更高的信息增益”。

7. RoboQuest: Generalist Physical Agents that Search, Inspect and Test｜P1

作者与机构、时间、性质。 Liu Renhang、Navonil Majumder、Tej Deep Pala、Soujanya Poria；DeCLaRe Lab、Nanyang Technological University。论文于 2026-10-07 提交；论文、项目页、GitHub、Hugging Face 数据集。这是公开 benchmark、代码和数据，论文仍是预印本。

研究问题与方法。 RoboQuest 评测机器人是否会在观察不完整时主动搜索目标、操作检查隐藏属性、测试陌生工具，并在证据足够时才确认完成。十个移动操作任务覆盖 search、manipulation-based inspection、interactive testing；每个模型 500 个 evaluation episodes，最多 200 次决策，三路相机。数据有 5,000 个 verified demos、约 366 小时、20 Hz、LeRobot v2.1，测试场景与 demonstration 场景不重合。

结果与创新。 官方项目页报告 GPT-6 Astra 23.2%、Claude Opus 5.5 13.8%、GPT-6.1 Sol 12.2%、Claude Fable 11.4%、Gemini 3.8 Flash 2.0%；执行技能单独测试为 72%-81%，但缺失证据导致 43%-46% 失败，π0.5 用完整 demos 微调后仍几乎不成功。它把“会做动作”与“知道何时继续探索、何时修复副作用、何时提交”分开测量，适合检验长时程 agent 是否真正维护任务状态。

局限、证据和复现。 指标来自作者/官方 benchmark，仍是仿真环境与 API agent 结果，不是第三方复现实验，也不等价于真机成功。模型调用成本、终止规则和执行器接口会影响数字。代码和数据公开，复现性是本期最强之一：先跑 README smoke test，再离线 replay 一个任务，随后选 search、inspect、test 各一项接入本地模型；评价中间证据、顺序状态和副作用修复，不要只看最终画面。

是否值得精读。 值得。它是今天最适合做小预算 benchmark 验证的项目，也可以直接作为 EmbodiedRSI 的外部评测。

8. RobotWorld: Benchmarking Multimodal Agents for Robot Use Across Diverse Tasks and Embodiments｜P1

作者与机构、时间、性质。 Zhiqin Yang、Chenxin Li、Xiaomeng Hu、Yibin Liu、Weidong Huang、Jiankai Sun、Haitao Li、Zijian Wu 等 35 位作者，末位包括 Yike Guo；项目页未把多机构署名集中列出，机构应以论文首页为准。论文于 2026-10-07 提交；论文、项目页、GitHub。

研究问题与方法。 RobotWorld 问通用多模态 agent 的代码、工具和视觉能力能否迁移到物理任务执行。它整合 84 个任务，覆盖 manipulation、mobile manipulation、locomotion、driving、aerial 五类，项目页列出 18 种 embodiment、20 个 control profiles；每个任务有明确 interaction budget、允许的 observation/action contract 和可执行 success checker，并保存分析与控制 trace。

结果与创新。 官方数据页当前给出 84/84 有效评测时，GPT-6 Astra 16/84（19.0%）、Claude Opus 5.5 13/84（15.5%）、Kimi K3 2/84、DeepSeek V4.1 Flash 1/84、Gemini 3.8 Flash 1/84。论文和 trace 分析显示，agent 能临时写出 segmentation、camera calibration、spatial estimation 和 dynamics computation，但经常丢失物体状态、未修正无效动作、恢复过晚或误判任务已完成；Astra 在空间/受限接触类较强，Opus 在连续平衡/定时交互类较强。它相对 RoboQuest 更强调跨本体和控制接口，相对普通 VLM benchmark 更强调执行过程。

局限、证据和复现。 结果是官方数据与作者报告，仍为 simulation-only；当前 GitHub snapshot 说明预构建镜像访问受限、完整测试并非全部通过、API-backed simulator validation 尚待完成，且 RobotWorld 自有代码的顶层许可证信息不完整。项目页的任务结果可下载，但不能把一次模型评测当成硬件泛化。轻量验证可先跑一个 RoboCasa 或 locomotion 任务，再扩到八任务子集；记录 observation/action trace、state retention、recovery latency 和 checker outcome，并用同一模型预算比较“只给 direct action”和“允许 code/tool workspace”两种接口。

是否值得精读。 值得作为跨 embodiment 的评测底座，但应把 benchmark 贡献与模型排行榜分开阅读。它最直接地暴露了“局部几何推理能力已有，状态维护和闭环编排仍缺失”的 gap。

9. Tetris3D: 3D Scene Generation With Objects That Fit Together｜P1

作者与机构、时间、性质。 Jaeyeong Kim、Jinhyuk Jang、Jongmin Lee、Kyehong Park、Seungryong Kim；KAIST AI。论文于 2026-10-07 提交；论文、项目页。这是 Spatial Intelligence 方向的 arXiv 预印本，代码按钮仍标为 “SOON”。

研究问题与方法。 许多单图 3D 重建把对象独立生成，导致相邻物体的接触、遮挡和空间兼容性不可信。Tetris3D 让每个对象的形状和姿态显式条件于周围几何与物理关系；同时提出 ComOb 物理仿真数据集，包含 1.2M 个场景、逐物体 mesh 和 pairwise physical-relation annotations。训练目标不只是外观重建，还要让遮挡区域、支撑关系和接触稳定在仿真中成立。

结果与创新。 作者报告在合成和真实场景上取得 generation quality 与 physical stability 的 state of the art，尤其在交互区域被遮挡时仍能恢复相互匹配的物体。它把“空间智能”从单对象几何或视觉新颖性推进到对象之间能否放在一起、是否会穿透或倒塌的问题；与 3D diffusion、独立 object completion 和一般 NeRF/GS 重建相比，物理关系是显式条件而不是事后过滤。

局限、证据和复现。 结果尚无第三方复现；ComOb 数据、权重和代码本轮未确认公开，物理稳定性也主要在作者选择的 simulator 中验证。轻量实验可以调用一个公开 3D backbone，生成 20 个桌面场景，与“逐对象独立生成” baseline 对比，在同一 MuJoCo/Isaac 场景中计算 penetration、支持多边形和扰动后跌落率；若只有视觉指标提升而 contact validity 不提升，研究价值会明显降低。

是否值得精读。 值得作为 Spatial Intelligence 的一级条目。它与 Agentic RSR 的关系是“重建后能否执行”和“生成时是否保持物理关系”两端；两者结合可构成一条从 3D world reconstruction 到 controllable simulation 的实验链。

10. ΔWAM: Distilling Action Tangent Fields into World Action Models｜P2

作者与机构、时间、性质。 Ke Wu、Hanwen Huang、Bo Gu、Kaizhao Zhang、Xiangting Meng、Yupeng Zheng、Zijun Xu、Jieru Zhao、Wenchao Ding 等；论文未在公开项目页集中列出机构。论文于 2026-10-07 提交；论文。这是预印本，未确认公开代码或权重。

研究问题与方法。 WAM 的视频监督往往被场景外观和静态背景占据，真正与动作相关的变化只占小部分。ΔWAM 提出 Action Tangent Fields，把未来动态写成动作变化的局部 Taylor 结构；在 Residual-VAE 空间中表示未来 residual，用 action-conditioned world model 探测 action variation 与 residual-world variation 的局部对应，再把这种一阶结构蒸馏到 WAM 的 denoising supervision。作者还把多步 VideoDiT denoising 蒸馏为单步推理。

结果与创新。 在 LIBERO-Plus、RoboTwin、RoboTwin2.0-Plus 上，作者报告对 lighting、background、camera、layout 等分布偏移更稳健，并在若干 shift 下超过预训练策略，且没有大规模 embodied pretraining。它与 Long-WAM/VPP2 的关系不是继续堆数据，而是把 video target 选择成更 action-relevant 的局部方向；这一方向也能解释为什么仅有更好外观预测未必带来更好控制。

局限、证据和复现。 摘要没有给出可独立核对的绝对成功率、训练成本或公开 checkpoint；没有第三方结果。轻量实验可以在二维 push 环境训练一个 residual model，用 action intervention 与 appearance-only target 做 linear probe，检查 action tangent 是否能预测接触后位移；再将该 target 接到一个小型 diffusion policy，比较单步推理和 shift robustness。

是否值得精读。 作为 P2 精读，重点看 Action Tangent 的估计误差、probe 是否使用未来信息泄漏，以及 shift robustness 是否来自更强 augmentation。若验证成立，它可以成为 WAM 的“动作相关监督”基线。

Spatial Intelligence / Frontier 扫描

Spatial Intelligence 本轮作为一级主线独立检索，覆盖 Tetris3D、Agentic RSR、RobotWorld，以及候选池中的 Ledger（持久 3D object memory）、Argos（几何先验的在线 scene-change detection）、ECHO（人类携物视频的 RGB-D/轨迹数据）和 TouchScale（视觉-触觉数据）。这些没有全部进入 Top 条目，原因是部分仍是作者报告、代码/数据未确认或与今日主线重复；这属于检索后 Selection，不是因为只看 arXiv 而漏检。

官方入口结果。 本轮已扫描 World Labs、Generalist AI、Physical Intelligence、Google DeepMind/Robotics、NVIDIA Robotics/Cosmos/GR00T、Figure、Skild AI、Field AI、1X、Meta FAIR、Anthropic、Toyota Research Institute，以及 Stanford、Berkeley、MIT、CMU、Princeton 和主要中国机器人团队的 research/news/project/model 页面；也交叉查了 GitHub、Hugging Face 和 broader web。本轮已扫描主要官方发布入口，未发现足以进入 Top Papers 的重大新增。 Google DeepMind、Meta FAIR、Figure、NVIDIA Cosmos、Anthropic 的窗口内页面主要是其他主题或更早的机器人更新；没有把 Anthropic 的政策/安全类页面当成机器人模型发布。Long-WAM 是 NVIDIA/MIT 合作的公开研究项目，已经在重点条目中计入，但不等同于 NVIDIA 公司新闻稿的新产品发布。

候选池还检索到同窗的 RealtimeWAM（arXiv 2610.10079）、VideoEvolve、TouchScale、ECHO、Argos、COSTGRAD 等。RealtimeWAM 的训练免费 adaptive compute 结果值得跟踪，但本轮没有确认对应论文的可运行代码；同名的 LightX2V 实现来自更早的 Oct-05 one-step 论文，不能与 2610.10079 混为一谈，因此没有把它当作本期新代码发布。

今天的共同趋势可以写成：

\[ \text{可用的 World Model} \approx \text{可预测未来} + \text{动作相关性} + \text{独立状态检查} + \text{可部署延迟}. \]

单独扩大视频、参数或合成轨迹，都不能替代这四个条件。Long-WAM 解决了上下文和部署的一部分，RoboJEPA 试图解决评估代理，VPP2/ΔWAM 处理 action relevance，RoboQuest/RobotWorld 则告诉我们仍缺少有序交互和恢复。

今日研究机会与轻量验证

  1. Context causality benchmark。 直接使用 Long-WAM 公共 checkpoint，在相同 compute 下比较 0、2.4、9.6、19.2 秒真实历史、随机打乱历史、只保留关键帧和 padding 历史；除 final success 外记录接触后状态、恢复次数、action latency。目标是区分“更多 token”与“可用历史”。
  2. Action-relevant future probe。 在小型桌面推物或 LIBERO 子集上，分别训练像素 future、latent future、ΔWAM 式 residual future；用 intervention 预测接触后位移和失败类型，验证 imagination error 与 ordered-state success 的相关性。
  3. Real-to-Sim 独立审计。 对 Agentic RSR 的单场景替代实验使用外部深度/网格真值和独立 success checker，公开每次重建修订、策略重试和 sim/real attempt budget。这样可以把“重建看起来像”与“足以执行任务”分开。
  4. 预算固定的自进化。 以冻结开源 VLA 为基线，在 RoboQuest 或自建 20-task suite 上比较 random、uncertainty、VOI 三种试验选择；统一 20 次物理/仿真预算，记录 hypothesis calibration、memory reuse 和 first-failure recovery。
  5. 关节物体的真实最小数据曲线。 先只建 3 个关节物体和 4 种 primitive，测 synthetic-only、10 条真实演示和 50 条真实演示的性能曲线，重点评价 joint-limit violation、接触后状态和未见物体，而不是只报总体 success。

这些实验都可以在单卡或中等 GPU 上完成，先验证数据契约、目标布局、action grounding 和 checker，再考虑大规模蒸馏或 8B/14B 训练。

证据状态与可复现性

  • 论文性质。 本期重点论文均为 2026-10-06 至 2026-10-08 的 arXiv 预印本或技术报告，尚未确认同行评审。作者/官方指标已经在正文中逐项标注，不能当作独立验证。
  • 已公开且可先跑。 Long-WAM 提供代码和多组 Hugging Face checkpoint；RoboQuest 提供 MIT 代码、LeRobot 数据和 replay/smoke test；RobotWorld 提供项目页、任务结果和 GitHub，但完整镜像与测试仍有限制。
  • 声称将公开但本轮未确认。 RoboJEPA 论文写明会发布 checkpoint/code，但项目页仍是 coming soon；Agentic RSR 写明将发布代码和场景；VPP2 的代码/权重在本轮没有可下载确认；SMART 的仿真、数据和 VLA 权重没有确认公开；Tetris3D 项目页的 code 按钮仍为 SOON。
  • 第三方证据。 Agentic RSR 和 VPP2 有第三方 AI 文字审阅，主要指出 self-assessed success、内部深度参考、样本量和缺少 policy-level ablation；没有一项形成独立硬件复现。Pith 等审阅不能替代真实第三方运行结果。
  • 检索失败与筛选的区分。 本轮确实建立了跨入口候选池，并在 broader web 交叉检查了 Spatial Intelligence、World Model、Physical AI、Real-to-Sim、3D/4D、Human-to-Robot 和 Agent/Self-Evolution。OpenWAM、VeriFine、DepthWorld 等上一期条目能被检索到，但没有新版本、代码/权重、基准或第三方证据，所以被去重筛除；这不是检索失败。对未公开代码、受限镜像和“将公开”的项目，报告保留“未确认”而没有把访问受限改写成低质量筛选理由。

今天先读 Long-WAM → RoboJEPA → VPP2，用公开 Long-WAM 权重做 context mask 和 ordered-state smoke test；若结果支持“可用历史”而非“更多 token”，再把同一评测协议迁移到 SMART 的关节物体和 RoboQuest 的主动探索任务。
